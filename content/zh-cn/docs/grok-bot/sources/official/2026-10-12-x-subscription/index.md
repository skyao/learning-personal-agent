今天我们推出 The X Subscription，把 Grok、Grok Bot、Cursor 和 X Premium 合并到一个套餐中。在接下来的几天里，我们将向全球所有人开放。

这是第一次，一个 AI 订阅支持从思考和创作到构建和分享的完整路径。

- **Grok** 支持聊天、语音以及图片和视频生成。
- **Grok Bot** 为你提供能把事办成的 AI 队友。
- **Cursor** 提供领先的本地和云端编码智能体。
- **X** 增加认证标记、创作者工具和更少的广告，更高档位会完全移除时间线中的广告。

The X Subscription 的付费套餐包含一个充裕的 Grok 模型用量池，在 Grok 和 Cursor 之间共享。**每个对应的新档位都比它所替代的套餐提供更高的每美元用量。**

无论你是在 Grok 应用、X 上的 Grok 标签页还是 Cursor 中使用 Grok 模型，共享用量池都覆盖它们。每个 X Subscription 套餐包含的我们模型的编码用量，至少是对应 Cursor 套餐的两倍。使用新套餐时，第三方模型在 Premium 及以上档位仍可在 Cursor 中使用。用量按 API 标价单独计费，通过充值支付。

The X Subscription 从今天起面向新客户提供。

我们也在为现有的 SuperGrok、Cursor 和 X Premium 订阅者推出切换选项。当它对你的账号可用时，你会在账号的账单设置中看到。你可以保留当前套餐，也可以切换，并按比例退还旧套餐的费用。

## 套餐与价格

The X Subscription 让你以大致相当于其中某一产品此前对应独立套餐的价格，获得 Grok、Cursor 和 X。

| 套餐 | 价格 | 包含内容 | 包含用量 |
| --- | --- | --- | --- |
| Free | $0 | 每日使用 Grok、Cursor 编码智能体的入门额度，以及标准版 X | 有限 |
| Plus | $8/月 | Grok 和 Cursor 中更多的 AI 用量，外加 X 上的认证标记、创作者工具和更少的广告 | 基础 |
| Premium | $30/月 | SuperGrok、Cursor Pro 和 X Premium+ 的权益，此前合计 $90/月 | Plus 套餐的 4 倍 |
| Super | $100/月 | 上述全部功能 | Plus 套餐的 15 倍 |
| Ultra | $200/月 | 上述全部功能 | Plus 套餐的 50 倍 |

关于定价、包含用量和资格的更多细节见[定价页](https://x.ai/pricing)。

## 面向团队和企业的一个订阅

团队用户以与个人套餐相同的每席位价格获得 The X Subscription 的 Premium、Super 和 Ultra。这比旧的 Cursor Teams 每席位更便宜，但现在包含多 3 倍的编码用量，外加 SSO、管理控制、统一账单、用量分析和 SOC 2 合规。

企业客户可以在一个控制台中管理 Grok 和 Cursor，两个产品共用一个用量池。我们的销售团队随时帮你[开始使用](https://x.ai/contact-sales)。

## 保留当前套餐或转向 The X Subscription

对现有的 SuperGrok、Cursor 或 X Premium 订阅者来说，一切不变。你可以保留当前套餐、价格和功能，也可以转向 The X Subscription。

切换附带限时优惠，你可以在账号的账单设置中看到。
