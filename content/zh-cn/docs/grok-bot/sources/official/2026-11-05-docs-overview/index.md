Grok Bot

Grok Bot 是你的主动型 AI 队友。它可以帮助你制作演示文稿、开展营销活动、预订晚餐，或让你的日历与所有日程变化保持同步。

它是一个能使用云端真实计算机的智能体，所以你能做的事，它也能做。

[开始使用](https://docs.x.ai/grok-bot/get-started)

[查看用例](https://docs.x.ai/grok-bot/use-cases)

[面向团队的 Grok Bot](https://docs.x.ai/grok-bot/teams-and-enterprises)

## 一整支 Bot 团队

Bot 可以承担原本要花数小时或数天的大任务。它们跨应用、网站和工具工作，也彼此协作：多个 Bot 可以像真正的团队一样一起工作。

聊天是 Grok Bot 的主要界面，但你也可以发起语音通话或发送语音消息。当你把 Bot 连接到日常使用的工具时，它们表现最好：[Slack](https://x.ai/bot/plugin/674)、[Notion](https://x.ai/bot/plugin/404)、[Google Drive](https://x.ai/bot/plugin/45893413)、Teams 等。Grok Bot 支持自定义工具，因此可以与任何 MCP 或 API 交互。

* [Google Drive](https://x.ai/bot/plugin/45893413) — 基于已有内容起草。读取文件夹中的简报和过往演示文稿，按你的格式起草下一份，并留在 Drive 中供你编辑。
* [Google Calendar](https://x.ai/bot/plugin/45893411) — 用一份计划开始每一周。每周日晚上读取未来一周，标出冲突和排满的日子，并在周一给你一份简短计划。
* [Gmail](https://x.ai/bot/plugin/45893410) — 醒来就有整理好的收件箱。在你起床前整理夜间邮件，为需要你处理的线程起草回复，并把每份草稿留给你发送。
* [Granola](https://x.ai/bot/plugin/5609) — 把笔记变成下一步行动。每天晚上读取当天的 Granola 笔记，提取每个行动项及其负责人，并起草一条发往团队 Slack 频道的帖子，经你批准后发出。
* [Slack](https://x.ai/bot/plugin/674) — 随时接住请求。监视提及你名字的消息，开始处理请求，例如营销文案或活动简报，并在线程中回复前把草稿发给你批准。
* [Notion](https://x.ai/bot/plugin/404) — 让项目页面保持最新。每周五为每个项目页面起草进度更新，标出变化，经你批准后添加。

[浏览所有应用](https://cursor.com/marketplace)

* [你的主 Bot](https://docs.x.ai/grok-bot/bots#your-primary-bot) — 问你的主 Bot 有什么新消息，它会代表为你工作的每个 Bot 回答。
* [晨间简报](https://docs.x.ai/grok-bot/use-cases#chief-of-staff) — 每天早上，一个 Bot 用一条帖子汇总你的邮件、日历、Slack 和文档。
* [使用计算机和应用](https://docs.x.ai/grok-bot/computer-and-apps) — 你的 Bot 共用一台云计算机，因此可以使用没有连接器的应用和网站。
* [给 Bot 一份工作](https://docs.x.ai/grok-bot/use-cases#sales-outbound) — 交给 Bot 一件明确的工作，例如筛选潜在客户，它会起草每一封回复供你确认。
* [连接你的工具](https://docs.x.ai/grok-bot/computer-and-apps#connect-an-app) — 连接你使用的应用，一个 Bot 就能跨 Gmail、Slack 和 Drive 工作。
* [每天早上运行](https://docs.x.ai/grok-bot/skills-routines-and-automations#create-a-routine) — 让 Bot 重复一项任务，它就会变成按你设定的时间表运行的例程。
* [团队一起跑活动](https://docs.x.ai/grok-bot/how-grok-bot-works) — 几个 Bot 分担一场活动，把工作传递下去，然后交给你审查。

## Grok Bot 的不同之处

* [Bot 之间交接工作](https://docs.x.ai/grok-bot/skills-routines-and-automations#create-a-routine) — Bot 一起工作，然后把你拉进来。一个 Bot 的例程拉取本周数据，另一个 Bot 据此起草活动方案，第三个审查它。然后它们交给你批准、编辑或退回。
* [Bot 共用一台计算机](https://docs.x.ai/grok-bot/computer-and-apps) — Bot 可以像人一样做真正的工作。在底层，你的 Bot 共用一台持久云计算机，带有浏览器、文件系统和终端，就像你自己的电脑。
* [像队友一样与它交谈](https://docs.x.ai/grok-bot/chat-and-collaboration#message-a-bot) — 交接工作就像告诉同事一样容易。无论你在哪里，都可以呼叫 Bot 或发送语音消息，它会像收到打字消息一样开始工作。
* [Bot 学得很快](https://docs.x.ai/grok-bot/skills-routines-and-automations) — 示范一次，它就能接手。带 Bot 走一遍任务，它就能把步骤保存为技能，并按时间表重跑。
* [Bot 记得你](https://docs.x.ai/grok-bot/bots#what-a-bot-remembers) — 你不必从头开始或反复说明。你的 Bot 会从上次停下的地方继续，你的偏好、文件和登录信息都已就位。
* [在你所在的地方工作](https://docs.x.ai/grok-bot/faq#where-do-i-talk-to-grok-bot) — 你的 Bot 在你已经工作的地方与你相见。可以在桌面、移动端、Slack 或 X 上使用 Bot。

## 预置 Bot，快速上手

已经为某项工作配置好的 Bot。在市场里打开一个，看看它做什么。

* [Overheard](https://x.ai/bot/marketplace/bots/overheard) — 监视 Reddit、Hacker News、新闻网站和 X 上关于你的名字、品牌和 URL 的第三方提及，有内容达到标准时发送一份工作日简短摘要。没有动静的日子保持安静，绝不代表你发布内容。
* [Tradbot](https://x.ai/bot/marketplace/bots/tradbot-2) — 监视你的个人邮件和日历，让学校表格、账单和 RSVP 不遗漏。起草回复，发现接送冲突，未经你确认绝不发送。
* [Meeting Recap Deck](https://x.ai/bot/marketplace/bots/echo) — 把你的会议笔记变成使用你的幻灯片模板的回顾演示文稿。基于你粘贴或上传的笔记工作，绝不编造引语。
* [Pitch Deck Coach](https://x.ai/bot/marketplace/bots/pitch-deck-coach) — 审查一份路演演示文稿，报告投资人可能理解、相信、质疑和记住什么，然后帮助加强故事、证据和幻灯片。
