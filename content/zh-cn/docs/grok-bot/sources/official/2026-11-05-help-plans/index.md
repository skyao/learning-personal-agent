## 如何获得 Grok Bot 的访问权限？

在 [The X Subscription](https://cursor.com/help/the-x-subscription/overview) 上，Grok Bot 包含在 Premium、Super 和 Ultra 中，适用于个人和团队席位。Plus 和 Free 不含。在[旧版 Cursor 套餐](https://cursor.com/docs/account/pricing/legacy-cursor-plans)上，Grok Bot 的访问权限包含在每个付费个人套餐和 Cursor Teams 中。你也可以通过关联个人 SuperGrok、SuperGrok Plus、SuperGrok Heavy 或 X Premium+ 订阅，或使用在自助 Grok Business 套餐中分配了席位的 Grok 账号登录，为旧版 Cursor 账号授予用量。

## Grok Bot 在 The X Subscription 上如何运作？

在 The X Subscription 上，Grok Bot 是你套餐中的又一个产品，而不是单独的授予。

- **包含在 Premium、Super 和 Ultra 中。** Plus 不包含 Grok Bot。Super 和 Ultra 包含比 Premium 更大的每周池。
- **一个共享的每周池。** Grok Bot 用量与 Cursor 和 Grok 应用从同一个每周池中扣除，而不是单独的 Grok Bot 计量器。该池每周刷新。
- **充值代替按需。** 当你的每周池用完时，额外的 Grok Bot 用量由你的预付额度支付。在 [grok.com/dashboard/billing](https://grok.com/dashboard/billing) 的**额外用量额度（Additional usage credits）**下购买额度、开启**自动充值（Auto Top-up）**，并设置每月额外用量上限。参见[基于用量的收费](https://cursor.com/help/account-and-billing/overages)。
- **无需关联。** SuperGrok 或 X Premium+ 关联不属于 The X Subscription。如果你从使用关联的旧版套餐切换过来，切换后你的 Grok Bot 用量来自共享池。
- **查看用量** 在 [grok.com/dashboard](https://grok.com/dashboard) 的**用量（Usage）**下。
- **推荐重置。** 邀请朋友使用 Grok Bot 可以为你赢得一次用量重置。参见 [Grok Bot 有推荐计划吗？](https://cursor.com/help/account-and-billing/referral-program#does-grok-bot-have-a-referral-program)。

关于切换后 SuperGrok 和 Grok Bot 会发生什么，参见 [The X Subscription 上的 Grok Bot](https://docs.x.ai/x-subscription/grok-bot)。本页其余部分介绍旧版 Cursor 套餐和账号关联。

## 旧版 Pro、Pro+ 和 Ultra 在 Grok Bot 上有什么区别？

- **Pro** 包含 Grok Bot 及每周用量，低于 Pro+ 档。
- **Pro+** 包含 Grok Bot 及充足的每周用量，低于 Ultra 档。
- **Ultra** 包含 Grok Bot 及最高的每周用量。

Pro、Pro+ 和 Ultra 登录 Grok Bot 的方式相同：使用同一个 Cursor 账号。你仍然可以在这些旧版 Cursor 套餐内升级。从 **Pro+** 移动到 **Ultra** 会把包含的 Grok Bot 用量提升到 Ultra 档。

## 我需要单独的 Grok Bot 订阅吗？

不需要。访问权限随 The X Subscription 的 Premium、Super 或 Ultra 包含，随旧版 Cursor Pro、Cursor Pro+、Cursor Ultra 或旧版 Cursor Teams 席位包含，也可通过个人 SuperGrok、SuperGrok Plus、SuperGrok Heavy 或 X Premium+ 账号关联获得，或在自助 Grok Business 套餐中分配了席位时获得。

## 加入 Cursor Teams 套餐需要为 Grok Bot 购买 Premium 席位吗？

不需要。在自助 **Cursor Teams** 套餐上，每个成员都会在其 Cursor 账号上获得 Grok Bot。在 The X Subscription 的团队中，每个付费席位（Premium、Super 或 Ultra）都包含它。在旧版 Teams 套餐上，管理员无需分配 Premium 席位，成员也无需申请访问权限。

Grok Bot 用量从席位的用量额度中扣除。在旧版 Teams 套餐上，按需用量默认启用。关于席位额度和额外用量详情，参见[团队定价](https://cursor.com/docs/account/teams/pricing)。

## Grok Bot 的用量如何运作？

在 The X Subscription 上，参见 [Grok Bot 在 The X Subscription 上如何运作？](#how-does-grok-bot-work-on-the-x-subscription)。在旧版 Cursor 套餐和账号关联上，付费的 Grok Bot 访问权限包含每周用量，显示为**每周用量上限（Weekly usage limit）**。该包含的授予每周重置。用完后，如果启用了按需，额外的 Grok Bot 用量可以作为**按需用量（On-demand usage）**继续。该额外用量通过 Cursor 计费，并计入**按需用量每月上限（On-demand monthly limit）**。参见[套餐和支出界面把什么称为用量？](#what-do-the-plan-and-spending-screens-call-usage)和[按需用量每月上限如何适用于 Grok Bot？](#how-does-the-on-demand-monthly-limit-apply-to-grok-bot)。

Grok Bot 用量在你的 Cursor 账号上计量，而不是在 Grok 或 X 上。SuperGrok 或 X Premium+ 关联在 SuperGrok 或 X Premium+ 保持活跃期间，为同一个 Cursor 账号授予 Grok Bot 用量。它不会在 Grok 或 X 上创建第二个计量器，也不会改变你的 Cursor 套餐。如果你同时有一个包含 Grok Bot 的 Cursor 套餐，两者不会相加。Grok Bot 使用其中每周用量更多的一个。参见 [Cursor 和 SuperGrok 套餐会叠加吗？](#do-cursor-and-supergrok-plans-stack)。

## Grok Bot 免费试用如何运作，我怎样高效使用？

Grok Bot 免费试用是一笔用量额度，而不是固定天数，不过 7 天窗口也同样适用。

这笔额度按你的智能体完成多少工作来扣减，以智能体步骤和 token 衡量，而不是你发送的消息数量。更大或更长的智能体任务消耗更多，所以额度能用多久取决于你如何使用它。

要让试用额度用得更久：

- 从小处开始，把任务范围收窄，然后在了解每个任务消耗多少后再扩大规模。
- 在运行大型或长时间智能体任务前，先在套餐界面查看你的用量。

## Grok Bot 用量在 macOS 和 iOS 之间共享吗？

是的。macOS 和 iOS 共享一个与你登录的 Cursor 账号绑定的用量桶。两个应用调用同一后端，因此你在 Mac 上看到的用量与 iOS 上显示的配额相同。

## 如果我的试用在一次运行中途用完怎么办？

试用是一笔用量额度，因此一个大型或长时间运行的智能体任务可能一次用掉大部分或全部额度。这是预期行为，已使用的试用额度不会恢复或补充。

要继续使用 Grok Bot，升级到 The X Subscription 的 **Premium**、**Super** 或 **Ultra**，或在旧版 Cursor 账号上升级到 **Cursor Pro**、**Cursor Pro+**、**Cursor Ultra** 或 **Cursor Teams** 套餐，或关联**个人 SuperGrok**、**SuperGrok Plus**、**SuperGrok Heavy** 或 **X Premium+** 账号。如果你在自助 **Grok Business** 套餐中拥有席位，退出后使用该 Grok 账号通过**使用 Grok 登录**重新登录。

参见[如何获得 Grok Bot 的访问权限？](#how-do-i-get-access-to-grok-bot)。要让额度用得更久，参见 [Grok Bot 免费试用如何运作，我怎样高效使用？](#how-does-the-grok-bot-free-trial-work-and-how-do-i-use-it-efficiently)。

如果一次运行因错误而失败，而不是结果不理想，请按[报告缺陷](https://cursor.com/help/troubleshooting/reporting-bugs)说明进行报告。

## 当我关联 SuperGrok 或 X Premium+ 时，我的 Cursor 套餐会怎样？

关联 SuperGrok 或 X Premium+ 是一种用量授予，而不是 Cursor 套餐。它不会改变或取消你的 Cursor 套餐。

- 如果你已经为 **Cursor Pro**、**Pro+** 或 **Ultra** 付费，该订阅在关联后保持不变。
- 如果你在 **Cursor Teams** 席位上，该席位在关联后保持不变。
- 如果你在关联前没有 Cursor 套餐，你仍然没有，Grok Bot 用量仅来自 SuperGrok 或 X Premium+ 授予。

SuperGrok 或 X Premium+ 关联一旦创建就是永久的。你无法解除关联，也无法将其移动到另一个 Cursor 账号，因此在关联前请使用正确的 Cursor 账号登录。关联步骤参见[为 Grok Bot 关联 SuperGrok](https://cursor.com/help/grok-bot/supergrok)。

## Cursor 和 SuperGrok 套餐会叠加吗？

不会。Cursor 套餐与 SuperGrok 或 X Premium+ 关联不会相加。Grok Bot 使用其中每周用量更多的一个。

**Pro**、**SuperGrok** 和 **X Premium+** 是同一档。**Pro+** 和 **SuperGrok Plus** 是同一档。**Ultra** 和 **SuperGrok Heavy** 是同一档。

- 如果你使用 **Pro** 并关联 **SuperGrok Plus**，Grok Bot 会移动到 Plus 档。
- 如果你使用 **Pro+**，关联 **SuperGrok Plus** 不会增加 Grok Bot 用量。它们属于同一档。
- 如果你已经关联了 **SuperGrok Heavy**，购买 **Cursor Ultra** 不会增加 Grok Bot 用量。
- 如果你使用 **Ultra**，关联任何 SuperGrok 套餐或 **X Premium+** 都不会增加 Grok Bot 用量。
- **Grok Business** 席位的工作方式与 SuperGrok 关联相同。它不会与 Cursor 套餐或 SuperGrok 关联相加。Grok Bot 使用其中授予更多的一个。

你也可以在 Cursor 套餐内升级。从 **Pro+** 移动到 **Ultra** 会把包含的 Grok Bot 用量提升到 Ultra 档。

你的 Cursor 订阅和你的 SuperGrok 或 X Premium+ 订阅可以同时保持活跃并各自继续计费。购买一个不会取消另一个。只是用量授予不合并。

当你的**每周用量上限**用完时，如果你的 Cursor 账号启用了[按需用量](https://cursor.com/help/account-and-billing/overages)，可以继续使用。按需是你在包含的授予之外获得更多 Grok Bot 用量的方式。如果你在 iOS 或 Android 应用中订阅，请在网页上启用按需。参见[移动订阅的按需用量](https://cursor.com/help/account-and-billing/on-demand-usage-for-mobile-subscriptions)。

## 套餐和支出界面把什么称为用量？

Grok Bot 设置和 Cursor 仪表板对同样的两个池使用不同的名称。

- 桌面端和手机上的**每周用量上限**是包含的用量。它每周重置。如果由 SuperGrok 套餐提供资金，**管理套餐（Manage Plan）**中出现 SuperGrok、SuperGrok Plus 或 SuperGrok Heavy 名称，表示该关联授予，而不是第二个 Cursor 套餐。
- Grok Bot 中的**按需用量**是每周用量用完后的额外用量。该行显示**通过 Cursor 计费（Billed through Cursor）**。
- Grok Bot 中的**按需用量每月上限**是该额外用量的上限。在网页上，同一上限称为**支出（Spending）**和**每月上限（Monthly Limit）**。

包含的每周用量不是每月上限。用尽每周用量不会让 Grok Bot 停止，前提是按需已开启。

## 如果我在已经关联后升级 SuperGrok 会怎样？

授予会跟随关联账号上的 SuperGrok 或 X Premium+ 套餐，但 Grok Bot 界面可能在一段时间内继续显示旧档位。

如果你在关联后将 SuperGrok 升级到 SuperGrok Plus 或 SuperGrok Heavy，请继续使用 Grok Bot。**每周用量上限**最多需要 24 小时才会移动到新档位。你无需重新关联，也不能通过解除关联来强制刷新。

你在等待期间购买的 Cursor 套餐不会增加到关联中。Grok Bot 使用其中每周用量更多的一个。参见 [Cursor 和 SuperGrok 套餐会叠加吗？](#do-cursor-and-supergrok-plans-stack)。

如果 24 小时后仍显示旧档位，请带上 Cursor 账号邮箱、Grok 账号邮箱和**每周用量上限**的截图[联系支持](https://cursor.com/help/grok-bot/get-help)。

## 按需用量每月上限如何适用于 Grok Bot？

Grok Bot 首先从你的**每周用量上限**中扣除。当包含的授予用完时，如果启用了按需，额外的 Grok Bot 用量会继续按需使用。该额外用量计入 Grok Bot 中的**按需用量每月上限**，这与网页上的**每月上限**是同一上限。

要开启或更改它：

1. 在 Grok Bot 中打开**设置（Settings）** > **用量与计费（Usage & Billing）**，找到**按需用量每月上限**。如果它处于关闭状态，选择**启用（Enable）**。
2. 如果 Grok Bot 要求提供银行卡，请在网页上完成。在浏览器中访问 [cursor.com/dashboard](https://cursor.com/dashboard)，打开**支出**，并设置**每月上限**。
3. 如果你在 iOS 或 Android 应用中订阅，请在网页上设置该上限。参见[移动订阅的按需用量](https://cursor.com/help/account-and-billing/on-demand-usage-for-mobile-subscriptions)。

上限不是运行中途的硬停止。已经在工作的 Bot 可以越过每月上限完成。之后，按需会停止，直到你提高上限或计费周期重置。保持上限不变不会增加更多包含的每周用量。

如果按需关闭，Grok Bot 会在每周用量用完时停止。界面会显示你已达到 Grok Bot 用量上限，并随每周用量一起重置。

## 如果我降级或我的 Teams 席位发生变化会怎样？

降级或席位变化会改变 Grok Bot 使用的单一授予。它不会与另一个套餐叠加。

- 降级 SuperGrok、SuperGrok Plus 或 SuperGrok Heavy 会在同样的刷新窗口内降低关联授予，最多 24 小时。本周已经花掉的用量仍然计入。如果你已经超过新档位，进一步的包含用量会停止。按需仅在启用时继续。
- 降级 Cursor 套餐，例如从 Ultra 到 Pro+，会以同样方式改变 Cursor 每周用量。如果你同时有 SuperGrok 关联，Grok Bot 使用两者中现在授予更多的一个。
- 在自助 Teams 套餐上，Grok Bot 跟随你所在的席位。更高的席位可以提高每周用量。更低的席位会降低它。你不需要单独的 SuperGrok 关联。关联不会增加到席位中。Grok Bot 使用其中授予更多的一个。
- 如果管理员移除你的 Teams 席位，Teams 授予结束。该 Cursor 账号上已有的 SuperGrok 或 X Premium+ 关联不会变成更大的授予，也不会恢复 Teams 额度。
- 如果你的 Grok Business 管理员移除你的席位或更改其许可证，来自该席位的 Grok Bot 用量会结束或相应改变。

基于申请的 Teams 套餐和 Enterprise 席位不接受个人 SuperGrok 关联。这些套餐将 Grok Bot 保留在 Cursor 合同下。

## 如何取消我的 Grok Bot 试用？

取消不收费，Grok Bot 试用永远不会变成付费套餐。

**取消试用（Cancel Trial）**会出现在免费套餐账号上。在付费套餐或 Teams 席位上，试用会自行结束，无需取消。

在套餐界面使用**取消试用**。这会立即结束试用，移除任何剩余的试用额度，并且你无法再次领取试用。

如果你使用免费套餐，**取消试用**没有出现或取消未生效，请[联系支持](https://cursor.com/help/grok-bot/get-help)。

## 如何取消我在 iOS 应用中开始的免费试用？

App Store 的推介优惠与 Grok Bot 的用量额度试用不同。它由 Apple 运营，除非你先取消，否则试用结束后会变成付费的 Apple 订阅。

在试用结束前于 **Apple ID → 订阅（Subscriptions）**中取消。参见 Apple 的[查看和取消订阅](https://support.apple.com/guide/iphone/iph4e3e7324f/ios)指南。对于 Apple 应用内收费的退款，请使用 [Apple 的订阅与计费支持](https://support.apple.com/billing)。Cursor 无法替你取消或退款 Apple 应用内试用或订阅。

参见[如何管理或取消移动订阅？](https://cursor.com/help/grok-bot/mobile-purchase#how-do-i-manage-or-cancel-a-mobile-subscription)。Android 没有应用内试用。

## Grok Bot 的退款如何运作？

Grok Bot 没有单独的订阅，因此没有单独的退款路径。

**The X Subscription。** 付费访问是你 Premium、Super 或 Ultra 套餐的一部分。退款遵循 SpaceXSI 文档中的[发票与退款](https://docs.x.ai/x-subscription/invoices-and-refunds)。你已花掉的预付额度不可退款。

**旧版 Cursor 套餐。** 付费访问通过你的 Cursor 套餐（Pro、Pro+ 或 Ultra）计费。订阅退款资格遵循[退款](https://cursor.com/help/account-and-billing/refunds)。

这些 Cursor 收费不可退款：

- Grok Bot 已消耗的按需用量
- 带用量的周期中途降级（无按比例退款）

**商店购买。** Cursor 无法退还应用内商店收费：

- **iOS：** [Apple 的订阅与计费支持](https://support.apple.com/billing)
- **Google Play：** [Google Play 的退款支持](https://support.google.com/googleplay/answer/2479637)

**SuperGrok、Grok Business 和 X Premium+。** 符合条件的 Grok 账号是个人 SuperGrok、SuperGrok Plus、SuperGrok Heavy、X Premium+，以及自助 Grok Business 套餐中已分配的席位。这些订阅由 xAI 或 X 计费，而不是 Cursor。

- **SuperGrok：** 参见 [xAI 的常见问题](https://docs.x.ai/grok/faq#can-i-get-a-refund-for-my-grok-or-supergrok-subscription)
- **X Premium+：** 联系 X 获取退款
