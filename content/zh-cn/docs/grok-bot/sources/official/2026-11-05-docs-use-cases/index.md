**收集者摘要**：文档给出八类适合 Bot 承担的岗位及起始提示：销售外联、人才寻访、付费媒体、费用管理、产品性能、缺陷复现、客户健康度、幕僚长。每条提示都刻意在审核点前结束，如「只返回审阅清单，不发送、不登记」「不要修改预算或发送消息」，对外发送、发布、购买和生产变更要放在批准之后。建议先做只读和准备类工作，审阅结果，再增加经批准的动作或例程。把岗位变成长期 Bot 的六步为：在 Bot 描述中写明工作、系统、输出格式和边界；做一次真实的小范围任务；修正到无需你也可审阅；存为技能并用第二份输入测试；定义重试和失败情况后再建例程；让有后果的外部动作继续留在批准之后。

**保留理由**：给出官方推荐的岗位化用法和放权顺序，可与实际案例文章对照，看官方如何建议用户逐步放权。
