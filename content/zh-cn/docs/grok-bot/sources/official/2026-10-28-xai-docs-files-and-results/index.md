文件与结果

把源材料附加到一次请求中，并让 Bot 以你可以检查、编辑和交接的形式返回工作成果。

## 附加文件

使用附件控件，或把文件拖入输入区（composer）。你也可以粘贴图片和链接。

常见支持的输入包括：

* 图片、音频和视频
* PDF 与纯文本文档
* Word、Excel 和 PowerPoint 文件
* CSV、JSON、YAML 和源代码文件
* HTML 与电子邮件文件
* Jupyter notebook

在桌面应用中，你可以附加：

| 限制 | 值 |
| --- | --- |
| 每条消息的附件数 | 20 |
| 图片 | 每个 25 MB，每条消息合计 200 MB |
| 文档、音频和其他文件 | 每个 250 MB |
| 视频 | 每个 1 GB |

如果某个文件超过其限制，输入区会提示文件过大并将其略去；请把其余文件放在另一条消息中发送。大型、加密、损坏或格式不常见的文件可能无法读取；请把不常见的格式导出为 PDF、CSV、纯文本或图片。

在 iPhone 上，你还可以从其他应用把照片、文件、链接或文本分享到 Grok Bot。使用系统分享面板，选择 **Grok Bot**，选择一个聊天，然后选择 **Attach**。该项目会被添加到该对话的输入区。在 Android 上，分享面板目前只接受文本。参见 [Grok Bot for Mobile](https://docs.x.ai/grok-bot/mobile)。

告诉 Bot 每个附件是什么，以及它应如何使用：

> 这份 PDF 是已签署的政策。这张电子表格是本月的交易记录。请把电子表格与政策核对，为每一处例外引用相关政策章节，并返回一张新的电子表格以及一份简短摘要。不要修改原始文件。

## 分享链接

当 Bot 能从其计算机或某个已连接的应用访问页面时，粘贴链接即可。如果页面是私有的，请[通过计算机登录](https://docs.x.ai/grok-bot/computer-and-apps#take-over-for-a-sensitive-step)，或连接该应用。

消息和结果中的链接会在你的系统浏览器中打开；将鼠标悬停在链接卡片上会先显示预览。在输入凭据或批准外部操作之前，务必检查目标地址。

## 在你的应用之间搬运文件

当你连接了 Google Drive、OneDrive、SharePoint、Gmail 或 Outlook 后，Bot 可以在其计算机与这些账户之间搬运文件，而无需把文件内容粘贴到聊天中：

* 把它生成或下载的文件保存到 Google Drive、OneDrive 或 SharePoint，或将其附加到 Gmail 或 Outlook 草稿中。
* 把 Drive、OneDrive 或 SharePoint 中的文件，或电子邮件附件，取到它的计算机上进行处理。Google Docs、Sheets、Slides 和 Drawings 会以 `.docx`、`.xlsx`、`.pptx` 和 `.png` 文件的形式到达。

说明文件应放到哪里。保存到 Google Drive 时总会新建文件，即使已存在同名文件。OneDrive 和 SharePoint 会拒绝已存在的名称，除非你告诉 Bot 覆盖它。

## 要求可复核的结果

明确指定交付物（artifact）及其验收标准：

* 带标题和来源链接的文档
* 具有明确列和公式的电子表格
* 带演讲者备注的幻灯片
* 包含截图和日志的文件夹
* 尚未发送的消息草稿
* 先给出简短建议、随后附上依据证据

对于影响重大的工作，让 Bot 区分：

1. 在源系统中找到的事实
2. 假设或推断
3. 已完成的动作
4. 等待批准的动作
5. 未解决的问题

## 预览生成的工作成果

文件、图片、链接和工具结果会以卡片形式出现在对话中。打开卡片即可预览受支持的格式。随后你可以保存文件、打开来源链接，或带着反馈继续对话。

让 Bot 修改现有交付物，而不是制作彼此割裂的副本：

> 更新你刚创建的报告。为前两项论断添加来源链接，并把最后的表格替换为 CSV 附件。

## 创建图片和视频

Bot 可以创建图片和短视频片段。它只在你要求时才创建，依据是描述或你在对话中分享的图片。它制作的每张图片和每个视频都会发送到对话中，你可以在 Bot 的[资料库（Library）](#find-a-page-later)中再次找到它们。它创建的图片在其计算机休眠时仍能在对话中加载。

### 请求一张图片

用你自己的话描述你想要的内容，例如主体、风格和氛围。要在已有的图片基础上继续创作，请在对话中分享这些图片，并说明如何使用它们。Bot 会把它们用作参考。

图片可以是方形、宽幅或竖幅：1:1、4:3、3:4、16:9 或 9:16。图片创建不用于图表、绘图或表格；这些请改用[页面（page）](#pages)。

### 请求一个视频

请求一个视频、动画或片段。Bot 可以根据以下内容制作：

* 对场景的描述
* 你分享的一张图片，它将成为第一帧
* 你分享的两张图片，一张用于开始、一张用于结束。两张使用同一张图片即可制作循环。
* 最多 14 张参考图片，用来表明人物、物体、服装或场景应是什么样子

你还可以分享最多 4 张图片，它们必须出现在片段的特定时刻。

* 片段时长为 1 到 15 秒。默认为 6 秒。
* 除非你要求 720p，片段为 480p。
* 宽高比为 1:1、16:9、9:16、4:3、3:4、3:2 和 2:3。用你的图片制作的片段会保持该图片的形状，除非你要求其他比例。
* 你为视频分享的图片必须是 JPEG、PNG 或 WebP，且一个片段的所有图片合计可达约 35 MB。
* Bot 会把每个片段保存为 MP4 文件。

视频看起来像实拍。它们适合现场场景、让静态照片动起来，或参考图片中的角色。它们不适用于动态图形、标题卡、幻灯片、产品或应用演示、图表，或任何需要精确文字、时间或品牌素材的内容。创建视频可能需要几分钟。

当 Bot 把工作交给某个任务时，该任务也可以创建图片和视频，随后 Bot 会把它们发送到对话中。

### 如果 Bot 没有创建你想要的内容

* 为了向你展示真实人物、地点或产品的样子，Bot 会寻找真实图片，而不是创建图片。
* 有些请求会被内容规则阻止，发生这种情况时 Bot 会告诉你。提及受商标保护的角色、品牌或真实人物常常会导致阻止。请用你自己的话描述主体后重试。
* 如果图片创建正忙，Bot 可能会让你稍后重试。
* 如果 Bot 说你的账户无法使用图片或视频生成，说明创建功能已对你关闭。在团队中，管理员的模型设置或团队的隐私设置可能导致此情况。请询问你的管理员。

### 查看、保存和复制图片与视频

在桌面应用中：

* 点击图片或视频缩略图可全屏打开。在此处点击图片可放大。当有多于一个项目时，使用左右方向键或缩略图在它们之间切换。点击顶部的下载按钮保存该项目。按 Escape、点击关闭按钮，或点击图片外部即可关闭查看器。
* 视频播放器有播放和暂停、进度条，以及包含 **2×**、**1.5×**、**1×** 和 **0.5×** 的速度菜单。
* 右键点击图片并选择 **Copy image** 或 **Save image…**，或右键点击视频并选择 **Save video…**。
* 将鼠标悬停在消息上并点击三个点。选择 **Download**，当消息包含多个项目时选择 **Download all**。对于图片，你还可以选择 **Copy**。

在手机应用中：

* 点击图片可全屏打开。打开查看器的菜单，选择 **Forward** 将其发送到另一个聊天，或选择 **Share**、**Save**。
* 在对话中长按图片，可看到 **Copy Image** 和 **Save to Photos**。
* 点击视频可在对话中播放。长按它可看到 **Save to Photos**。

## 页面（Pages）

页面是 Bot 为你构建、供你阅读的内容，例如报告、备忘录、仪表盘、跟踪器或解释说明。它可以包含文本、表格、图表，以及筛选器和开关之类的控件。页面存放在 Bot 的资料库中，因此你可以稍后回来查看并分享它。

Pages 正在逐步推出，目前在企业版团队中尚不可用。如果你看不到页面，请把计算机上的 Grok Bot 更新到 0.60.0 或更高版本，把手机上的更新到 1.14.0 或更高版本。

要制作页面，请在聊天中向 Bot 提出请求。说明页面的用途以及其中应包含什么，例如：

> 制作一个页面，比较本线程中的三份报价，包含一个表格和一条简短建议。

> 为过去 30 天的注册、试用和转化构建一个仪表盘。

> 创建一个发布跟踪器，整理未完成的任务、负责人和状态。

Bot 会构建页面，并把它作为一张带有页面标题和 **Open** 的卡片发布到聊天中。你也可以让 Bot 通过[例程（routine）](https://docs.x.ai/grok-bot/skills-routines-and-automations)创建或更新页面。

### 打开页面

在桌面应用中，点击对话中页面的卡片即可打开。页面会占满窗口，聊天则保持在旁边一个较小的面板中打开，因此你可以在阅读的同时继续与 Bot 交谈。

当 Bot 更新页面时，聊天中较早的卡片会显示 **Updated below**。点击它可打开最新版本。

在手机应用中，点击页面的卡片即可打开。点击关闭按钮返回对话。

### 修改页面

向 Bot 提出请求。页面打开时，在旁边聊天面板中输入，该面板标有 **Message about** 和页面标题。Bot 会编辑同一个页面，因此所有能打开它的人都会看到更改。

页面上的筛选器、开关和其他控件改变的是你看到的内容，而不是页面所保存的内容。你在页面上做的任何操作都不会被保存。要改变页面本身，请让 Bot 来做。

要重命名你制作的页面，点击打开页面顶部的标题，输入新名称，然后按 Enter。按 Escape 保留旧名称。

### 稍后找到页面

在桌面应用中，按 `Cmd/Ctrl+K` 并输入页面标题即可找到它。

每个 Bot 还都有一个**资料库（Library）**。点击聊天顶部的 Bot 名称（**View conversation details**），然后打开 **Library** 标签页。它会列出 Bot 制作的页面、文件和应用，以及它在你的对话中发送的图片、视频和链接，按 **Today**、**This week** 和 **Older** 分组，最新的在前。你发送的内容（包括你上传的图片）以及 Cloud Agent 返回的文件不会列出。每组一次显示五个项目；点击 **Show more** 查看更多。在手机上，点击聊天顶部的 Bot 名称打开其个人资料，然后点击 **Library**。

* 点击页面可打开它。点击图片或视频可全屏查看，点击文件可预览，点击链接可在浏览器中打开。
* 你与团队或任何拥有链接的人分享过的页面，其所在行会显示一个标记。
* 点击行上的 **More actions**（三个点），选择 **Pin** 可将该项目固定在资料库顶部的 **Pinned** 下。选择 **Unpin** 可取消固定。页面的菜单还包含 **Open**，对于你拥有的页面还有 **Share…**。

### 分享页面

新页面在你分享之前只对你私有。你可以更改谁能查看你拥有的页面。

* 在桌面应用中，打开页面并点击顶部的 **Share**，或从资料库中页面的菜单选择 **Share…**。点击当前设置，并选择谁可以查看页面。
* 在手机应用中，打开页面，点击分享按钮，并在 **Who can view** 下选择一个选项。

| 选项 | 谁可以打开页面 |
| --- | --- |
| **People you invite** | 你以及你添加的队友和群组。每个人获得 **Viewer** 访问权限；打开该设置并选择 **Remove** 可将某人移除。在个人账户上，此选项为 **Only you**。 |
| 你的团队名称，或 **Your team** | 你的 Cursor 团队中的所有人。 |
| **Anyone with the link** | 任何人，无需登录。 |

有些团队还会看到面向其组织中所有人的选项。打开团队链接或邀请链接的人需要先使用其 Cursor 账户登录。你分享给的每个人都可以阅读页面并使用其控件；只有 Bot 能修改它。要与更少的人分享页面，请再次打开 **Share** 并选择范围更窄的选项，或从你的[仪表盘](#see-pages-youve-shared)中更改。

当某个选项不可用时，分享菜单会说明原因：

| 你看到的 | 它的含义 |
| --- | --- |
| **Public sharing is off for Enterprise teams** | 你的团队使用 Enterprise 套餐。请改为与团队或你邀请的人分享页面。 |
| **Pages in your personal space can't be team-shared** | 该页面属于你的个人账户，而不是团队。请保持其私有，或与任何拥有链接的人分享。 |
| **Couldn't update access** | 更改未保存。请重试。 |
| **This page's access changed. Make your change again.** | 在你打开菜单期间，有人更改了谁可以查看该页面。请重新进行你的更改。 |

要发送链接，请使用桌面分享菜单底部的 **Copy link**，或手机分享屏幕顶部的 **Copy link**。桌面菜单还有 **Open in browser**。在手机应用中，一旦除你之外有人能打开页面，分享屏幕还会有 **Share**（打开手机的分享面板）和 **Open in browser**。

你与任何拥有链接的人分享的页面，会以基于页面标题的独立地址在 `pages.grok.bot` 上打开。任何拥有该地址的人无需登录即可打开页面，因此仅当页面不含任何私密内容时才以这种方式分享。重命名页面后地址保持不变，且你目前无法选择自定义地址。在手机应用中，地址位于 **Address** 下；点击即可复制。企业版团队关闭了公开分享；使用个人账户，或在非 Enterprise 套餐的团队中，你可以与任何拥有链接的人分享页面。

如果更改未保存，请选择 **Retry**。

### 查看你分享过的页面

要查看你分享过的所有页面，请打开 [Cursor 仪表盘](https://cursor.com/dashboard/shared-canvases)并找到 **Grok Bot Pages**。每一行显示 **Page**、其 **Visibility** 和 **Date**。点击一行可打开页面，或使用 **Visibility** 更改谁可以查看它。

点击行上的三个点，可进行 **Copy Link** 或 **Delete**。当你删除页面时，任何拥有链接的人都会失去访问权限。

## 来自 Cloud Agent 的结果

Bot 可以把编码工作交给 [Cloud Agent](https://docs.x.ai/grok-bot/teams-and-enterprises#cloud-agents)。当 Cloud Agent 完成时，Bot 会把 Cloud Agent 最终报告中引用的图片、视频和其他文件复制到其计算机，并附加到回复中。在桌面应用中，对话中 Cloud Agent 的卡片会显示相同的文件；打开图片或视频可全屏查看。

在手机应用中，一旦运行处于 **Done**、**Error** 或 **Expired** 状态，Cloud Agent 的卡片就会显示相同的文件：先是图片，然后是视频，最后是其他文件。点击图片可全屏查看，点击视频可播放，点击其他文件可打开手机的分享面板。如果文件无法加载，请点击 **Retry**。如果该运行打开了拉取请求且尚未过期，**View PR** 会打开它。**Open in Cursor** 会在 Cursor 应用或网页中打开该运行。

## 保留证据

有力的结果应当可以被独立复核。视任务而定，要求提供：

* 直接来源链接
* 显示相关状态的截图
* 时间戳和时区
* 输入和输出文件名
* 简明的操作日志
* Bot 无法核实的事项的明确清单

对于快速变化的数据，不要只依赖截图。尽可能保留来自源系统的链接或导出文件。

## 共享的计算机文件

Bot 可以读取其他 Bot 保存在 `/workspace` 中的文件。使用项目文件夹和描述性名称，让交接更可靠。

共享工作区适合存放中间材料，但对话中仍应包含最终结果或指向它的明确链接。关于持久化和恢复的细节，参见[使用计算机和应用](https://docs.x.ai/grok-bot/computer-and-apps)。
