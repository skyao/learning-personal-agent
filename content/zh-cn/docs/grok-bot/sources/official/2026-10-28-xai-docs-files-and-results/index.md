文件与结果

把资料附在请求里，并要求 Bot 以你能检查、编辑和交接的形式交回工作成果。

## 附加文件

使用附件控件，或把文件拖进输入框。你也可以粘贴图片和链接。

常见的受支持输入包括：

* 图片、音频和视频
* PDF 和纯文本文档
* Word、Excel 和 PowerPoint 文件
* CSV、JSON、YAML 和源代码文件
* HTML 和邮件文件
* Jupyter 笔记本

在桌面应用中，你可以附加：

| 限制 | 值 |
| --- | --- |
| 每条消息的附件数 | 20 |
| 图片 | 每个 25 MB，每条消息合计 200 MB |
| 文档、音频和其他文件 | 每个 250 MB |
| 视频 | 每个 1 GB |

如果某个文件超出限制，输入框会提示它太大并把它排除；把其余的分到另一条消息发送。体积大、加密、损坏或格式少见的文件可能无法读取；请把少见的格式导出为 PDF、CSV、纯文本或图片。

你也可以从手机上的其他应用分享：iPhone 上的照片、文件、链接或文字，或 Android 上的文字、照片、视频、音频或 PDF。使用系统分享面板，选择 **Grok Bot**，在**收件人（To:）**中选择一个 Bot，可选**添加备注（Add a note）**，然后选择**发送（Send）**。见 [Grok Bot 移动版](https://docs.x.ai/grok-bot/mobile)。

告诉 Bot 每个附件是什么、应该怎么用：

> 这份 PDF 是已签署的政策。这个电子表格是本月的交易。把电子表格与政策核对，为每个例外引用相关的政策条款，交回一个新的电子表格加一份简短摘要。不要修改原件。

## 分享链接

当 Bot 能从它的计算机或已连接的应用访问该页面时，粘贴链接即可。如果页面是私有的，[通过计算机登录](https://docs.x.ai/grok-bot/computer-and-apps#take-over-for-a-sensitive-step)或连接该应用。

消息和结果中的链接在你的系统浏览器中打开；悬停在链接卡上会先显示预览。在输入凭据或批准对外操作之前，一定要先确认目标地址。

## 在你的应用之间搬运文件

当你连接了 [Google Drive](https://x.ai/bot/plugin/45893413)、[OneDrive](https://x.ai/bot/plugin/57302028)、SharePoint、[Gmail](https://x.ai/bot/plugin/45893410) 或 [Outlook](https://x.ai/bot/plugin/57302029) 后，Bot 可以在它的计算机与这些账号之间搬运文件，而不必把文件内容粘贴进聊天：

* 把它制作或下载的文件保存到 [Google Drive](https://x.ai/bot/plugin/45893413)、[OneDrive](https://x.ai/bot/plugin/57302028) 或 SharePoint，或附加到 [Gmail](https://x.ai/bot/plugin/45893410) 或 [Outlook](https://x.ai/bot/plugin/57302029) 草稿。
* 把 [Google Drive](https://x.ai/bot/plugin/45893413)、[OneDrive](https://x.ai/bot/plugin/57302028) 或 SharePoint 中的文件，或一封邮件的附件，取到它的计算机上处理。Google 文档、表格、幻灯片和绘图会以 `.docx`、`.xlsx`、`.pptx` 和 `.png` 文件的形式送达。

说明文件应该放到哪里。保存到 [Google Drive](https://x.ai/bot/plugin/45893413) 总是新建文件，即使已存在同名文件。[OneDrive](https://x.ai/bot/plugin/57302028) 和 SharePoint 会拒绝已存在的名称，除非你让 Bot 覆盖它。

## 要求可审阅的结果

明确交付物及其验收标准：

* 一份带标题和来源链接的文档
* 一份有明确列和公式的电子表格
* 一份带演讲者备注的幻灯片
* 一个装有截图和日志的文件夹
* 一条尚未发送的消息草稿
* 一份简短建议，后附支撑证据

对于后果重大的工作，要求 Bot 分开列出：

1. 在源系统中查到的事实
2. 假设或推断
3. 已完成的操作
4. 等待批准的操作
5. 未解决的问题

## 预览生成的工作

文件、图片、链接和工具结果以卡片形式出现在对话中。打开卡片可以预览受支持的格式。然后你可以保存文件、打开来源链接，或带着反馈继续对话。

要求 Bot 修订现有交付物，而不是另建互不相干的副本：

> 更新你刚创建的报告。给前两个论断加上来源链接，并把最后的表格换成一份 CSV 附件。

## 创建图片和视频

Bot 可以创建图片和短片。它只在你要求时创建，依据一段描述或你在对话中分享的图片。它把自己制作的每张图片和每段视频发到对话中，你也可以在 Bot 的[资料库](#find-a-page-later)里再次找到它们。即使它的计算机处于休眠状态，它创建的图片仍能在对话中加载。

### 要求一张图片

用你自己的话描述你想要什么，例如主体、风格和氛围。要在已有图片的基础上制作，请在对话中分享它们并说明如何使用。Bot 会把它们用作参考。

图片可以展示真实或虚构的人物，包括你自己：分享一张你自己的照片，然后例如要求看看某套服装穿在你身上的样子。对于知名人物、产品或地点，Bot 会先找一张真实照片作为参考。

图片可以是方形、宽幅或竖幅：1:1、4:3、3:4、16:9 或 9:16。图片创建不用于图表、绘图或表格；这些请要求生成[网页](#pages)。

### 要求一段视频

要求一段视频、动画或短片。Bot 可以依据以下内容制作：

* 对场景的描述
* 你分享的一张图片，它成为首帧
* 你分享的两张图片，一张用于开头、一张用于结尾。两张用同一张图片可以做成循环。
* 最多 14 张参考图，用来展示人物、物体、服装或场景应有的样子

你还可以分享最多 4 张必须在片段特定时刻出现的图片。

* 片段时长 1 到 15 秒。默认为 6 秒。
* 除非你要求 720p，片段为 480p。
* 宽高比为 1:1、16:9、9:16、4:3、3:4、3:2 和 2:3。用你的图片制作的片段会保持该图片的形状，除非你要求其他比例。
* 为视频分享的图片必须是 JPEG、PNG 或 WebP，一段片段的全部图片合计最多约 35 MB。
* Bot 把每段片段保存为 MP4 文件。

视频看起来像实拍。它们适合现场场景、让静态照片动起来，或你参考图中的角色。它们不适合动态图形、标题卡、幻灯片、产品或应用演示、图表，以及任何需要精确文字、时序或品牌素材的内容。创建一段视频可能需要几分钟。

当 Bot 把工作交给某个任务时，该任务也可以创建图片和视频，随后由 Bot 把它们发到对话中。

### 如果 Bot 没有创建你要的内容

* 为了向你展示真实的人物、地点或产品长什么样，Bot 会找一张真实图片，而不是创建一张。如果找不到，它会告诉你，而不是创建图片。
* 有些请求会被内容规则拦截，发生这种情况时 Bot 会告诉你。点名受商标保护的角色、品牌或真实人物常常会导致拦截。用你自己的话描述对象再试一次。
* 如果图片创建繁忙，Bot 可能请你稍后再试。
* 如果 Bot 说你的账号无法使用图片或视频生成，说明创建功能已对你关闭。在团队中，管理员的模型设置或团队的隐私设置可能导致这种情况。请联系你的管理员。

### 查看、保存和复制图片与视频

在桌面应用中：

* 点击图片或视频缩略图可全屏打开。在那里的图片上点击可放大。有多个项目时，用左右方向键或缩略图在它们之间切换。点击顶部的下载按钮保存该项目。按 Escape、点关闭按钮或点击图片外侧可关闭查看器。
* 视频播放器有播放和暂停、进度条，以及带 **2×**、**1.5×**、**1×** 和 **0.5×** 的速度菜单。
* 右键点击图片并选择**复制图片（Copy image）**或**保存图片……（Save image…）**，或右键点击视频并选择**保存视频……（Save video…）**。
* 悬停在一条消息上并点击三个点。选择**下载（Download）**，消息中有多个项目时则选择**下载全部（Download all）**。对于图片，你还可以选择**复制（Copy）**。

在手机应用中：

* 点一下图片可全屏打开。打开查看器的菜单，选择**转发（Forward）**把它发到另一个聊天，或选择**分享（Share）**、**保存（Save）**。
* 按住对话中的图片，可看到**复制图片（Copy Image）**和**存储到照片（Save to Photos）**。
* 点一下视频可在对话中播放。按住它可看到**存储到照片**。

## 网页

网页是 Bot 为你构建、供你阅读的内容，例如报告、备忘录、仪表盘、跟踪表或讲解。它可以包含文字、表格、图表，以及筛选器和开关之类的控件。网页存放在 Bot 的资料库中，因此你可以之后回来看它，也可以分享它。

网页功能正在逐步推出，企业版团队暂不可用。如果你看不到网页，请把电脑上的 Grok Bot 更新到 0.60.0 或更高版本，手机上的更新到 1.14.0 或更高版本。

要生成网页，在聊天中请求 Bot。说明网页的用途和上面应该有什么，例如：

> 做一个网页，比较这个线程里的三份报价，带一个表格和一段简短建议。

> 做一个仪表盘，显示过去 30 天的注册、试用和转化。

> 创建一个发布跟踪表，整理未完成的任务、负责人和状态。

Bot 构建该网页，并以卡片形式发在聊天中，卡片上有网页标题和**打开（Open）**。你也可以让 Bot 从[例程](https://docs.x.ai/grok-bot/skills-routines-and-automations)创建或更新网页。

### 打开网页

在桌面应用中，点击对话中网页的卡片即可打开。网页占满窗口，聊天留在旁边一个较小的面板中，因此你可以在阅读时继续与 Bot 交谈。

当 Bot 更新网页时，聊天中较早的卡片会显示**已在下方更新（Updated below）**。点击它可打开最新版本。

在手机应用中，点网页卡片即可打开。点击关闭按钮回到对话。

### 修改网页

告诉 Bot。网页打开时，在它旁边的聊天面板中输入，面板标有**就此发消息（Message about）**和网页标题。Bot 编辑的是同一个网页，所以每个能打开它的人都会看到改动。

网页上的筛选器、开关和其他控件改变的是你看到的内容，而不是网页本身保存的内容。你在网页上做的任何操作都不会被保存。要改变网页本身，请告诉 Bot。

要重命名你创建的网页，点击打开网页顶部的标题，输入新名称，按 Enter。按 Escape 保留旧名称。

### 之后找到网页

在桌面应用中，按 `Cmd/Ctrl+K` 并输入网页标题即可找到它。

每个 Bot 还有一个**资料库（Library）**。点击聊天顶部的 Bot 名称（**查看对话详情（View conversation details）**），打开**资料库**标签页。它列出该 Bot 制作的网页、文件和应用，以及它在你对话中发送的图片、视频和链接，按**今天（Today）**、**本周（This week）**和**更早（Older）**分组，最新的在前。你发送的内容（包括你上传的图片）和 Cloud Agent 返回的文件不会列出。每组每次显示五项；点击**显示更多（Show more）**查看更多。在手机上，点聊天顶部的 Bot 名称打开它的资料页，再点**资料库**。

* 点击网页可打开它。点击图片或视频可全屏查看，点击文件可预览，点击链接可在浏览器中打开。
* 你分享给团队或分享给任何持链接者的网页，会在其行上显示标记。
* 点击某行上的**更多操作（More actions）**（三个点），选择**置顶（Pin）**可把该项目留在资料库顶部**已置顶（Pinned）**之下。选择**取消置顶（Unpin）**可移出。网页的菜单还有**打开**，你拥有的网页还有**分享……（Share…）**。
* 在桌面应用中，选择列表上方的类型，例如**网页（Pages）**、**媒体（Media）**、**链接（Links）**、**文件（Files）**、**应用（Apps）**或**已置顶**，可只显示该类内容。选择**全部（All）**可重新看到所有内容。

在 [Team Bot](https://docs.x.ai/grok-bot/team-bots) 上，桌面端资料库把 Bot 为你制作的内容列在**仅你可见（Private to you）**下，把你团队共享的网页和 Bot 自己的文件列在**Bot 的文件（Bot's files）**下。没有**已置顶**标题：悬停在**仅你可见**中的某一行上并点击它的置顶图标，可把它留在顶部。该行置顶期间会一直显示置顶图标；再次点击可取消置顶。

### 分享网页

新网页在你分享之前仅你可见。你可以更改谁能查看你拥有的网页。

* 在桌面应用中，打开网页并点击顶部的**分享（Share）**，或在资料库中从网页的菜单选择**分享……**。点击当前设置，选择谁能查看该网页。
* 在手机应用中，打开网页，点分享按钮，在**谁可以查看（Who can view）**下选择一个选项。

| 选项 | 谁能打开该网页 |
| --- | --- |
| **你邀请的人（People you invite）** | 你以及你添加的队友和群组。每个人都获得**查看者（Viewer）**权限；打开该项并选择**移除（Remove）**可去掉某人。在个人账号上，此选项为**仅你（Only you）**。 |
| 你团队的名称，或**你的团队（Your team）** | 你 Cursor 团队中的所有人。 |
| **任何持有链接的人（Anyone with the link）** | 任何人，无需登录。 |

有些团队还会看到面向其组织内所有人的选项。打开团队链接或邀请链接的人需先用 Cursor 账号登录。你分享给的每个人都能阅读该网页并使用其控件；只有 Bot 能修改它。要以更少的人分享网页，再次打开**分享**并选择更窄的选项，或从你的[控制台](#see-pages-youve-shared)更改。

某个选项不可用时，分享菜单会说明原因：

| 你看到的 | 含义 |
| --- | --- |
| **企业版团队已关闭公开分享（Public sharing is off for Enterprise teams）** | 你的团队使用企业版套餐。请改为与团队或与你邀请的人分享该网页。 |
| **个人空间中的网页不能分享给团队（Pages in your personal space can't be team-shared）** | 该网页属于你的个人账号，而不是某个团队。请保持私有，或与任何持链接者分享。 |
| **无法更新访问权限（Couldn't update access）** | 改动没有保存。请重试。 |
| **此网页的访问权限已变更。请重新操作。（This page's access changed. Make your change again.）** | 你打开菜单期间有人改了谁能查看该网页。请重新操作。 |

要发送链接，使用桌面端分享菜单底部的**复制链接（Copy link）**，或手机分享屏幕顶部的同一按钮。桌面端菜单还有**在浏览器中打开（Open in browser）**。在手机应用中，一旦除你之外有人能打开该网页，分享屏幕还会有**分享**（打开手机的系统分享面板）和**在浏览器中打开**。

与任何持链接者分享的网页会在 `pages.grok.bot` 上以它自己的地址打开，地址基于网页标题生成。任何拿到该地址的人无需登录即可打开网页，所以只有网页不含私密内容时才这样分享。重命名网页后地址保持不变，目前还不能自定义地址。在手机应用中，地址在**地址（Address）**之下；点它可复制。企业版团队关闭了公开分享；使用个人账号，或在非企业版套餐的团队中，你可以与任何持链接者分享网页。

如果改动没有保存，选择**重试**。

### 查看你分享过的网页

要查看你分享过的所有网页，打开 [Cursor 控制台](https://cursor.com/dashboard/shared-canvases)，找到 **Grok Bot Pages**。每行显示**网页（Page）**、它的**可见性（Visibility）**和**日期（Date）**。点击一行可打开该网页，或用**可见性**更改谁能查看它。

点击行上的三个点，可**复制链接（Copy Link）**或**删除（Delete）**。删除网页后，任何持链接者都会失去访问权限。

## Cloud Agents 的结果

Bot 可以把编码工作交给 [Cloud Agent](https://docs.x.ai/grok-bot/teams-and-enterprises#cloud-agents)。Cloud Agent 完成后，Bot 会把 Cloud Agent 最终报告中引用的图片、视频和其他文件复制到它的计算机，并附加到回复中。在桌面应用中，对话里 Cloud Agent 的卡片也显示这些文件；打开图片或视频可全屏查看。

在手机应用中，运行状态为**完成（Done）**、**错误（Error）**或**已过期（Expired）**后，Cloud Agent 的卡片显示这些文件：先图片，再视频，然后是其他文件。点图片可全屏查看，点视频可播放，点其他文件可打开手机的系统分享面板。如果某个文件加载不出来，点**重试（Retry）**。如果该次运行发起了拉取请求且尚未过期，**查看 PR（View PR）**会打开它。**在 Cursor 中打开（Open in Cursor）**会在 Cursor 应用或网页中打开该次运行。

## 保留证据

有力的结果应当可以被独立复核。视任务而定，要求提供：

* 直接的来源链接
* 能看到相关状态的截图
* 时间戳和时区
* 输入和输出文件名
* 简明的操作日志
* 明确列出 Bot 无法核实的所有内容

对于快速变化的数据，不要只依赖截图。尽可能保留来自源系统的链接或导出文件。

## 共享的计算机文件

Bot 可以读取其他 Bot 保存在 `/workspace` 中的文件。使用项目文件夹和描述性的名称，让交接更可靠。

共享工作区适合存放中间材料，但对话中仍应包含最终结果或指向它的明确链接。持久化和恢复的细节见[使用计算机和应用](https://docs.x.ai/grok-bot/computer-and-apps)。
