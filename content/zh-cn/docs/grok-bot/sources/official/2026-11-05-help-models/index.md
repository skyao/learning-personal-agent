**收集者摘要**：Grok Bot 不绑定单一模型，每个任务用它认为最可能得到最佳结果的后端模型，可以是 xAI 自家模型，也可以是子处理方名单上的第三方模型，同一用户的不同请求可能不同。用户看不到某个请求实际用了哪个模型，用量和支出界面统一记作 Grok Bot 用量；用户不能指定、请求或屏蔽某个模型，设置里也没有模型选择器。团队的 Cursor 模型允许列表或屏蔽列表对 Grok Bot 无效，启用时会显示相关提示。文中答复称，把任务路由到 Opus 5.5 不会改变每个 token 的价格。只有子处理方名单上的服务商才能处理数据。

**保留理由**：这是官方对模型选择方式的说明，说明模型不可见、不可选，且可能含第三方模型，对判断其模型层的透明度和合规影响有用。
