**「如果世界只剩一个前台，那是悲哀的。」**

今年 9 月以来，Instinct、Muse 等 Personal Agent（个人 AI 助理）产品陆续爆火，一度被生产力主流淹没的 AI to C 领域再起变化。10 月 27 日，蚂蚁灵光 2.0 全量上线，给出新的明确定位：Personal Agent。

但灵光不是一个新产品。2025 年 11 月 18 日，灵光 1.0 发布，将近一年后，它从之前很多人印象里的 Coding Agent 走到了 Personal Agent。

“这是‘什么火做什么’吗？”我们的访谈直接从这个问题开始。

蚂蚁集团副总裁、灵光产品负责人蔡伟描述了变化背后贯穿的线索：从 1.0 开始，灵光就明确面向 C 端用户，想提升个人在工作和生活中的效率。做出一款国民级 To C 产品，也是蔡伟的执念之一。

15 年前的 2011 年，在美国读博的蔡伟退学创业，开始第一次 AI To C 尝试：用视觉搜索匹配服装、鞋包等时尚品，类似后来淘宝推出的“拍立淘”。那时后来改变行业的 AlexNet 还没有出现。

公司被 Pinterest 收购后，蔡伟进入 Google，先后参与开发了 Google Photos 和 Google Lens 两款拥有数亿用户的 AI 产品。

此后，蔡伟回国、创业、投资。2024 年，他加入蚂蚁，在这一轮大模型热潮中，他看到了一种做出 AI 大 C 端产品的新可能性。

这期节目，蔡伟和我们一起回顾了今年春节以来，灵光团队对 2.0 产品的定义过程，他们在 6 个多月的开发过程中的坑和经验；我们也一起讨论了即将到来的更加激烈的个人 Agent 竞争。

从灵光发布以来的初步反馈中，蔡伟说，他更相信个人 Agent 未来会成为国民级的应用，虽然它不一定是我们现在看到的形态。

但同时他提到，个人 Agent 成为一个超级统一入口，所有目前存在的前端应用、超级 App 都被颠覆乃至消失的未来，也不太可能发生。

这甚至是一种悲哀的未来，它背后是一套极致追求效率的假设。而这不是他设想中，AI 与人最好的相处方式。

**附录：本期出现的产品、技术术语等**

* **蚂蚁百灵大模型**：蚂蚁集团自研的基础模型体系，也是灵光背后的模型底座。本期蔡伟提到，灵光团队与百灵团队从预训练、中期训练到后训练保持强耦合，以便围绕 Personal Agent 的工具调用、任务规划、效果、性能和成本共同优化。
* **Ling 系列：**百灵旗下的通用大语言模型产品线，采用 MoE 架构，覆盖从轻量模型到万亿参数模型。代表模型包括 Ling-1T、Ling-2.6-1T，以及侧重真实任务效率和性价比的 Ling-3.x Flash 系列。
* **Ring 系列：**百灵旗下的思考模型产品线，面向数学、推理和复杂问题求解。代表模型包括 Ring-1T、Ring-2.6-1T。
* **Ming 系列：**百灵旗下的多模态模型产品线，覆盖文本、图像、音频和视频的理解与生成，包括图像生成、语音识别和语音合成等模型。
* **Agent Runtime：**智能体的运行与调度层，负责决定何时调用什么工具、如何推进任务，以及如何响应时间、事件和状态变化。相比一次性问答，持续管理事项需要更复杂的任务状态、权限和触发机制。
* **云主机（Cloud VM）：**运行在云端的虚拟计算环境，让 Personal Agent 在用户退出对话后仍能持续执行和调度任务。本期提到的“独立云主机”主要强调不同用户的任务与数据相互隔离，并不意味着每位用户独占一台物理服务器；底层计算资源仍可以采用资源池方式调度。
* **APASS：**蚂蚁用于智能体授权与安全管理的体系。灵光 2.0 通过授权密钥与 Agent 分离托管等机制，让智能体执行任务时不直接接触用户密钥，用户也可以查看、调整或撤销授权。
