Autopilot 如何审查操作

[本文为预发布文档，可能变更。]

重要

- 使用 Autopilot（Frontier）需要完成相应的 **[Frontier 预览计划](https://adoption.microsoft.com/copilot/frontier-program/)** 注册、预览分配并接受参与条款。仅注册 Frontier 并不会启用每一项预览功能。Frontier 预览受你的客户协议中适用的预览条款约束，其可用性与功能可能变化。
- 此功能处于预览阶段。
- 预览功能可能功能受限，且可能不会正式发布。这些功能在正式发布之前提供，以便客户提前使用并提供反馈。
- 更多信息，请参阅我们的 [Microsoft 产品条款](https://www.microsoft.com/licensing/terms/product/ForOnlineServices/MCA)。

Autopilot 使用第二个 AI 模型，在操作运行前审查 Autopilot 的操作。它把每个操作与你提出的请求比对，包括你的请求明确隐含的步骤以及你设定的任何限制，例如「只读」或「先别发」。无论 Autopilot 以你的身份行事还是以自己的身份行事，规则相同。

| 操作类型 | 会发生什么 |
| --- | --- |
| 读取、搜索与起草 | 不中断运行。这类操作中有一小部分会被抽查。 |
| 发送、分享、删除或更改邮件、日历、文件、聊天或其他应用中的内容；创建或更改自动化 | 由自动审查系统决定。如果操作与你的请求匹配，则无需审批请求直接运行。如果不匹配，或自动审查系统无法检查，你会收到一张审批卡。 |
| 付款及其他敏感的浏览器步骤 | 始终需要你批准，即使你提出了该操作。 |

只有你自己的消息才算请求。出现在电子邮件、文档或网页中的指令不构成对操作的授权，即使它们声称来自你。Autopilot 不会要求你在聊天中回复以确认操作。如果你自行批准了一份草稿，例如写下「看着不错，发吧」，系统会把它当作你的请求。

当你设置自动化时，自动审查系统会把该自动化与你的请求比对。在运行期间，它会把每一步与该自动化保存的指令比对。如果有一步不符，审批卡会出现在该自动化的投递聊天中。某些周期性权限始终需要你审查，即使检查建议批准。

本版本中，自动审查系统没有面向用户或管理员的设置。

### 设置权限

你的指令、已授权账户、操作权限和组织策略约束着 Autopilot 能做什么。Autopilot 可以在不必每一步都询问你的情况下完成任务。在它采取操作之前，自动检查会决定该操作可以继续，还是需要你的批准。

### 回应审批卡

审批卡会出现在你与 Autopilot 的 Teams 一对一聊天中。如果你是在 Microsoft Copilot 中提出的请求，卡片也会出现在那里，在一处作答会更新另一处。如果你在审批请求过期前没有回应，等待该批准的操作不会运行。任务的其余部分会在等待期间继续。一张卡可以覆盖多个相关操作。

每张卡会显示：

- 将会发生什么、会触达谁，包含每个人的姓名和电子邮件地址。你组织之外的人会标为**外部**。
- 将要发送的任何消息的只读预览。
- 你的请求，或自动化的名称。
- **查看更多**，显示技术细节，例如所使用的应用，以及 Autopilot 是以你的身份行事还是以自己的身份行事。
- 为什么询问你，付款及其他始终需要批准的操作除外。

| 卡片上的原因 | 含义 |
| --- | --- |
| 「此操作可能超出你所要求的内容。只有当它符合你的意图时才允许。」 | 该操作与你的请求不符。例如，它包含了一个额外的步骤，或一个你没有提到的收件人。 |
| 「在允许之前，请确认此操作与你所要求的内容一致。」 | 系统不确定该操作是否与你的请求相符。这在宽泛的请求中很常见，例如「清理我的收件箱」。 |
| 「安全检查未能完成。在允许之前请审查此操作。」 | 系统无法检查该操作。 |

回应方式：

1. 检查操作、收件人、目的地和执行账户。选择**查看更多**了解详情。
2. 选择**允许**以单次运行卡片上的所有内容，或选择**拒绝**取消。没有「始终允许」的选项，因此之后类似的操作会再次被检查。
3. 运行后检查结果。如果你拒绝了卡片或操作被阻止，不要把该请求当作已完成。

打开管理面板并选择**活动**，可与其他操作一起查看审批事件。条目可以标明操作是自动批准还是由你批准。批准不是完成的证明；请在目的位置核实结果。

Autopilot 可能把你的请求解释得比你本意更宽泛。例如，清理旧项目文件的请求可能影响的文件比你预期的更多。在允许某个操作之前，请精确检查涉及哪些文件、数据、人员和通信。

### 检查 Autopilot 设置

打开管理面板并选择**设置**。在这里可以找到**名称与外观**、查看**记忆**，以及在**计算机**下查看已列出的设备及其连接状态。
