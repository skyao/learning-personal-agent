**内容摘要**：微软 Responsible AI 应用卡，称 Autopilot 是 Microsoft Copilot 中常驻的云端智能体，面向在 Microsoft 365 中委派多步工作的信息工作者，仍为预览。文档给出术语表、能力清单（自动化、工作场所身份、记忆、技能与插件、Edge 浏览器使用、iOS/Android 移动访问）和预期用途，并说明运行于 GPT-6.1 Sol，关闭 OpenAI 后改用 Azure OpenAI 托管的 GPT-5.6 Sol。限制部分列出指令误读、自动审查可能出错、无法访问本地文件夹或应用、针对英语优化等；评估与缓解部分说明评估方法，并声明不发布定量通过率。

**保留理由**：提供官方对 Autopilot 能力边界、限制、评估方法与缓解措施（提示注入、动作授权）的自述，是其他资料里没有的安全与责任 AI 视角；也明确云端 Autopilot 不能访问本地文件夹或应用，与旧 Scout 桌面应用形成对照。
