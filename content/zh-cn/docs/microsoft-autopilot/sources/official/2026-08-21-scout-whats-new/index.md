本文列出 Microsoft Scout 近期的功能、改进和变更。有关 Microsoft Scout 能力的完整指南，请参阅[使用 Microsoft Scout](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout)。

## 2026 年 8 月

此版本为 Microsoft Scout 增加以下功能和改进。

### 新功能

| 功能 | 说明 | 了解更多 |
| --- | --- | --- |
| GitHub Enterprise Cloud 登录 | 在登录屏幕开启 **Use a GitHub Enterprise host**，以登录 GitHub Enterprise Cloud（例如 `your-org.ghe.com`）。 | [登录](https://learn.microsoft.com/en-us/microsoft-scout/get-started#sign-in) |
| Teams 会议转录和会议室 | 获取可用的 Teams 会议转录，并查找和预订会议室。 | [使用会议](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#retrieve-a-teams-meeting-transcript) |
| SharePoint Lists | 查看 SharePoint 列表的列和项，并创建或更新列表项。 | [使用 SharePoint Lists](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#work-with-sharepoint-lists) |
| Outlook 收件箱规则 | 列出、创建、更新、启用、禁用和删除 Outlook 收件箱规则。 | [管理 Outlook 收件箱规则](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#manage-outlook-inbox-rules) |
| 文件共享和访问 | 与特定人员共享 OneDrive 和 SharePoint 文件，设置查看或编辑权限，并查看当前谁拥有访问权限，具体取决于你的访问权限和组织政策。 | [共享文件并管理访问权限](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#share-files-and-manage-access) |
| 云端存储的 Co-Create 工作区 | 将 Co-Create 工作区存储在 OneDrive 或 SharePoint 中。 | [使用 Microsoft Scout 共同创作文件](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#co-create-files-with-microsoft-scout) |

### 改进

此版本改进了聊天交互、自动化调度、可靠性、可访问性和整体用户体验。

## 2026 年 7 月

此版本为 Microsoft Scout 增加以下功能和改进。选择 **Learn more** 了解详情。

### 新功能

| 功能 | 说明 | 了解更多 |
| --- | --- | --- |
| Co-Create 编辑器和文件类型 | Co-Create 新增 Markdown、源代码、结构化数据和 HTML 编辑器，并支持更多文件类型，包括 CSV 和 TSV、Mermaid 图表和 Excalidraw 绘图。你可以在 Markdown 编辑器中添加内联评论。 | [使用 Microsoft Scout 共同创作文件](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#co-create-files-with-microsoft-scout) |
| 模型和推理控制 | 选择对话的上下文窗口大小，包括 **Max** 选项；在 Settings 中设置默认推理强度；并为单条消息切换模型。 | [选择模型和推理强度](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#choose-a-model-and-reasoning-effort) |
| 缩短长对话 | 按需压缩长对话以腾出空间，同时保留重要上下文。 | [缩短长对话](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#shorten-a-long-conversation) |
| 整理聊天 | 按全部项目、聊天或自动化筛选聊天列表；固定聊天并重新排序；右键打开聊天的操作菜单；将对话标记为未读。 | [整理聊天](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#organize-your-chats) |
| 访问工作区之外的文件 | Microsoft Scout 可以读写工作区文件夹之外的文件。你授予某个文件夹一次访问权限后，Microsoft Scout 可以在后续操作中使用它。 | [使用文件](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#work-with-files) |
| 更多 Microsoft 365 工具 | Microsoft Scout 可与你的 Microsoft To Do 任务和列表配合工作，通过状态（presence）检查可用性，并向 Teams 频道发布消息。 | [使用 Microsoft 365](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#work-with-microsoft-365) |
| 每个自动化的推理和上下文 | 为每个自动化单独设置推理强度和上下文大小。 | [创建自动化](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#create-automations) |
| 恢复过去的对话 | 按需恢复较早的对话。会话历史按设备存储在你的 OneDrive 中。 | [使用记忆和会话历史](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#use-memory-and-session-history) |
| 用自己的话回答 | 当 Microsoft Scout 提出开放式问题时，你可以输入自由文本回答，而不必选择预设选项。 | [回答 Microsoft Scout 的问题](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#answer-questions-from-microsoft-scout) |
| 重新设计的 Settings | Settings 现在是一个单一、分组、可搜索的窗口。**Integrations** 已移入 Settings，**Extensions** 可直接在左侧导航中使用。 | [探索设置](https://learn.microsoft.com/en-us/microsoft-scout/get-started#explore-settings) |

### 改进

此版本还包括重新设计的撰写框，内置模型选择器；大屏幕下的更宽布局；工具调用和权限提示的更新图标；聊天消息的格式化复制；长对话中更平滑的滚动；以及当模型不可用或对话达到上限时更清晰的错误消息。登录和会话恢复更可靠，包括自动化运行时会话过期时的就地恢复。
