**内容摘要**：文档按月记录 Microsoft Scout 的更新。2026 年 8 月版本新增 GitHub Enterprise Cloud 登录、Teams 会议转录与会议室预订、SharePoint Lists、Outlook 收件箱规则、OneDrive/SharePoint 文件共享与访问管理，以及可存放在 OneDrive 或 SharePoint 的 Co-Create 工作区。2026 年 7 月版本新增 Co-Create 的 Markdown、源代码、结构化数据和 HTML 编辑器，上下文窗口大小（含 Max 选项）与默认推理强度设置，对话压缩，聊天整理，访问工作区之外的文件，Microsoft To Do 与 Teams 频道发帖，以及每个 Automation 单独的推理与上下文设置。此外还有按设备存放在 OneDrive 的会话历史恢复和重新设计的 Settings。

**保留理由**：这是 Scout 按月份记录功能变化的官方版本历史，可用来核对某项能力出现在 7 月还是 8 月。
