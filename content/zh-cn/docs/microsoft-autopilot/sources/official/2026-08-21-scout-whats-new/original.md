What's new in Microsoft Scout

[This article is prerelease documentation and is subject to change.]

Important

- You need to be part of the **[Frontier preview program](https://adoption.microsoft.com/en-us/copilot/frontier-program/)** and sign up to accept terms of participation to get **early access** to Microsoft Scout. Frontier connects you directly with Microsoft's latest AI innovations. Frontier previews are subject to the existing preview terms of your customer agreements. As these features are still in development, their availability and capabilities may change over time.
- This is a preview feature.
- Preview features may have restricted functionality and may not be released for general availability. These features are available before an official release so that customers can get early access and provide feedback.
- For more information, go to our [Microsoft Product Terms](https://www.microsoft.com/licensing/terms/product/ForOnlineServices/MCA).

This article lists recent features, improvements, and changes in Microsoft Scout. For a full guide to Microsoft Scout's capabilities, see [Use Microsoft Scout](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout).

## August 2026

This release adds the following features and improvements to Microsoft Scout.

### New features

| Feature | Description | Learn more |
| --- | --- | --- |
| GitHub Enterprise Cloud sign-in | Turn on **Use a GitHub Enterprise host** on the sign-in screen to sign in to GitHub Enterprise Cloud (for example, `your-org.ghe.com`). | [Sign in](https://learn.microsoft.com/en-us/microsoft-scout/get-started#sign-in) |
| Teams meeting transcripts and rooms | Retrieve available Teams meeting transcripts, and find and book meeting rooms. | [Work with meetings](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#retrieve-a-teams-meeting-transcript) |
| SharePoint Lists | Review SharePoint list columns and items, and create or update list items. | [Work with SharePoint Lists](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#work-with-sharepoint-lists) |
| Outlook inbox rules | List, create, update, enable, disable, and delete Outlook inbox rules. | [Manage Outlook inbox rules](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#manage-outlook-inbox-rules) |
| File sharing and access | Share OneDrive and SharePoint files with specific people, set view or edit access, and check who currently has access, subject to your access and organization policies. | [Share files and manage access](https://learn.microsoft.com/en-us/microsoft-scout/work-with-microsoft-365#share-files-and-manage-access) |
| Cloud-stored Co-Create workspaces | Store Co-Create workspaces in OneDrive or SharePoint. | [Co-create files with Microsoft Scout](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#co-create-files-with-microsoft-scout) |

### Improvements

This release improves chat interactions, automation scheduling, reliability, accessibility, and the overall user experience.

## July 2026

This release adds the following features and improvements to Microsoft Scout. Select **Learn more** for details.

### New features

| Feature | Description | Learn more |
| --- | --- | --- |
| Co-Create editors and file types | Co-Create adds editors for Markdown, source code, structured data, and HTML, and supports more file types, including CSV and TSV, Mermaid diagrams, and Excalidraw drawings. You can add inline comments in the Markdown editor. | [Co-create files with Microsoft Scout](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#co-create-files-with-microsoft-scout) |
| Model and reasoning controls | Choose the context window size for a conversation, including a **Max** option, set a default reasoning effort in Settings, and switch the model for an individual message. | [Choose a model and reasoning effort](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#choose-a-model-and-reasoning-effort) |
| Shorten a long conversation | Compact a long conversation on demand to free up room while keeping the important context. | [Shorten a long conversation](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#shorten-a-long-conversation) |
| Organize your chats | Filter the chat list by all items, chats, or automations; pin and reorder chats; open a chat's actions with a right-click; and mark a conversation as unread. | [Organize your chats](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#organize-your-chats) |
| Access files outside your workspace | Microsoft Scout can read and write files outside your workspace folder. You grant access to a folder once, and Microsoft Scout can use it in later actions. | [Work with files](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#work-with-files) |
| More Microsoft 365 tools | Microsoft Scout works with your Microsoft To Do tasks and lists, checks availability through presence, and posts to Teams channels. | [Work with Microsoft 365](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#work-with-microsoft-365) |
| Per-automation reasoning and context | Set the reasoning effort and context size for each automation individually. | [Create automations](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#create-automations) |
| Restore past conversations | Restore earlier conversations on demand. Session history is stored per device in your OneDrive. | [Use memory and session history](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#use-memory-and-session-history) |
| Answer in your own words | When Microsoft Scout asks an open-ended question, you can type a free-text answer instead of choosing a preset option. | [Answer questions from Microsoft Scout](https://learn.microsoft.com/en-us/microsoft-scout/use-microsoft-scout#answer-questions-from-microsoft-scout) |
| Redesigned Settings | Settings is now a single, grouped, searchable window. **Integrations** moved into Settings, and **Extensions** is available directly in the left navigation. | [Explore settings](https://learn.microsoft.com/en-us/microsoft-scout/get-started#explore-settings) |

### Improvements

This release also includes a redesigned compose box with an in-box model selector, a wider layout for large screens, updated icons for tool calls and permission prompts, formatted copy for chat messages, smoother scrolling on long conversations, and clearer error messages when a model is unavailable or a conversation reaches its limit. Sign-in and session recovery are more reliable, including in-place recovery when your session expires while an automation is running.
