## 推出 ChatGPT Wallet

ChatGPT Wallet 帮助你的 dot 从「找到你需要的东西」走到「代你完成购买」。无论你是在挑一件新毛衣，还是预订酒店，都可以让 dot 帮忙，并在结账时使用 Wallet。保存一次符合条件的卡片，之后批准购买时就不必再输入支付信息。

在你的 dot 付款之前，你会核对商家、商品、总价和所选卡片，然后用 Face ID 或 Touch ID 等生物识别授权购买。Wallet 会在结账时提供替代的支付凭据，让你的真实卡信息对智能体和商家都保持隐藏。你仍然保留与你的卡片相关的奖励，以及它在符合条件的争议中的保护。

Wallet 正逐步在 dots 中向美国 18 岁以上、持有符合条件的美国发行卡片和美国账单地址的 ChatGPT Pro 订阅者推出。要开始使用，请让你的 dot 把一张卡加入 Wallet。有些网站可能不支持由智能体发起的购买，而且仅仅批准并不能确认订单——结账后请查看商家的确认。关于设置与购买指引，见：[用 ChatGPT Wallet 购物](https://help.openai.com/articles/20001654)。
