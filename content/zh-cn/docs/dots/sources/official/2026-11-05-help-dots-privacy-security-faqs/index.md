了解你的 dot 可以访问什么、它如何使用和保护你的信息，以及它什么时候需要你的批准。

## 访问与权限

### 我的 dot 能使用我已经在 ChatGPT、ChatGPT Work 或 Codex 中设置好的插件吗？

可以。插件权限在 dots、ChatGPT、ChatGPT Work 和 Codex 之间共享。你的 dot 可以在你已授予的权限范围内使用你现有的连接。

你的 dot 带有严格的默认设置，规定哪些操作每次都需要你批准、哪些可以由你预先批准、哪些可以不经询问直接执行。详见[操作、批准与控制](#actions-approvals-and-control)一节。

### 我在哪里授予新权限或管理已有权限？

你可以在 ChatGPT 的 **插件** 标签页中连接新插件并管理已有插件。这些连接在 dots、ChatGPT、ChatGPT Work 和 Codex 之间共享。

你也可以为你的 dot 设置一个单独的 Slack 账户，让它在这些服务中拥有自己的身份和访问权限。即使你的 dot 有了自己的电子邮件或 Slack 账户，它仍然可以使用你已连接到 ChatGPT 的插件。

### 如何控制我的 dot 通过插件可以读取或修改什么？

你可以在 ChatGPT 的 **插件** 标签页中管理对不同插件的访问。关于何时需要你批准才能通过插件执行操作，你的 dot 遵循严格的默认设置。

自定义规则让你可以为 dots 设置额外的边界，例如告诉你的 dot 永远不要发送电子邮件。这些规则不能凌驾于某些内置的防护栏和安全要求之上。

你的 dot 还可以在你提出请求之前寻找有用的动态。这称为主动研究。它可以从获准的已连接来源读取信息并保存私人笔记，但它的研究工具不能直接：

- 给其他人发送消息。
- 通过插件修改内容。
- 控制浏览器或计算机。

任何后续操作都必须遵循通常的操作规则和安全检查。同样的规则也适用于你已经授权、并在后台继续进行的任务。

### 我的 dot 能访问我的摄像头、麦克风或屏幕吗？

在你的 dot 能够访问你计算机的摄像头、麦克风或屏幕之前，你必须把你的计算机连接到你的 dot。你还必须在设备设置中授予 ChatGPT 应用访问摄像头、麦克风或屏幕的权限。

### 18 岁以下的用户可以使用 dots 吗？

不可以。dots 目前还不向 18 岁以下的用户开放。

## 数据使用、记忆与隐私

### 我的 dot 与 ChatGPT 共享记忆吗？

是的。你的 dot 可以从 ChatGPT 接收记忆和近期的对话上下文，与你的 dot 的对话也可以为 ChatGPT 中的记忆提供内容。设置完成后，记忆可以继续在 ChatGPT 和你的 dot 之间共享。

在 ChatGPT 中关闭 **记忆** 会停止这种共享。它不会删除你的 dot 已经接收的信息。

### 我的 dot 会保留哪些信息，这些信息如何受到保护？

只要你保留你的 dot，它就可以保留来自你的对话和插件的上下文。你可以通过删除你的 dot 来删除它的上下文。你的 dot 已共享到 ChatGPT 记忆中的任何信息，可以在 ChatGPT 记忆设置中单独管理。

你的 dot 的上下文不会保留凭证、图片或屏幕截图。你的 dot 在其他位置创建或使用的文件，例如 ChatGPT 资料库、你的计算机或已连接的存储服务中的文件，遵循相应位置的保留政策。

OpenAI 会在你的内容存储时，以及在你、OpenAI 和我们的服务提供商之间传输时对其进行加密。

### 我能查看、更正或删除我的 dot 关于我记住的内容吗？

你可以通过删除你的 dot 来删除它的上下文。目前你无法查看、删除或直接修改单条 dot 记忆，包括从插件进入 dot 上下文的具体细节。

### 如果我断开通过插件关联的某项服务，我的信息会怎样？

这会停止通过该连接进行的新访问。它不会删除你的 dot 已经纳入其上下文的信息。

### 如果我删除我的 dot，我的信息会怎样？

- **删除你的 dot：** 这会删除你的 dot 自己的上下文。
- **文件和对话：** 你的 dot 创建的文件、Codex 会话线程和 ChatGPT 对话是单独存储的。删除你的 dot 不会删除它们。
- **ChatGPT 记忆：** 来自你其他 ChatGPT 对话的记忆保持不变。你可以通过 ChatGPT 的记忆控制来管理它们。

### 如果我关闭了模型改进，与 OpenAI 相关的人员还能审查我的 dot 的活动吗？

能。即使关闭了模型改进，在有限的[情形](https://help.openai.com/articles/7039943#authorized-human-access-to-content)下，包括与安全相关的情形，仍可能进行人工审查。

### OpenAI 会使用来自我的 dot 的信息来改进其模型吗？如何选择退出？

对于 ChatGPT Business、Enterprise 和 Edu 工作区，我们默认不会使用你的数据训练我们的模型。对于个人 ChatGPT 套餐，你的「**为所有人改进模型**」设置决定你的 dots 的对话和工作是否可能被用于改进我们的模型。这可能包括 dots 执行的操作、它们委派给其他智能体的工作、你设置的自动化，以及用于为你的对话提供信息的已连接应用数据。在使用符合条件的数据之前，我们会尽可能采取措施去除个人身份标识。

我们不会直接用主动的后台研究或其笔记进行训练。如果某个 dot 把这些研究中的信息带入了一段符合条件的对话或任务，根据你的设置，这些信息可能会被用于训练。你可以在 ChatGPT 设置中关闭「**为所有人改进模型**」。你可以在 [ChatGPT 中的数据控制](https://help.openai.com/articles/7730893)中进一步了解你的数据如何被使用。

### 如何申请访问、更正或删除我的个人信息？

即使你没有 OpenAI 账户，也可以通过 OpenAI 的[隐私门户](https://privacy.openai.com/)提交请求，或发送电子邮件至 [dsar@openai.com](mailto:dsar@openai.com)。

根据你所在的地区，你的权利可能包括访问、更正、删除或获取一份你的个人数据副本。我们可能会要求提供信息以核实你的身份。详见我们的[隐私政策](https://openai.com/policies/privacy-policy/)。

### OpenAI 如何使用服务提供商？

OpenAI 使用服务提供商帮助运营其服务，包括托管、云基础设施、支持、安全和电子邮件投递。这些提供商可能会按照 OpenAI 的指示访问、处理或存储个人信息，以提供这些服务。

更多信息请参阅我们的[隐私政策](https://openai.com/policies/privacy-policy/)。对于代表企业客户处理的信息，其处理方式由适用的客户协议约定。

## 操作、批准与控制 {#actions-approvals-and-control}

### 哪些操作需要我的批准，或需要我接管？

如果你让你的 dot 执行敏感操作，你的 dot 可能会确认你的明确批准（在某些情况下可以预先给出），或请你接管、自己完成这项操作。你的 dot 已被指示遵循以下政策：

- 最敏感的操作，例如更改密码或转账，需要你接管，由你自己完成。
- 其他操作，例如永久删除数据或安装软件，可能在你每次要求你的 dot 执行时都需要批准。
- 在其中某些情况下，例如发送定期消息，你可以预先给出批准，而不必每次批准。

你的 dot 根据你的指示来理解它何时以及如何可以代表你行事。你可以通过明确说明你批准的内容，帮助把这些边界划清楚。对于一条未来要发送的消息，请写明它应发给谁、应该说什么，以及应在何时或在什么条件下发送。批准一条消息并不意味着你的 dot 获得了代表你联系他人的持续许可。任何预先批准都仅限于你授权的范围。dots 仍然可能犯错，所以请始终审阅有后果的工作。

### 自定义规则可以允许或阻止什么？哪些批准要求或安全检查不能被覆盖？

你的 dot 预置了严格的默认设置，规定哪些操作需要在执行时确认、哪些需要预先批准、哪些不需要确认。自定义规则让你可以调整这些设置，并告诉你的 dot 哪些受支持的操作可以独立执行、哪些需要你的批准、哪些不应执行。你可以在设置中查看你的自定义规则。自定义规则不能关闭核心安全要求，例如你的 dot 请你重新接管以更改密码的情形。自定义规则也不能改变独立的安全审查系统「自动审查」（Auto-review），或对主动研究的限制。

### 如何审阅和引导我的 dot 的活动？

桌面应用中的活动视图会显示你的 dot 正在进行的任务和已委派的任务。你可以看到任务描述及其状态，以跟踪进展。你也可以审阅你的 dot 已经执行的步骤。

你可以补充上下文、纠正误解、改变方向，或让你的 dot 停止。

### 我能让我的 dot 停下、更正它的指令，或撤销它已经执行的操作吗？

在你的 dot 工作时，你可以提供更新的指导、改变方向或让它停止。

一项已完成的操作能否撤销，取决于操作本身和所涉及的应用。你可以让你的 dot 帮助纠正错误，但有些操作无法撤销。

### 如果我的 dot 犯了错、意外分享了信息，或执行了我并不打算让它执行的操作，我该怎么办？

你的 dot 可能会犯错。如果你发现了错误，可以让你的 dot 修复问题，它也许能够撤销操作。例如，你的 dot 也许能够撤回对文档的意外编辑，或撤回一封电子邮件。如果你想报告一个错误，请参阅[开始使用你的 dot](https://help.openai.com/articles/20001530) 获取更多指导。

## 安全与内置防护措施

### 使用 dots 时，如何帮助保护我的账户安全？

多重身份验证（MFA）会在你登录 ChatGPT 账户时增加一个额外的验证步骤，为防范网络钓鱼和未经授权的访问提供额外保护。你可以在 **设置 > 安全与登录** 中开启它。[了解如何设置 MFA](https://help.openai.com/articles/7967234)。

### 哪些安全检查有助于防止我的 dot 分享私人信息或超出我的权限行事？

你的 dot 使用多层保护：

- **模型防护：** GPT-6 Astra 经过训练，会拒绝有害请求，包括生物或网络安全方面的滥用。
- **插件权限** 限制它可以访问什么。
- **自定义规则** 让你可以为受支持的操作设置额外的边界。
- **自动审查** 在某些计划中的操作运行之前，对照你的指示、自定义规则和安全要求对其进行检查。
- **安全监控** 在你的 dot 工作时寻找潜在的有害行为。

例如，在你的 dot 发送电子邮件之前，自动审查会检查收件人和邮件内容，以帮助发现错误的地址或你并不打算分享的信息。

如果自动审查拦截了该操作，你的 dot 可能会在澄清或批准能够解除拦截时请你澄清或批准，或尝试一种获准的替代做法，或者停止。你的批准不能凌驾于核心安全要求之上。

当你的 dot 委派工作或在后台继续工作时，操作规则同样适用。主动研究还有额外的限制：它的工具不能直接给其他人发送消息、通过插件修改内容，或控制浏览器或计算机。

你的 dot 不能关闭必需的自动审查检查，也不能解除这些研究限制。这些防护措施有助于降低风险，但你的 dot 仍然可能犯错。

关于自定义自动审查策略的信息，请参阅[自动审查配置](https://learn.chatgpt.com/docs/sandboxing/auto-review#configuration)。

### 我的 dot 如何防范提示注入、网络钓鱼和恶意指令？

网站、电子邮件或文档中可能包含试图诱骗你的 dot 去做你没有要求的事情的指令，例如分享私人信息。这称为[提示注入](https://openai.com/safety/prompt-injections/)。

你的 dot 被设计为能够区分你的指令和它在工作中遇到的内容。这些内容本身并不授予任何许可。

其他保护措施包括对工具能力的限制、某些操作之前的自动检查、批准要求以及安全监控。我们还通过人工和自动化测试来发现弱点，并改进这些防护措施。

这些保护措施有助于降低恶意指令导致非预期操作的风险，但并不能消除这种风险。

## 密码、身份验证与付款

### 我的 dot 如何处理密码？

对于受支持的登录，你的 dot 会暂停，由你在一个安全的登录表单中输入凭证。该表单会把你的凭证直接发送到浏览器环境，而不会暴露给模型。之后你的 dot 可以继续使用已登录的会话。

这些保护措施适用于受支持的登录流程。它们不涵盖你在聊天、文档中或通过插件另行分享的密码。

### 我的 dot 能替我完成登录和安全检查吗？

你可能需要提供身份验证码，或接管以完成安全检查。

### 使用商家网站上保存的卡片购物

你的 dot 也可以使用你保存在商家网站上的卡片进行购物。这些购物需要你的批准；如果预先批准明确涵盖该笔购物，也可以预先给出。
