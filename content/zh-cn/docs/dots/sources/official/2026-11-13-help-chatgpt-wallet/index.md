用 ChatGPT Wallet 购物

了解如何向 ChatGPT Wallet 添加卡片、查看和批准购买、管理已保存的卡片，以及获取帮助。

**ChatGPT Wallet 正在逐步推出。** 即使你是美国符合条件的 Pro 用户，也可能尚未获得访问权限。当你的账号可以使用 Wallet 时，你可以让 dot 帮你添加卡片。

## 概览

ChatGPT Wallet 为你的 dot 提供了一种安全的代付方式。
  
ChatGPT Wallet 会安全地保存你的卡片信息，并让你在每笔交易发生前查看和批准。批准后，会生成一个支付令牌（payment token）——它是你实际卡片信息的替代品——包含卡号、安全码和有效期，使款项可以记到你的卡上，而无需把你的实际卡片信息分享给商家或智能体。
  
使用 ChatGPT Wallet，你可以让 dot「帮我找一件新毛衣」或「帮我订下周末去芝加哥的酒店」。到结账时，你的 dot 会提示你设置并使用 Wallet 来完成。

### 可用范围

ChatGPT Wallet 正在向美国符合条件的 ChatGPT Pro 用户推出。它可在与你的 dot 的对话中使用。使用 Wallet 前请先设置一个 dot。Wallet 在 Chat、Work 或单独的 Codex 线程中不可用。批准购买需要在受支持的设备上进行生物识别验证，例如 Face ID 或 Touch ID。
  
Wallet 面向持有符合条件的美国发行 American Express、Chase、Mastercard 和 Visa 卡片的美国 Pro 用户。你必须年满 18 岁、居住在美国，且卡片账单地址在美国。要添加符合条件的 Chase 卡，你必须是主卡持卡人，而不是授权用户。
  
你的银行可能在设置过程中要求你验证卡片。

### 开始之前

你使用 ChatGPT Wallet 进行信用卡交易和购物时，必须遵守 OpenAI 的[使用政策](https://openai.com/policies/usage-policies/)。添加卡片前，请阅读 [ChatGPT Wallet 条款](https://openai.com/policies/chatgpt-wallet-terms/)和 [ChatGPT Wallet 隐私声明](https://openai.com/policies/chatgpt-wallet-privacy-notice/)。
  
为使用 ChatGPT Wallet 购物而保存的卡片，与你的 ChatGPT 订阅付款方式以及礼品卡或预付余额是分开的。关于存储余额，参见：[使用你的 ChatGPT 余额](https://help.openai.com/articles/20001508)。

## 添加卡片

让 dot 添加卡片，或从设置页面的 Wallet 部分开始。两种方式都会进入用于填写卡片信息的安全表单。如果你首次发起交易，也应会看到卡片登记流程。

### 用 dot 添加卡片

- 在与 dot 的对话中，说「帮我把一张卡添加到 Wallet」。
- 打开对话中的安全卡片设置请求或链接，然后完成下面的卡片设置。

### 通过设置页面添加卡片

- 在移动设备上，打开左侧导航栏中的**设置**页面。
- 在该页面选择 **Wallet**
- 选择**添加卡片**（Add Card）并输入你的卡片信息

### 完成卡片设置

1. 在安全表单中——而不是聊天中——输入你的卡号、有效期和安全码。American Express 卡请使用卡片正面的 4 位安全码。
2. 阅读 [ChatGPT Wallet 条款](https://openai.com/policies/chatgpt-wallet-terms/)和 [ChatGPT Wallet 隐私声明](https://openai.com/policies/chatgpt-wallet-privacy-notice/)，然后选择**添加卡片**。
3. 如被要求，完成银行验证，并等待出现**卡片已添加**（Card added）后再开始购物。

如果不确定卡片是否已添加，请先查看已保存的卡片，再尝试重新添加。

### 完成银行验证

你的银行可能要求你验证卡片后才能使用。请按安全设置流程中的说明操作，其中可能包括输入验证码，或在银行的手机应用中批准连接。这有助于银行确认你有权使用该卡。购买会单独由你查看和批准。
  
你可以使用哪些验证方式由银行决定。验证码只能在安全验证表单中输入，绝不要输入到聊天或支持消息中。

### Chase 发行的信用卡

开始之前，在手机上安装 Chase 应用，并用生物识别登录。对于符合条件的 Chase 卡，请按设置链接在 Chase 手机应用中批准连接。如果你使用的是电脑，请用手机扫描二维码。在 Chase 应用中批准后，返回 Wallet 完成设置。

## 批准购买

选好要买的东西后，让 dot 完成购买。出现购买请求时，按以下步骤操作。

1. 检查所有重要购买信息，例如商家、商品、总价、所选卡片，以及显示的任何配送或定期付款条款。
2. 选择**批准**（Approve），并完成生物识别验证，例如 Face ID 或 Touch ID。

    1. 如果你无法在当前设备上批准，请按链接或二维码，在同一 ChatGPT 账号已登录的受支持设备上继续。如果你的笔记本电脑合上了，请打开它以使用生物识别验证，或在受支持的手机上继续批准。
3. 你批准后，dot 会继续完成结账并报告结果。

**可以结账了**（Ready to check out）表示你的批准已完成。它并不确认商家已受理你的订单。如果结果不明确，请先查看有没有商家确认，再重试。
  
请仔细查看每个购买请求，包括总价和任何定期付款条款。如果你同意定期或持续付款计划，商家可能会保存支付凭据，并按你同意的条款再次扣款。要管理或取消这些扣款，请联系商家。
  
你批准后，dot 会使用与所选卡片关联的虚拟卡号完成结账。结账时输入的号码可能与你实体卡上的号码不同。
  
如果你在批准前改变主意，请拒绝该请求。要取消已完成的订单，请联系商家。

## 管理已保存的卡片

### 用 dot 管理卡片

让 dot 显示你已保存的卡片。列表包含每张卡的昵称、后四位和有效期。要更改默认卡，请说「把尾号 1234 的卡设为我的默认卡」，并填入你卡号的后四位。
  
Wallet 中保存的卡片与商家网站上保存的付款方式是分开的。查看购买时请检查所选付款方式。
  
要移除一张卡片：

1. 请求移除一张已保存的卡片，用卡号后四位指明是哪一张。
2. 在确认移除前，检查确认信息指的是正确的卡片。
3. 再次请求查看已保存的卡片，确认该卡已被移除。

一旦移除某张卡片，除非重新添加，否则无法用它进行新的 Wallet 付款。
  
移除卡片不会取消购买、不会向银行注销该卡，也不会删除你的 Wallet 数据或 OpenAI 账号。要取消已有订单、申请退款或管理定期扣款，请联系商家。

## 获取帮助

### 购买与付款

按问题类型选择联系对象：

- 关于订单状态、取消、退货或退款，请用商家收据或网站上的联系方式联系商家。商家按自己的政策处理这些请求。
- 关于被拒、待处理、有争议或无法识别的扣款，或银行验证问题，请联系发卡机构。发现无法识别的扣款请尽快报告。
- 关于 Wallet 错误、怀疑你的 ChatGPT 账号被未经授权访问，或购买内容与你批准的不一致，请[联系 OpenAI 支持](https://help.openai.com/articles/6614161)。

### 遇到欺诈怎么办

批准前，请确认你认识这笔购买并信任卖家。如果不认识或不信任，请拒绝该请求。
  
对于无法识别的卡片扣款，请尽快通过发卡机构的官方应用或卡片上的电话联系发卡机构。

- 如果你怀疑有人访问了你的 OpenAI 账号，请保护账号安全，并通过[如何举报欺诈或可疑活动？](https://help.openai.com/articles/7242626)报告未经授权的活动。
- 对于你能识别的订单出现问题，请联系商家办理退货、取消或退款；如果你认为这是诈骗，也请告知发卡机构。

绝不要在支持消息中分享完整卡号、安全码、密码或银行验证码。

### 就 Wallet 问题联系 OpenAI

如果在添加或移除卡片、打开付款请求或完成批准流程时遇到问题，请[联系 OpenAI 支持](https://help.openai.com/articles/6614161)。
  
请提供应用或浏览器及其版本、问题发生的时间和你的时区、确切的错误信息，以及失败的那一步。如果是结账问题，请提供商家、金额、币种和任何订单编号。截图中的敏感细节请遮盖。不要发送完整卡号、安全码、密码或验证码。

## 常见问题

### 为什么我无法保存卡片？

有些卡片不受支持。对于 Chase 卡，你还必须是主卡持卡人。请在安全表单中确认卡片信息，并完成所需的任何银行验证。
  
如果**添加卡片**按钮不可用，请更正安全表单中卡号、有效期或安全码显示的错误。如果按钮仍不可用、某张卡无法用于付款，或 Wallet 错误持续存在，请[联系 OpenAI 支持](https://help.openai.com/articles/6614161)，并提供确切的提示信息和设备详情。

### 我可以在 ChatGPT Wallet 中使用借记卡吗？

不可以。ChatGPT Wallet 不支持借记卡。请改用符合条件的美国发行信用卡。

### 我可以添加虚拟卡吗？

发布时不支持虚拟卡。请添加另一张受支持的美国发行信用卡。这与 Wallet 为完成已批准购买所使用的虚拟卡号是两回事。

### 如果银行在验证期间锁定我的卡片或账户怎么办？

停止验证尝试，并通过银行的官方应用或卡片上的电话联系银行。说明你是在 Wallet 中添加或验证卡片，并提供时间和确切的错误信息。卡片或账户的限制由你的银行处理。如需协助调查 Wallet 错误，请[联系 OpenAI 支持](https://help.openai.com/articles/6614161)。不要在聊天或支持消息中分享密码、完整卡号或验证码。

### 我可以在每家商店使用 Wallet 吗？

Wallet 可能无法在每家商店完成结账。如果购买失败，请先查看有没有商家订单确认，再直接向商店尝试其他付款方式。

### 为什么在批准卡片登记后还需要批准购买？

保存卡片和批准购买是两个独立的步骤。请在每个购买请求批准前先查看它。商家的定期扣款遵循你与该商家约定的付款计划。

### 为什么我被要求提供地址或其他联系信息？

商家可能需要你的姓名、电话号码、电子邮箱，或账单或配送地址来完成结账。对话中可能会要求你提供这些信息。请查看你要分享的内容，卡号、有效期和安全码只能在安全卡片表单中输入——不要在聊天中输入。

### 为什么我看到的卡号与填入表单的实体卡或收据上的号码不同？

Wallet 每次使用都会生成一个支付令牌——它是你实际卡片信息的替代品
  
结账失败，但我看到一笔待处理的扣款。我该怎么办？
  
请先查看有没有订单确认，并在重试前联系商家了解订单是否已完成。向发卡机构询问这笔待处理扣款以及冻结可能何时解除。仅凭对话中的错误并不能确认订单状态，也不能确认冻结何时解除。

### 如果结账过期或对话停止响应怎么办？

请先查看商家的收据或订单状态。如果没有明确结果，请联系商家，而不要立刻重复购买。如果对话或批准流程卡住，请[联系 OpenAI 支持](https://help.openai.com/articles/6614161)。
