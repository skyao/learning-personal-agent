你的 dot 运行在云端，有自己的计算机和浏览器。你的电脑关机时，它仍然可用。连接你自己的电脑和应用，能让它接触到更多你的工作。这些连接与[你用来给 dot 发消息的渠道](https://learn.chatgpt.com/codex/dots/channels)是分开的。你可以在手机上发出请求，同时你的 dot 在云端工作，或在已连接的电脑上协调工作。

## 使用云端计算机

打开你的 dot 的个人资料，在 **Computers**（计算机）下查看它的云端计算机。当你的 dot 提供浏览器交接（handoff）时，你也可以选择 **Open computer**（打开计算机）。

打开这台计算机并不等于你获得了控制权。选择 **Take over**（接管）来使用它的鼠标和键盘，在你的 dot 可以继续时再选择 **Return control**（归还控制权）。

把云端计算机用于调研、文档、数据分析或软件工作。设备关机时云端工作仍可继续，这台计算机也能在使用间歇保留状态。它有自己的文件、软件和浏览器会话。你在自己电脑上登录某个网站，并不会让你的 dot 也登录该网站。

## 为浏览器页面或文件添加标注

浏览器与文件标注正在面向 Pro、Business Premium 和 Enterprise 用户，在 ChatGPT 桌面应用中推出。用标注告诉你的 dot，你想让它处理页面或文件的哪一部分。

对于浏览器页面，使用应用内浏览器工具栏中的标注工具。选中你想讨论的页面部分，添加评论，然后把它发送给你的 dot。

对于文件，在你自己的 dot 中打开 PDF、文档、演示文稿或电子表格。选中你想讨论的部分，添加评论，然后在文件查看器中选择 **Send**（发送）。

## 云端线程

你的 dot 可以为云端工作开启独立的线程。这些线程会出现在你的桌面、网页和移动应用中，你可以在那里查看结果并给出进一步指示，同时你的 dot 继续协调。对于编码工作，它可以使用你已设置好的 Codex 云端环境，其中带有所需的仓库和配置。

你的 dot 可以并行处理几件事，这些线程运行期间你也可以继续与它对话。参见[任务与记忆](https://learn.chatgpt.com/codex/dots/tasks-and-memory#assigned-work)。

## 登录网站

你的 dot 使用与 ChatGPT Work 相同的私密登录流程。当网站需要登录时，你的 dot 可以发送一个带私密表单的请求。你在表单里输入凭据，并完成网站要求的任何验证，例如验证码。该表单会在你的对话之外把这些信息发送给远程浏览器。

你也可以选择直接在该网站上登录。这会以接管模式打开你的 dot 的浏览器，让你自己完成这些步骤。准备好让你的 dot 继续时，归还控制权。

### 保持登录状态

网站会话可以一直留到以后的工作中使用，直到你退出登录或网站使其过期。你的 dot 的云端浏览器有自己的会话；它不会继承你个人浏览器的登录状态。有些网站会阻止云端浏览器，或要求进一步验证。

### 保存和复用登录信息

在提供该选项时，**Save to Passwords**（保存到密码）可以让你保存一条登录信息，供以后的登录使用。保存是可选的。如果新的登录请求有匹配的已保存登录信息，你可以确认要使用它，或改用另一个账号。

已保存的登录信息和有效的网站会话不是一回事。你的 dot 可以在不再登录的情况下继续使用有效会话。复用已保存的登录信息来登录，则需要你确认。

## 连接你的电脑

把电脑连接一次，就能让它的本地文件、代码和应用可供你的 dot 使用：

1. 在那台电脑上的 ChatGPT 应用中打开你的 dot 的个人资料。
2. 在 **Computers**（计算机）下找到你正在使用的电脑，选择 **Allow**（允许）。
3. 查看确认信息，选择 **Allow access**（允许访问）来完成连接。

要连接另一台电脑，在那台电脑的 ChatGPT 应用中重复这些步骤。让你的 dot 在每台电脑上各开一个独立线程，处理互不相关的任务。每个线程一次使用一台电脑。

你的 dot 的云端计算机保持连接。对你这台电脑的访问权，在你给同一个 dot 发消息的任何地方都有效，包括从手机上。

你的 dot 可以创建本地 Work 或 Codex 任务，并继续已有的本地 Codex 任务。任务可以在云端管理，同时使用你已连接电脑上的文件和工具。打开任务可以查看工作在哪里进行，或直接下达指示。任务类型和连接要求参见[任务与记忆](https://learn.chatgpt.com/codex/dots/tasks-and-memory#assigned-work)。

如果某个网站阻止云端浏览器，可以让你的 dot 试试你已连接的电脑。这可能会创建一个单独的本地任务。它不会转移云端浏览器的会话，也不保证某个特定的本地浏览器受支持。

连接会在任务之间保持。你的 dot 使用电脑期间，请让电脑保持在线、ChatGPT 应用保持打开。**Offline**（离线）状态表示这台电脑不可用，并不撤销连接。要移除访问权，选择 **Revoke access**（撤销访问）。你的 dot 的本地电脑权限，与把电脑连接到 Codex 或启用 Work Sync 是分开的。单独做其中任何一项连接，都不会给你的 dot 访问权。

## 连接应用

你的 dot 可以使用为你的账号安装并启用的受支持[插件](https://learn.chatgpt.com/codex/plugins)。能否使用取决于该插件已连接的账号、权限，以及工作运行的环境。本地技能（skill）需要已连接的电脑。

例如，连接 Gmail 来查找相关邮件，连接 Google Drive 来读取和更新文档，或连接 GitHub 来调查一个问题并准备一个拉取请求。为你希望 dot 使用的每个插件完成安装和连接。在 iOS 上，你的 dot 给出的受支持 Gmail 邮件链接会打开 Gmail 应用中对应的邮件（如可用），否则在浏览器中打开。

查看已连接的账号及其允许的操作。你现有的 ChatGPT 应用权限适用于你的 dot。例如，你可以允许它读取邮件，而不允许它发送邮件。如果连接过期，打开相应请求重新连接后再继续。

添加联系方式不会授予对你的应用或电脑的访问权。例如，在 Slack 中给你的 dot 发消息，并不会连接你的收件箱。
