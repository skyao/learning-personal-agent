你的 dot 住在云端，拥有自己的计算机和浏览器。在你的计算机关闭时，它仍然可用。连接你自己的计算机和应用，能让它接触到你更多的工作。这些连接独立于[你用来给 dot 发消息的渠道](https://learn.chatgpt.com/codex/dots/channels)。在你的 dot 在云端工作，或在已连接的计算机上协调工作时，你可以用手机发送请求。

## 使用云端计算机

打开你的 dot 的个人资料，在**计算机**（Computers）下查看它的云端计算机。当你的 dot 提出浏览器交接时，你也可以选择**打开计算机**（Open computer）。

打开计算机并不会把控制权交给你。选择**接管**（Take over）来使用它的鼠标和键盘，然后在你的 dot 可以继续时选择**交还控制**（Return control）。

使用云端计算机来做研究、处理文档、分析数据或进行软件工作。在你的设备关闭时，云端工作可以继续，而且这台计算机可以在两次使用之间保持它的状态。它有自己的文件、软件和浏览器会话。在你的计算机上登录某个网站，并不会让你的 dot 登录那个网站。

## 云端会话线程

你的 dot 可以为云端工作开启单独的会话线程。它们会出现在你的桌面、网页和移动应用中，你可以在那里查看结果并给出进一步的指示，同时你的 dot 继续进行协调。对于编程工作，它可以使用你用所需代码仓库和配置设置好的 Codex 云端环境。

你的 dot 可以并行处理多件事情，在这些会话线程运行时，你可以继续和它交谈。请参阅[任务与记忆](https://learn.chatgpt.com/codex/dots/tasks-and-memory#assigned-work)。

## 登录网站

你的 dot 使用与 ChatGPT Work 相同的私密登录流程。当某个网站需要登录时，你的 dot 可以发送一个带私密表单的请求。在那里输入你的凭证，并完成网站要求的任何验证，比如验证码。这个表单会绕过你的对话，把这些信息发送到远程浏览器。

你也可以选择改为在网站上登录。这会以接管模式打开你的 dot 的浏览器，让你亲自完成这些步骤。准备好让你的 dot 继续时，交还控制。

### 保持登录

一个网站会话可以在之后的工作中保持可用，直到你退出登录或网站让它过期。你的 dot 的云端浏览器有自己的会话；它不会继承你个人浏览器中的登录状态。有些网站会屏蔽云端浏览器，或要求进一步的验证。

### 保存和复用登录信息

在提供该选项时，**保存到密码**（Save to Passwords）让你可以保存一个登录信息，用于以后的登录。保存是可选的。如果某个新的登录请求有匹配的已保存登录信息，你可以确认要使用它，或者输入另一个账户。

已保存的登录信息和一个有效的网站会话是两回事。你的 dot 可以继续使用一个有效的会话，而不必再次登录。复用已保存的登录信息进行登录需要你的确认。

## 连接你的计算机

连接一次你的计算机，就能让它的本地文件、代码和应用可供你的 dot 工作使用：

1. 在那台计算机上的 ChatGPT 应用中打开你的 dot 的个人资料。
2. 在**计算机**下，找到**你的计算机**（Your computer），然后选择**允许访问**（Allow access）。
3. 查看确认信息，然后选择**允许访问**进行连接。

你一次只能连接一台个人计算机。你的 dot 的云端计算机保持连接。对你计算机的访问权限，在你给同一个 dot 发消息的任何地方都适用，包括从你的手机上。

你的 dot 可以创建本地 Work 或 Codex 任务，并继续已有的本地 Codex 任务。一个任务可以在云端管理，同时使用你已连接计算机上的文件和工具。打开任务，可以查看工作在哪里进行，或者直接给出指示。关于任务类型和连接要求，请参阅[任务与记忆](https://learn.chatgpt.com/codex/dots/tasks-and-memory#assigned-work)。

如果某个网站屏蔽了云端浏览器，让你的 dot 改为尝试你已连接的计算机。这可能会创建一个单独的本地任务。它不会转移云端浏览器的会话，也不保证支持某个特定的本地浏览器。

这个连接在各项任务之间保持不变。在你的 dot 使用你的计算机期间，请保持计算机在线并打开 ChatGPT 应用。

**离线**（Offline）状态表示这台计算机不可用；它并不会撤销连接。选择**撤销访问**（Revoke access）来移除访问权限。你的 dot 的本地计算机权限，独立于把计算机连接到 Codex 或启用 Work Sync。这两种连接中的任何一种单独都不会让你的 dot 获得访问权限。

## 连接应用

你的 dot 可以使用为你的账户安装并启用的受支持[插件](https://learn.chatgpt.com/codex/plugins)。访问权限取决于插件已连接的账户、权限，以及工作运行所在的环境。本地技能需要一台已连接的计算机。

例如，连接 Gmail 来查找相关邮件，连接 Google Drive 来阅读和更新文档，或者连接 GitHub 来调查一个问题并准备一个拉取请求（pull request）。安装并连接你希望你的 dot 使用的每一个插件。

检查已连接的账户及其允许的操作。你现有的 ChatGPT 应用权限适用于你的 dot。例如，你可以允许它阅读电子邮件，而不允许它发送电子邮件。如果某个连接过期了，在继续之前打开请求重新连接它。

添加一种联系方式不会授予对你的应用或计算机的访问权限。例如，在 Slack 中给你的 dot 发消息，并不会连接你的收件箱。
