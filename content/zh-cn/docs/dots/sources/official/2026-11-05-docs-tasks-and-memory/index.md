**内容摘要**：dot 可以同时跟踪多项职责，在对话之间持续工作，自己决定何时暂停和醒来，也可以把工作分给并行的后台智能体。任务分为新的本地 Work 或 Codex 任务、已有的本地 Codex 任务、新的云端编程任务和 dot 自己创建的任务四类，本地任务需要电脑在线并打开 ChatGPT 应用。周期性任务要写明做什么、何时做、时区与结束日期、何时通知、结果送到哪里，dot 也可以读写 ChatGPT Work 的自动化；事件监控需要来源本身支持。上下文来自当前对话、ChatGPT 记忆和 dot 自己的笔记，笔记与 ChatGPT 保存的记忆分开。主动研究是只读的，不会发消息、改动应用或控制浏览器。

**保留理由**：这一页是 dot 任务类型、记忆分层和主动研究边界的官方说明，「dot 的笔记独立于 ChatGPT 记忆」等细节别处少见。
