内置的安全防护、现有的应用权限和自动批准检查从一开始就适用。你可以查看进行中的工作、添加说明，或设置可选的自定义规则。

## 检查工作

在桌面应用中，打开你的 dot 的个人资料并选择**活动**（Activity）。选择一个任务，查看它的进展、文件和结果，包括在后台进行的工作。如果它正在等待一个决定、应用连接、登录或批准，打开该请求并作出回应，工作就会继续。在工作进行过程中，你可以改变方向。

打开**已安排**（Scheduled），查看你的 dot 的定时任务。检查任务的指示、时间和投递目的地。关于周期性工作，请参阅[任务与记忆](https://learn.chatgpt.com/codex/dots/tasks-and-memory)。

## 操作审查如何工作

在你的 dot 采取一个可能影响你的账户或分享信息的操作之前，一次自动审查会对照你的说明、权限、自定义规则和内置的安全要求对它进行检查。审查会决定这个操作是可以继续、需要你的批准，还是包含一个必须由你亲自完成的步骤。例如，你必须亲自更改密码。

给长期说明划定清楚的范围：谁可以参与，应该发生什么，以及什么时候。让你的 dot 起草回复，并不等于允许它发送回复。一条具体的说明可以涵盖该范围内今后的操作；超出范围的操作需要另一个决定。

你的 dot 还可以研究来自你已连接应用的信息，寻找帮忙的方式。它用于这种研究的工具不能发送消息、修改应用内容，也不能控制你的浏览器或计算机。任何后续操作都要遵守同样的权限和安全要求。

## 设置自定义规则

自定义规则是可选的控制，用于设定具体的长期边界。先从在对话中给出清楚的说明开始；你不需要为每一次批准都创建一条规则。

设置好你的 dot 之后，在你的应用中打开自定义规则：

- **桌面端和网页：** 打开**设置** > **个性化**，在**权限**下选择**自定义规则**。
- **iOS 和 Android：** 打开侧边栏，然后选择**自定义** > **自定义规则**。

选择**添加**，描述这个操作，选择你的 dot 应该如何处理它，然后选择**添加规则**。可选项有：

| 规则 | 预期行为 |
| --- | --- |
| 不询问直接采取行动（Take action without asking） | 采取指定的操作，不请求批准。 |
| 在你说了之后采取行动（Take action when you say so） | 在你明确请求该操作时继续；否则在行动之前立即询问。 |
| 采取行动前先询问（Ask before taking action） | 在采取指定的操作之前请求批准。 |
| 交给你（Hand off to you） | 改为请你亲自采取这个操作。 |

例如，对于给客户发消息，你可以选择**采取行动前先询问**；对于删除共享的项目文件，可以选择**交给你**。写作风格或你喜欢的更新方式这类偏好，就在对话中说；自定义规则控制的是你的 dot 什么时候可以采取一个操作。

保存的自定义规则适用于同一账户中的你的 dot。它们可以允许你的 dot 执行特定操作，要求它先与你确认，或者阻止它采取某个操作。它们是你的 dot 努力遵循的说明，而它可能会犯错。它们不会授予对某个应用或计算机的访问权限，不会凌驾于内置的安全要求之上，也不会取消必需的确认，比如使用已保存登录信息时的批准。

使用一条规则的菜单来编辑或删除它。选择**打开插件**（Open Plugins）查看**插件权限**，插件权限独立于自定义规则，单独控制应用操作。

如果你的工作区禁用了自定义规则，你就无法编辑已保存的规则，它们也不会生效。请参阅[配置 dots 权限](#for-workspace-admins)。（译注：原文此处为页内锚点，页面中没有对应的标题，照录。）

**面向工作区管理员：** 关于工作区权限、设置以及安全与治理指引，请参阅[为工作设置 dots](https://learn.chatgpt.com/codex/enterprise/dots-admin-guide)。

## 管理数据设置

你的 ChatGPT 数据控制同样适用于与你的 dot 之间符合条件的对话，以及它执行的工作。OpenAI 不会直接用主动研究或它的私人笔记来训练模型。如果来自这种研究的信息成为某段符合条件的对话或任务的一部分，你的数据设置就会适用。请参阅 [ChatGPT 中的数据控制](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)。

## 停止工作

暂停你的 dot、停止一个委派出去的任务和取消一个时间安排，效果各不相同：

- **暂停**（Pause）会停止你的 dot 当前的主要任务。它不会停止每一个委派出去的任务，也不会取消将来按计划进行的运行。
- 在**活动**中打开一个委派出去的任务，查看并停止该任务。
- 打开**已安排**，禁用或删除你想结束的周期性任务。

使用**继续**（Resume）让暂停的 dot 继续工作。停止工作不会撤销已经完成的操作。请分别检查进行中的任务和时间安排。

## 删除你的 dot

使用**删除**（Delete）来删除你的 dot。请阅读确认信息，了解删除操作如何处理对话、记忆和定时任务。在确认之前保存你需要的任何结果；这个操作无法撤销。

删除你的 dot 不会撤销已经在已连接应用中做出的修改，也不会撤回已经送达其他人的消息。
