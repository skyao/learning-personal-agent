内置保护措施、既有的应用权限和自动批准检查从一开始就已生效。你可以查看正在进行的工作、添加指令，或设置可选的自定义规则。

## 查看工作

在桌面应用中，打开你的 dot 的个人资料并选择 **活动**。选择一个任务，查看它的进度、文件和结果，包括在后台进行的工作。如果它正在等待决定、应用连接、登录或批准，请打开该请求并作出回应以继续。在工作进行中，你可以改变方向。

打开 **已计划**，查看你的 dot 的定时任务。检查任务的指令、时间和目标位置。关于重复性工作，见[任务与记忆](https://learn.chatgpt.com/codex/dots/tasks-and-memory)。

## 操作审查如何运作

在你的 dot 采取可能影响你的账号或分享信息的操作之前，自动审查会根据你的指令、权限、自定义规则和内置安全要求检查该操作。审查会判定该操作可以继续、需要你批准，还是包含必须由你亲自完成的步骤。例如，修改密码必须由你自己来做。

给持续性的指令划定清晰的范围：谁可以参与、应该发生什么、什么时候发生。让你的 dot 起草回复，并不等于授权它发送回复。一条具体的指令可以覆盖该范围内的未来操作；范围之外的操作需要另行决定。

如果你使用 Wallet，每一笔付款都需要你用生物识别审核并批准。

你的 dot 也可以从你已连接的应用中研究信息，寻找提供帮助的方式。它用于这类研究的工具不能发送消息、更改应用内容，也不能控制你的浏览器或计算机。任何后续操作都受同样的权限和安全要求约束。

## 设置自定义指令

自定义指令专属于你的 dot。用它来设定 dot 的工作方式，例如你偏好的写作风格、它多久 check-in 一次，或它在采取操作前何时询问。你的 dot 的指令与你在 ChatGPT 中的自定义指令是分开的。

在聊天中告诉你的 dot，你希望它把什么作为持续性指令记住。例如：「任务完成后，链接到结果，并告诉我哪些地方需要我留意。」你也可以之后让 dot 更新某条指令。

在移动端，当 **行为** 可用时，你可以在 **自定义** 中查看 dot 的指令，并在编辑功能已启用时进行编辑：

1. 打开侧边栏，选择 **自定义** > **行为**。
2. 如果你看到 ChatGPT 和你的 dot 的标签页，请选择你 dot 的名称。
3. 在 **「[你的 dot 名称]」如何处理任务** 下输入你的偏好。
4. 选择对勾（**保存**）。

回到 **自定义** > **行为** 即可编辑你的指令并保存更改。如果你的移动应用不显示 **行为**，请更新应用，或在桌面端或网页端使用 dot 的聊天。

在支持的地方，自定义规则让你选择 dot 如何处理特定的操作和批准。见[设置自定义规则](#set-custom-rules)。

## 设置自定义规则

自定义规则是针对特定持续性边界的可选控制项。先从对话中的清晰指令开始；你不需要为每一次批准都创建一条规则。

设置好你的 dot 后，打开你所用应用的自定义规则：

- **桌面端和网页端：** 打开 **设置** > **个性化**，在 **权限** 下选择 **自定义规则**。
- **iOS 和 Android：** 打开侧边栏，然后选择 **自定义** > **自定义规则**。这一选项在 **行为** 不可用时出现。

选择 **添加**，描述该操作，选择你的 dot 应如何处理它，然后选择 **添加规则**。可选项有：

| 规则 | 预期行为 |
| --- | --- |
| 不询问直接执行 | 不经请求批准就执行指定的操作。 |
| 你说了才执行 | 当你明确要求该操作时才执行；否则在行动前立即询问。 |
| 执行前先询问 | 在执行指定的操作前请求批准。 |
| 交由你处理 | 请你改为自己执行该操作。 |

例如，你可以对给客户发送消息选择 **执行前先询问**，对删除共享项目文件选择 **交由你处理**。写作风格或你希望收到更新方式这类偏好，请用你的对话或[自定义指令](#set-custom-instructions)；自定义规则控制的是你的 dot 何时可以采取操作。

已保存的自定义规则适用于同一账号中的你的 dot。它们可以授予 dot 执行特定操作的权限、要求它先与你确认，或阻止它采取某个操作。它们是你的 dot 会努力遵循的指令，它也可能出错。它们不会授予对某个应用或计算机的访问权限，不会覆盖内置安全要求，也不会移除必需的确认，例如使用已保存登录信息的批准。

使用规则菜单可以编辑或删除规则。选择 **打开插件** 可查看 **插件权限**，它独立于自定义规则来管理应用操作。如果你的工作区禁用了自定义规则，你就无法编辑已保存的规则，它们也不会生效。见[配置 dots 权限](#for-workspace-admins)。

**面向工作区管理员：** 工作区权限、设置以及安全与治理指引见[为工作设置 dots](https://learn.chatgpt.com/codex/enterprise/dots-admin-guide)。

## 管理数据设置

你的 ChatGPT 数据控制项同样适用于与你的 dot 之间符合条件的对话，以及它开展的工作。OpenAI 不会直接用主动研究或其私人笔记训练模型。如果该研究中的信息成为符合条件的对话或任务的一部分，你的数据设置就会适用。见 [ChatGPT 中的数据控制项](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)。

## 停止工作

暂停你的 dot、停止被委派的任务和取消计划，这三者的效果不同：

- **暂停** 会停止你的 dot 当前的主任务。它不会停止每一个被委派的任务，也不会取消未来的计划运行。
- 在 **活动** 中打开某个被委派的任务，以检查并停止该任务。
- 打开 **已计划**，禁用或删除你想结束的重复性任务。

使用 **恢复** 继续已暂停的 dot。停止工作不会撤销已完成的动作。请分别检查活动中的任务和计划。

## 删除你的 dot

使用 **删除** 删除你的 dot。请阅读确认提示，了解删除会如何处理对话、记忆和定时任务。在确认前，保存你需要的任何结果；此操作无法撤销。

删除你的 dot 不会撤销已在连接应用中做出的更改，也不会收回已经发送给他人的消息。
