**内容摘要**：用户可以在桌面应用中查看 dot 的活动与定时任务；执行可能影响账户或分享信息的操作前，自动审查会判断它可以继续、需要批准，还是要用户自己完成。新版新增自定义指令：它只属于这个 dot，与 ChatGPT 本身的自定义指令分开，可以在对话中让 dot 更新，移动端在 Behavior 可用时也可在「Customize → Behavior」中编辑。自定义规则有四种处理方式：不询问直接做、用户说了才做、做之前先问、交给用户。使用 Wallet 时，每笔付款都要用户用生物识别审核批准。暂停只停当前的主任务，不停已委派的任务，也不取消计划运行；删除 dot 无法撤销。

**保留理由**：这一页是暂停、停止委派任务、取消计划三者区别的官方出处，新版又说明了 dot 自定义指令与自定义规则的分工。
