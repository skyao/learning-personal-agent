Meta 的首席 AI 官 Alexandr Wang 已正式宣布 Muse Chrome 扩展，此时距离该扩展悄悄出现在 Chrome Web Store 上、Meta 未作任何宣布，已过去一周。[Digital Trends 报道](https://www.digitaltrends.com/computing/meta-is-putting-muse-in-a-chrome-sidebar-and-the-official-announcement-just-arrived/)，Wang 在 X 上的一篇帖子中称这次宣布来晚了，并表示已有 20 万人在使用该扩展。

Meta 的 Muse 商店页面现在显示 20 万用户和 4.6 的评分。TestingCatalog 于 11 月 13 日首次发现该上架页面，[当时被报道的这次悄悄上架](https://www.allthingsmuse.com/articles/muse-chrome-extension/)在其商店截图中显示 126 名用户。

## 扩展在 Chrome 中做什么

该扩展把 Muse 放入 Chrome 的侧边面板，因此用户可以在任何打开的页面上与 Muse 聊天，并用 Alt+Shift+C 快捷键打开面板。它要求 Chrome 137 或更高版本。

当 Muse 通过该扩展工作时，它使用用户自己的 Chrome 浏览，把标签页打开在自己的标签组中，并且只能在这些标签页内操作。它可以使用用户已经登录的网站，而无需再次索要这些登录信息。Digital Trends 报道，Muse 可以处理购物、旅行预订，以及为美国的付费订阅用户拨打电话。

## 控制与限制

Muse 无法通过该扩展看到用户保存的密码、浏览历史或 Chrome 设置，网页上的密码会在 Muse 读取之前从文本中移除。用户在实际操作发生前予以批准，Muse 保留完整活动日志，用户可以随时撤销任何连接器。

用户可以暂停 Muse，或通过点击页面、按 Esc、把标签页移出 Muse 标签组来接管浏览器。Meta 警告 Muse 可能采取非预期行动，因此用户应留意并在需要时介入。Muse 的活动可能出现在用户的 Google 账户与浏览历史中，并可能影响他们看到的广告与推荐。Meta 建议用户在连接该扩展之前，退出任何不希望该智能体使用的账户。

在[网站纷纷封堵自行到访的智能体](https://www.allthingsmuse.com/articles/muse-websites-blocking-agents/)之际，该扩展为 Muse 提供了通往网站的第二条路径——通过用户自己已登录的浏览器。该扩展现已在 Chrome Web Store 上架。
