**收录说明**：直接下载。去掉了首图 Jolly 插画、作者头像与站内推荐卡片。Wang 在 X 上的宣布经 Digital Trends 的报道转述（见 basedOn），商店用户数与评分引自 Chrome Web Store 上架页面。原文全文存于本目录的 original.md，网站上不显示，待翻译。

**内容摘要**：Meta 首席 AI 官 Alexandr Wang 已正式宣布 Muse Chrome 扩展，称宣布来晚了，已有 20 万人在使用；扩展一周前悄悄上架 Chrome Web Store 时 Meta 未作任何宣布。商店页面现显示 20 万用户、4.6 分，而 TestingCatalog 于 11 月 13 日首次发现上架时截图中只有 126 名用户。扩展把 Muse 放入 Chrome 侧边栏，可用 Alt+Shift+C 打开，要求 Chrome 137 或更高版本；Muse 经扩展用用户自己的 Chrome 浏览，标签页归入独立标签组，可使用用户已登录的网站而无需再次索要登录信息，据 Digital Trends 报道可处理购物、旅行预订与面向美国付费订阅用户的电话。控制与限制与上架时相同：Muse 看不到已保存的密码、浏览历史或 Chrome 设置，网页密码会在 Muse 读取前被去除，操作前需用户批准，用户可随时暂停或接管，Meta 建议在连接扩展前退出不希望代理使用的账号。

**保留理由**：这是 Chrome 扩展从悄悄上架到官方宣布的跟进记录，补上了首周 20 万用户、4.6 评分，以及 Chrome 137 与 Alt+Shift+C 两项此前未见的细节；与 11-13 收录的上架首报对照，可看清一周内的采用速度。
