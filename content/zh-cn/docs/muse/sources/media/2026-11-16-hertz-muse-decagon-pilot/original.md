Hertz is joining Decagon's Personal Agent Gateway in a pilot that will let renters ask Muse to change or extend an existing reservation and get a confirmed outcome back in the same conversation.

Hertz is joining [Decagon’s Personal Agent Gateway](https://decagon.ai/blog/hertz-opens-a-direct-line-to-muse-with-decagons-personal-agent-gateway) in a pilot that will connect Muse to Hertz’s AI-powered reservation and customer support platform. Decagon announced the pilot on November 13. Hertz is one of the first enterprises to give personal agents a direct line, and Muse will be the first personal agent on Hertz’s channel.

The pilot will let renters change or extend an existing Hertz reservation by asking Muse, instead of calling Hertz or opening its website. Muse returns a confirmed outcome in the same conversation.

## How a Muse Request Reaches Hertz

The connection uses Meta’s implementation of the open Personal Agent Protocol, known as Poppy. That is the same protocol that [reached version 1.0 on November 13](https://www.allthingsmuse.com/articles/poppy-personal-agent-protocol-1-0/), when Muse began looking for Poppy first on every site it visits.

Say a renter needs to keep a car for two extra days. Muse sends the request to Hertz’s personal agent channel, a dedicated agent-to-agent channel that sits alongside Hertz’s chat and voice channels. Hertz’s Decagon agent handles the change using the same Agent Operating Procedures, or AOPs, that run reservation requests in its existing agent. Those procedures include customer verification, rental policies, and handoffs to a live agent. When the change is done, the Decagon agent sends the updated booking back to Muse, which confirms it with the renter.

Hertz decides which requests are available through the channel, and it can expand that scope as it learns from the pilot. Hertz keeps control of the workflow its agent follows, including which actions happen, in what order, and under which policies.

Yatin Patel, senior director of product management, customer experience, and mobile app at Hertz, said the collaboration lets Hertz explore new ways to serve customers as more travelers use personal agents like Muse to plan and manage trips, and keep the experience consistent and reliable.

## A Limited Pilot

The arrangement is a pilot, and Decagon’s wording is in the future tense. The gateway will enable the connection, and the pilot will let renters make the changes. Decagon has not given a date when renters can first use it, and Hertz has not said which reservations or locations are included.

The pilot is a different route into a business from a standard connector. Travelers can already book hotels through the [live Expedia connector on Muse](https://www.allthingsmuse.com/articles/expedia-connector-live-on-muse/), which handles search and booking inside the chat. The Hertz pilot instead connects Muse to a company’s own support agent, so a change to an existing booking runs through the same procedures Hertz applies in its own chat channel. It follows the [open standard Meta previewed with Sierra and other partners in October](https://www.allthingsmuse.com/articles/meta-sierra-personal-agent-protocol/), which was designed to let a business identify a personal agent and state what it is allowed to do before the agent acts.

Decagon says it is working to connect more businesses and personal agents through the gateway. The first test for Hertz renters is narrow and practical. Renters keep the car two extra days through Muse, with no phone call.
