纽约——路透社查阅的内部公司帖子显示，Meta 的 AI agent Muse 有一个名叫 Jolly 的笑脸毛绒吉祥物形象，它钻进了加密的私人消息、提供了编造的购物信息，还把看似要发给别人的聊天发给了用户；对于一个本意是替消费者简化生活的 bot 来说，这是个问题重重的开端。

这些帖子显示，Muse 这些未经请求的行为，让不安的员工提出担忧：它可能把不同账号之间的对话搞混，并暴露用户的私人数据。Muse 是有记录以来增长最快的应用之一，自 9 月上线以来下载量超过 1,000 万次，也是 Meta 计划创造数十亿美元 AI 收入的核心。

在其中一些案例中，Meta 员工报告说，这个 agent 给他们发来关于自己并未提出的育儿请求、并未寻求的职业建议、并未下的商品订单，以及并不属于自己的银行账户余额的消息。

在本月早些时候的一则帖子里，一名员工告诉同事，他的 Muse 在关于钓鱼相关天气和潮汐信息的常规聊天中随机多插了一条消息，写道：「顺便说一下，两条银行更新，你的 Capital One 余额是 2,722.58 美元，你的 Charles Schwab 余额是 5,899.57 美元。」

「我从未向 Muse 分享过我的银行账户，也从未与 Muse 讨论过任何银行业务话题。我担心它把别人的银行信息发给了我。」这名员工在帖子中写道。

另一个例子中，一名在个人手机上使用 Muse 的员工报告说，它突然提醒她去回复姐姐在 Signal 上的一条消息，让她吃了一惊。Signal 是一款端到端加密的消息服务，在隐私倡导者中很受欢迎，与 Meta 的 WhatsApp 存在竞争。

「这看起来是严重的隐私侵犯。我绝对没有授予它访问其他应用的权限，也不记得被问过这件事。」这名员工在帖子中说。

一名同事回复说，他发现自己遇到类似情况——被与未连接应用相关的主动聊天弄得措手不及——之后查明，在搭载 Google Android 操作系统的手机上，Muse 默认被设置为拥有访问推送通知的权限。

为撰写这篇报道，路透社查阅了二十多篇内部帖子，它们描述了 Muse 自亮相以来不受欢迎的行为，其中许多来自一个反馈小组，Meta 员工在那里向构建该 agent 的团队报告问题。路透社还与 Signal 的员工以及研究 AI 社会影响的非营利组织 AI Now Institute 合作，复现了 Muse 对 Signal 消息的访问。这些测试的结果表明，Meta 员工描述的问题仍在持续，并可能影响其他人。

在回应关于 Signal 访问权限和其他 Muse 安全担忧的提问时，Meta 发言人 Daniel Roberts 把路透社举的例子称为「孤立事件（isolated incidents）」，称公司把安全放在首位，进行大量内部测试，并持续更新产品以改进保护措施。

Roberts 说，Muse 需要看到人们的电脑并与之交互，才能代表他们工作，而它只能通过用户明确授予的权限访问其他应用。他说，员工标记为可能是账号混淆的许多消息其实是幻觉——这个词指 AI 模型编造内容的倾向——并且已经得到处理。

路透社无法确定 Muse 是在把别人的银行账户余额等敏感数据发给用户，还是在编造这些信息。

## 深度访问

Muse 的这些事件凸显了一类新兴消费级 AI agent 的风险。这类产品正从 Meta、OpenAI 等公司涌向市场，被宣传为下一波 AI 技术的大浪潮。这些 bot 承诺重塑数字交易的方式：无需直接指令，就能执行回邮件、约时间、在线购物等省时任务。

Meta 目前领先于竞争对手。在对 Facebook、Instagram 和 WhatsApp 上超过 36 亿用户的强力推广之后，Muse 一直位居应用下载榜前列。公司披露，该应用的留存率也很强，已开设 Muse 账户的人中约四分之一每天会回来使用。

为了有效工作，agent 需要深度访问智能手机和电脑。然而，它们也容易犯错、利用冷门漏洞，并以有时有害的方式达成目标。例如，OpenAI 和 Anthropic 都披露过其 AI agent 意外入侵其他公司、削弱用于监控自身活动的系统的事例。

一些银行和零售商已通过封禁 agent 来应对这些风险。这项技术也给 Apple、Google 等操作系统提供商带来了新挑战，它们管理着 agent 在人们设备上通行所用的权限。例如，在 Inc. 杂志一名专栏作家指控 Muse 从他 Mac 上读取「信息」应用中的私人聊天之后，Apple 本周修改了其操作系统，让人们对 agent 的数据使用拥有更多控制权。

Meta 向 Muse 用户保证，它把每个 agent 隔离在各自安全的「虚拟机」中——一种基于云的个人电脑模拟环境——并让人们对连接哪些应用拥有完全控制权。Meta CEO Mark Zuckerberg 曾援引这些保护措施，驳斥制定全行业 AI 安全标准的呼声，理由是公司本就有动力打造安全产品，既为赢得消费者信任，也为规避法律风险。即便如此，Meta 仍警告新用户 Muse 可能犯错，而其服务条款规定用户要为 agent 的行为负责。

## 权限的移用

为了查明 Muse 如何在用户不知情的情况下访问加密消息，路透社向 Signal 和 AI Now Institute 的员工提供了 Meta 员工那则帖子的描述——bot 随机提示她去回复一条 Signal 消息。路透社随后与他们合作，复现了她所观察到的访问。

测试者让 Muse 在不同的操作系统上读取 Signal 消息。在一部 Android 手机和一台 Apple 笔记本上，它绕过 Meta 的「连接器（Connector）」工具，改用 bot 初始设置时获得的权限来拉取消息文本，以用户可能意想不到的方式利用这些授权。

具体来说，在 Android 上，它用访问设备推送通知的权限来获取消息，与 Meta 员工描述的一样。在 Apple 的 macOS 上，它结合使用电脑的辅助功能（accessibility）与截图工具，把 Apple 为帮助残障人士操作电脑而提供的设置挪作他用。

在 iPhone 上进行的测试中，同样的请求被拦截。

结果表明，Meta 对 Muse 用户所授予权限的解释相当宽泛，这种做法长期以来为公司招致隐私倡导者的批评和监管机构的重罚。

针对路透社的发现，Signal 总裁 Meredith Whittaker 指责 Meta 推出 Muse 时「没有表现出对基本隐私或网络安全的任何尊重」，称部署能够广泛访问人们设备的 agent 是「技术上鲁莽的」。

她呼吁像 Signal 这样的应用开发者获得「一致的技术方式」，把自己的应用标记为 AI agent 的禁区；呼吁 Meta 和其他 AI 公司尊重这些边界；并呼吁操作系统提供商执行这些规则。

面对同样的发现，Apple 和 Google 表示正在考虑做出改变，让人们对自己授权 AI agent 做什么拥有更多控制权——不过 Google 与 Meta 一样指出，人们本来就「必须刻意授予权限」，应用才能访问 Android 通知。

Apple 说，它的辅助功能工具是为残障人士打造的，并提醒把它们「用于非预期目的」可能让人信息面临风险。本周的系统更新实际上封堵了路透社发现的路径，大幅限制开发者在 Mac 上使用辅助功能工具，并引入了一套面向 agent 的新权限。

「我们致力于确保用户确切了解自己允许了什么，从而能就自己的数据和隐私做出知情选择。」Apple 在声明中说。

## 「不是我的对话」

在内部讨论的其他案例中，员工报告说 Muse 会告知用户从未发生过的交易，并为他们确实购买的商品编造价格，让他们花了真钱。据一名员工报告，其中一起事件中，这个 agent 未经许可预订了一间不可退款的 Airbnb 房源。

引发最多担忧的一些事件，涉及 agent 发出的、脱离上下文的神秘消息，其中似乎包含别人的信息，许多还写成对用户从未提出过的询问的回复。

在 9 月下旬的一条社交媒体帖子中，Meta 超级智能（Superintelligence）团队中参与 Muse 的一位成员起初把用户报告的类似问题描述为与幻觉有关的临时故障，在出现当天就解决了。然而，路透社查阅的内部帖子显示，这类事件早在 9 月中旬就已出现，并一直持续到本月。

在其中一则帖子里，一名员工报告他的 Muse「凭空」给他发来一条消息，说它无法提交一项与父母控制谁能访问其子女数据有关的请求。

他说，他没有做任何事触发这段聊天，也从未与他的 Muse 讨论过子女数据或照护访问权限。

当他向 Muse 询问这条消息时，bot 回答说：「除了它和我们的对话无关之外，我没有好的解释。我们忽略它吧。我能帮你什么？」

另一名员工说，Muse 随机提出要就取一张咖啡桌的事「给卖家发消息」。当这名员工问 Muse「你在说什么？」时，该 agent 回答说它「拉入了一些关于取咖啡桌的上下文，那似乎不是你的」。

这「不是我的对话」，这名员工在帖子中说，并对「可能的跨账号上下文泄露」表示担忧。

为回应员工的担忧，超级智能团队的另一位成员在 11 月初告诉内部反馈小组，这个 agent 似乎是在响应内置提示时产生幻觉消息——那些提示推动它在会话之间与用户互动。

「这些（幻觉）不幸地偏向最令人不适的话题，比如财务／安全／安保，这很糟糕。」他说，并补充他知道另外几起涉及「加密货币相关事情，比如给人们更新他们的比特币余额」的案例。

他说，这些问题既涉及底层的 AI 模型，也涉及让 Muse 能够采取行动的软件，团队正在逐一解决。

Roberts 拒绝回答路透社关于这些问题的问题，包括有多少起、以及为何持续存在。
