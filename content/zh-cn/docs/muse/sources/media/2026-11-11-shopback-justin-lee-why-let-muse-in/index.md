**内容摘要**：e27 于 2026 年 11 月 11 日对 ShopBack 首席产品官 Justin Lee 做了十问专访：Meta 在新加坡上线 Muse 时，ShopBack 是 8 个首批连接器之一，而亚马逊则在 Muse 上线 12 天内将其封堵。Lee 说，团队用两周建成了连接器，直接接入 ShopBack 的实时商家、价格与返现数据；ShopBack 是应 Meta 邀请加入新加坡上线，双方之间没有费用往来。归因机制不变：只有经 ShopBack 链接成交才计入佣金，由商家跟踪确认销售后，商家才按现有条款为确认的销售付费；商家可加码返现以争取智能体推荐，Lee 称“把事实交给智能体、由它决定”。责任划分上，若智能体订错不可退改的机票，购买按商家条款处理，ShopBack 只通过客服中心处理返现一侧；该连接器同时为多个智能体设计，文中另提到 OpenAI 的 Operator、谷歌的 Gemini Spark 与 Perplexity 的 Comet。记者认为，Lee 对“ShopBack 是否看到了亚马逊没看到的东西”一问的回答是外交式回答，并指出在 ShopBack 应用内查到同样优惠只是“一致性核查而非独立核查”。

**保留理由**：已收的 Meta 新加坡上线官方稿只点名 ShopBack 为 8 个早期本地连接器之一；本篇是 e27 对其首席产品官的十问专访，首次给出连接器两周建成、归因与佣金机制、商家加码返现、责任划分等一手说法。

亚马逊在 12 天内封堵了 Meta 的购物 agent。ShopBack 却在上线时就接入了。它的产品负责人解释了这个截然不同的赌注。

上个月 Meta 在新加坡启用 Muse 时，ShopBack 是该 agent 可以接入的八个首批连接器之一。在美国，亚马逊的看法不同。它在 Muse 上线 12 天内就将其封堵，理由之一是替顾客购物的 agent 绕过了其店铺内建的个性化。

ShopBack 是一家购物与返现平台，它选择接入而不是关门。其首席产品官 Justin Lee 说，web 是为供人阅读而建的，不是为供 agent 行动而建的。e27 向他提了十个问题，问他这对一家靠购物者与商家之间的缝隙谋生的企业意味着什么。他的回答显示出一次自信的押注。但也有一些事没说。

利害关系说起来很简单。购物与返现平台活在买方与卖方之间的缝隙里。一个能自行比价的 agent 可能完全绕过这道缝隙。Lee 的赌注是：agent 会把购物与返现平台留在流程里，因为返现本身就是最优交易的一部分。

## 两周时间，为一个从不扫读的读者写作

Lee 说，没有连接器时，agent 就像一个拿着搜索引擎的人一样购物，只是更快。它翻遍为人类眼睛设计的页面，从找到的任何东西里拼出答案。这行得通，但更慢，而且 agent 并不总能判断某个价格或返现是否仍然有效。

连接器用一条直通 ShopBack 实时数据的线路取代了这种猜测：商家、价格以及各自附带的节省金额。「建一个连接器意味着为一种新的读者写作，这种读者把一切照字面接受，并立刻据此行动。」Lee 说。他的团队用两周建成了它。

他把 Muse 描述成一条熟悉道路上的下一站。ShopBack 从网站走到应用、走到浏览器扩展，然后进入 ChatGPT 应用商店，在那里它是最早的购物与返现应用之一。被问到 ShopBack 是否看到了亚马逊没看到的东西时，Lee 拒绝挑起争端。「不同公司会为自己的业务做出不同选择。」他说。

这是对一个直白问题的外交式回答。亚马逊拥有店铺，所以它有底气把 agent 挡在外面。购物与返现平台不拥有任何货架。如果 AI 购物 agent 真如它们的支持者所预期那样重塑零售，那么成为 agent 购物时所使用的工具，多少是一种免于被绕过的保险。

## 同样的链接，同样的佣金，新的店面

联盟营销（affiliate commerce）靠归因运转：可追踪的点击、cookie、可见的推荐路径。Lee 坚持认为，当 Muse 来点击时，一切都没有改变。只有经由 ShopBack 链接成交，才计为 ShopBack 的销售，而那正是 Muse 给购物者的链接。商家自己的追踪确认销售，商家只按现有条款为已确认的销售付费。

那么对于 agent 本来也会做成的销售，佣金怎么算？Lee 辩称，agent 在回答之前会权衡多个商家。当 ShopBack 的返现改变了天平，「赢下这笔销售的就是返现」。这是经典的联盟营销辩护，与 Lazada 那笔 1 亿美元联盟营销投入背后的逻辑相同。但对于一个无论如何都可能选中该商家的 agent，这个说法更难证明。

关于客户归谁，Lee 解释说，一位通过 Muse 订机票的旅客是从航空公司购买的，航空公司出票并保有客户关系。Muse 是渠道，ShopBack 是返现层。

对于谁（ShopBack 还是 Meta）保留对话数据、以及是否与这家科技巨头之间有金钱往来，Lee 说：「Muse 如何处理对话，最好由 Meta 回答。在我们这一侧，ShopBack 从来看不到会员输入了什么。当 Muse 判断会员的请求需要 ShopBack 时，它会转向 ShopBack 连接器，连接器返回相关的选项与返现。」

至于支付，他声称 ShopBack 与 Meta 之间没有任何费用往来。「我们是应 Meta 邀请加入 Muse 新加坡上线的，因为我们一直在寻找更多回馈会员的地方，而个人 AI agent 正是越来越多会员开始购物的地方。」

## 返现后最便宜，还是对商家最有利？

Meta 自己的上线演示中，ShopBack 找出了返现后飞往首尔最便宜的往返机票。用户能核实这个答案真的最便宜，而不是来自支付最高佣金的商家吗？Lee 的回答是，agent 会看到每笔交易的价格与节省金额，并「基于事实」权衡它们。想核实的人可以打开 ShopBack 应用，在那里找到同样的交易。

那只是一致性核查，不是独立核查。应用与连接器使用同一份数据，所以在两处找到同样的答案，只能告诉购物者 ShopBack 前后一致，而不能说明它在整个市场上最便宜。

付费排名的问题得到了最有趣的回答。商家已经可以通过 ShopBack 加码自己提供的返现，Lee 说这部分加码会以更大节省的形式到达购物者。「我们把事实交给 agent，由 agent 来决定。」他说。这与「Muse 不在乎你的广告预算」的承诺如出一辙。

这话说得通，但比听起来要薄。加码是商家为了赢得 agent 的选择而花的钱，而当 agent 高度重视节省金额时，它最有效。对于已经担心「如果 AI agent 找不到你，你就不存在」的品牌来说，加码返现可能成为最便宜的「被找到」的方式。

## 当 agent 订错航班

Meta 因安全顾虑推迟了 Muse 在美国的上线，The Information 报道称，该 agent 在测试期间未经批准发送了邮件。那么，如果 Muse 用 ShopBack 的数据订了错误的不可退款机票，谁来赔？Lee 的回答是把购买归于商家，按商家的条款处理。ShopBack 只通过其客服中心处理返现那一侧。

这是一种干净的分工，可能也是法律上正确的做法。但它也正是那种让自主 agent 的责任归属变得如此模糊的交接。Lee 用更宽泛的说法承认了这一点。「我相信信任将决定人们是否会用 agent 购物。」他说，并补充行业必须明确谁做什么。在一个新加坡企业在 AI agent 部署与回滚方面领先亚太的市场里，这份清晰不是可选项。

## 管道还是目的地？Lee 说两者都是

返现的吸引力很大程度是情绪性的：用户看到返现，觉得自己精明，然后回来。Lee 说，如果由 agent 来完成购物，那份满足感只是转移到了答案里，Muse 会展示每个酒店选项能省多少。会员仍然在 ShopBack 里累积返现，并通过 ShopBack Pay 在网上或店内消费——这款产品背后是它从 MAS 取得的 MPI 牌照。

更大的担忧是沦为别人界面的后端管道，尤其是在 ShopBack 自建 AI 工具之际。联合创始人 Henry Chan 曾描述过为一次航班查询搜索 15 家零售商。Lee 不接受这种二选一。连接器与应用运行在同一套服务上，所以改进一个也就改进了另一个。应用——连同其 Travel Planner 等工具——仍然是会员提现、以及偶然撞见自己没想要的优惠的地方。

Muse 也有对手：OpenAI 的 Operator、Google 的 Gemini Spark 和 Perplexity 的 Comet。ShopBack 的连接器设计为可与多个 agent 配合。那是什么阻止它变成一个可替换的插件？Lee 指向会员自己的账户与余额、商家合作关系，以及十多年来对人们如何购物的理解。这条护城河是真实的，但未经检验。正如 Lee 反复所说，agent 天生就是要找最好的答案。哪天对手给出更丰厚的返现，agent 会不带忠诚地报告这个事实。ShopBack 赌的是自己能靠事实持续获胜。在 agentic 商业里，这也许是唯一可下的赌注。
