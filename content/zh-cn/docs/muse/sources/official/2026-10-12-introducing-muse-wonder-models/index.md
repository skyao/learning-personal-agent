## 要点

- Meta 推出 Muse Wonder 和 Muse Wonder Full，这是我们迄今能力最强的模型，旨在个人和职业领域的智能体任务上提供最先进的性能：从处理保险理赔、理解租约，到构建一个可用的应用。
- Muse Wonder 从今天起通过 Meta Model API 和 Muse Code 向开发者和构建者开放，而 Muse Wonder Full 从今天起向 Muse Code 订阅用户开放。
- Muse Wonder 将很快为 [Muse](http://muse.ai) 中的体验提供支持，并将首先向订阅用户推出。

十四个月前，我们开始全面改革我们的 AI 工作，在这段时间里，我们从重建基础走到了推动前沿。今天，Meta 推出 [Muse Wonder](http://research.meta.ai/blog/muse-wonder) 系列，包括 Muse Wonder 和 Muse Wonder Full，这是我们迄今能力最强的模型，建立在我们通过 [Muse Spark](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/) 打下的基础之上。这些模型在个人和职业领域的智能体任务上提供最先进的性能。

## 为现实世界的需求而打造

无论这项工作是处理保险理赔、理解一份租约，还是弄清某人的财务状况，模型都必须解读眼前的信息并把问题处理到底。Muse Wonder 和 Muse Wonder Full 把这种能力带到了法律、金融和健康等专业领域，同时具备前沿的编程性能，供那些构建从游戏到新生意所需应用等各种东西的人使用。

真实的工作也是随着时间展开的。这就是为什么我们让新模型具备主动记忆（Active Memory），也就是把对你重要的东西带到不同的对话中，并调回与手头任务相关的细节的能力。它们还具备主动专注（Active Focus），也就是在任务变得困难时持续朝着你的目标工作、尝试其他方法、从错误中恢复并贯彻到底的能力，在需要时请求澄清，并在执行任何重要事项之前先与你确认。

## 我们如何为安全而构建

一个个人智能体可以为你承担真实的任务，这通常意味着要在你的消息、日历和文档之间开展工作。这就是为什么我们训练 Muse Wonder 系列：避免在未经许可的情况下分享私人信息；拒绝协助实施真正有害行为的请求；并努力提升安全性、加强对网络攻击的防御。开发者和安全团队可以使用 Muse Wonder 这样的模型来发现自己代码中的缺陷并加固系统，所以我们确保这些模型仍然能做这项工作。我们按照 [Meta 超级智能扩展框架](https://research.meta.ai/blog/developing-capable-models-responsibly)（Meta Superintelligence Scaling Framework）中规定的标准来训练、评估和发布我们能力最强的 AI 模型。一份包含更多安全评估的完整报告将很快发布。

Muse Wonder 从今天起可通过 Meta Model API 和 Muse Code 使用。它将很快为 [Muse](https://muse.ai/) 的更多部分提供支持，首先向订阅用户推出。这是朝着为每个人提供个人超级智能迈出的重要一步，未来还有更多。
