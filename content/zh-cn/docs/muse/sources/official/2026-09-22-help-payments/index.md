Muse 可以帮助你在网上购物。在完成一次购买之前，它总是会请求你的批准。在批准购买之前，务必在商家网站上核实购买细节和商家条款。购买能力可能因你所在的地区、商家和结账流程而有所不同。所有订单都由你购买的商家履行。

## 你的 Muse 如何进行购买

Muse 可以通过不同的方式帮助你完成购买：

* 使用 Stripe 的 Link 付款（推荐）

  Link 通过为每次购买签发一个一次性卡号来保障你的付款安全，让你的真实卡号保持私密。当你使用 Stripe 的 Link 时，Stripe 会对符合条件的购买提供损坏、盗窃、丢失、降价和退货方面的保障。查看更多关于 Stripe 的 Link 以及[完整保障细节](https://support.link.com/questions/what-s-covered-with-protections)的信息。

* 登录你的账户并使用已保存的信用卡付款

  当 Muse 使用保存在安全凭证存储（Secure Credential Store）中的凭证代表你登录时，Muse 可以代表你进行购买。在完成一次购买之前，Muse 会请求你的批准。当 Muse 代表你登录时，请始终对它进行监督，并在批准之前核实所有交易细节。当 Muse 使用浏览器时，你可以在任何交易之前查看 Muse 所看到的网站。

你要对你的 Muse 代表你进行的所有交易负责。请留意电子邮件确认、收据和账单。
