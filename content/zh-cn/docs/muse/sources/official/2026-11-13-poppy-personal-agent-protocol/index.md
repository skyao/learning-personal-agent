**内容摘要**：Meta 发布 Personal Agent Protocol（Poppy）1.0，这是一项规范个人智能体如何与商家协作的开放标准，Muse 是首个支持 Poppy 的个人智能体。协议由 Meta 与 Sierra、Genesys、NiCE、Decagon、Rocket、Shopify、Stripe、Walmart 等行业伙伴共同开发。商家通过发布名为 `poppy.json` 的文件说明自身服务与接入方式，可从纯网站起步、逐步扩展能力，并用配套实施工具包中的验证工具与清单测试。Poppy 让商家识别使用协议的个人智能体、按任务引导其走网站、API 或商家自有智能体，并把网站活动、API 调用与商家智能体对话统一到同一会话中；客户通过 OAuth 在商家自己的页面登录授权，权限可撤销。首批落地商家包括 BYLT、Mercury 与 Hertz，其中 Mercury 客户可查账、分类支出并请求付款或转账，Hertz 客户将可查询、更改与延长租车预订。

**保留理由**：Poppy 1.0 发布的官方一手出处，完整给出商家接入方式与首批落地名单，是协议发布事实的权威记录；与 Sierra 的 1.0 公告互补（官方口径与合作方落地细节各执一端）。
