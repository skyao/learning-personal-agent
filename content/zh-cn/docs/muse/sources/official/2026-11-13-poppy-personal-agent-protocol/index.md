- 我们正在发布个人智能体协议（Personal Agent Protocol，“Poppy”）的第一个版本，这是一项关于个人智能体如何与企业协作的标准。
- Muse 是第一个支持 Poppy 的个人智能体，已有企业在使用它来帮助客户购物、获得解答和管理预订。
- 任何企业如今都可以实施 Poppy，从对自己有用的能力入手，并随时间增加更多能力。

人们开始把日常任务交给个人智能体，而其中许多任务最终落在某家企业：预订旅行、重新订购杂货、退一件夹克，或者只是得到一个问题的答案。企业希望把这些客户服务好，而在此之前，一直没有一种标准的方式来识别个人智能体并为其引路。

个人智能体协议旨在弥合这一差距，它是一项开放标准，规定个人智能体如何与企业协作，无论是通过网站、API，还是与企业自己的智能体直接对话。我们上个月预览了它，今天我们发布个人智能体协议的 1.0 版。Muse 是第一个支持 Poppy 的个人智能体。

我们正与 Sierra、Genesys、NiCE、Decagon、Rocket、Shopify、Stripe 和 Walmart 的行业伙伴，以及此后加入这项工作的其他设计合作伙伴一起开发 Poppy。我们的伙伴在零售、支付、客户服务等领域经验丰富，为任何企业或个人智能体提供商都可以在其上构建的共同标准贡献力量。

我们的目标是让人们更容易通过 Muse 把事情办成，也让企业更容易服务这些同样的客户。

Poppy 是我们构建 Muse 网络（Muse network）的方式之一——随着更多消费者拥有自己的 Muse、更多企业与 Muse 集成，人们可以通过 Muse 做更多的事。

## 如何开始

Poppy 的技术说明是公开提供的。任何企业都可以通过其网站以及已有的任何系统或 API 来构建支持。[企业实施工具包](https://personalagentprotocol.org/kit/company)帮助团队规划、构建和测试其设置。

**发布你的 Poppy 文件，并设置你所选择的能力。** 一个名为 `poppy.json` 的文件告诉个人智能体你的企业提供什么以及如何联系你：你的网站、你的 API 或 MCP 服务器，或者你自己的智能体。仅有网站的设置可以从发布这个文件开始，而无需添加客户登录。API、登录和企业智能体对话需要工具包中所述的相应设置。

**选择、测试并扩展。** 从一项客户任务开始（例如查询订单）。选择要通过你的网站、现有 API 或你的企业智能体提供的能力和权限。使用工具包的验证工具和清单在测试环境中测试你的设置，然后随时间增加更多。

## 引导智能体如何与你的企业协作

当客户请求 Muse 与你的企业协作时，你应该能够引导该请求如何被处理。Poppy 为你提供了指引智能体和管理其访问权限的方式。

**识别真实客户，而不是把他们拒之门外。** 每一次 Muse 的访问背后都有一位客户，而如今，许多企业难以区分代表真实客户行事的个人智能体与不受欢迎的自动化流量，于是把两者都阻止了。Poppy 让你可以识别使用该协议的个人智能体（从 Muse 开始），并放行它们。

**引导智能体，获得更快、更准确的结果。** 你不必让智能体靠反复试错来摸索，而是可以针对每项任务把它引向最合适的路径。那可能是你的网站、用于搜索或下单的 API，或是你自己的支持智能体，用来处理需要真正答案的问题。

**客户旅程的统一视图。** Poppy 把他们的网站活动、API 调用和企业智能体对话连接在同一个会话中。你看到的是完整的交互，而不是互不相连的片段。当客户登录时，这些活动还可以与其账户关联起来。

**让客户授予和管理访问权限。** OAuth 让客户在你自己的页面上登录并授予访问权限，而在该流程中智能体不会接触他们的密码。权限范围由你定义，客户选择授予什么，并且访问权限可以被撤销。

**你的智能体仍是专家。** Muse 现在可以与你的支持或销售智能体交谈，或直接把客户交给它。你的智能体给出你的权威答复，客户无需重复自己说过的话。

## 在 Muse 中的样子

以下企业是最早把 Poppy 与 Muse 配合使用的企业之一。除它们之外，许多其他企业和合作伙伴也在帮助塑造该协议，并开发通过个人智能体服务客户的方式。我们很高兴欢迎更多企业加入，并扩展人们通过 Muse 能办成的事情。

- **BYLT。** 不久之后，Muse 可以与 BYLT 的智能体（用 Meta Business Agent 构建）直接对话，帮助客户查找产品、提问、查询库存情况并建立购物车。
- **Mercury。** Muse 可以通过 Sierra 与 Mercury 连接，借助 Poppy 帮助客户管理财务。Mercury 的客户可以查询企业和个人账户的余额与交易、对支出分类、请求付款或转账等。\*
- **Hertz。** Muse 将能够通过这家租车公司与 Decagon 的 Personal Agent Gateway 进行的试点，查询、更改和延长 Hertz 的预订，为租车人提供一种管理预订的新方式，同时带来无缝的体验。

## 一项将持续改进的开放标准

任何人都可以在 [personalagentprotocol.org](https://personalagentprotocol.org/) 开始，在那里可以阅读有关该协议的内容，并找到[企业实施工具包](https://personalagentprotocol.org/kit/company)。Meta 验证的连接器（connector）将接受功能、安全和法律要求方面的审查，并完成端到端测试：如果你有 API/MCP 等面向智能体的就绪界面，请在 [platform.muse.ai](https://platform.muse.ai/) 申请。我们将继续根据企业和使用 Muse 的人们的反馈来开发 Poppy。

\*Mercury 不是银行。银行服务由 Mercury 的受 FDIC 保险的合作银行提供。
