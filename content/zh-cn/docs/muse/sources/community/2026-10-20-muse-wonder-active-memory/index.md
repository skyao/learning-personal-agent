## 内容摘要

文章以 Meta 2026 年 10 月 12 日发布 Muse Wonder 及其大号版本 Muse Wonder Full 开篇：扎克伯格在发布前数小时贴出一张西瓜照片，称是自己的 Muse 助手发来的，调侃模型内部代号。Wonder 与 Wonder Full 是 Meta 超级智能实验室为个人与专业智能体工作打造的首批自称前沿的模型，两项核心能力是 Active Memory（跨对话携带关于用户的上下文）与 Active Focus（任务变难时持续工作、尝试其他方法、从错误中恢复、在重要动作前确认）。作者的原创测算是价格表：Wonder 经 Meta Model API 定价为每百万输入 token 4 美元、每百万输出 token 20 美元，上下文窗口约 100 万 token；取 20 万 token 的记忆规模，每次请求仅记忆一项输入成本即 0.80 美元，每天 50 次请求则为每天 40 美元、每月约 1200 美元，而消费级 Muse 的 Power 为每月 20 美元、Maximum 为每月 100 美元，因此 Meta 不可能把全部历史塞进上下文，Active Memory 必然是选择性检索。Meta 官方记分卡：Harvey 法律智能体基准上 Wonder Full 通过率 13.1%、Wonder 10.0%、最接近的对手 GPT-6 Astra 8.6%；Artificial Analysis 智能指数 Wonder 52、Wonder Full 56、Claude Opus 5.5 为 58。可用性星号是：基准胜出的 Wonder Full 不在 API 上架，仅存在于 Muse Code 订阅内；Wonder 本身进入消费级 Muse 智能体的时间是“即将”，先向订阅者推送。

## 保留理由

这是唯一一篇讨论 Wonder 模型与 Active Memory 的文章；每月 1200 美元的记忆成本测算、13.1%/10.0%/8.6% 的 Harvey 基准对照、Wonder Full 不在 API 上架的可用性星号，是已收资料里没有的模型事实。

Meta 于 10 月 12 日发布 Muse Wonder 的数小时前，Mark Zuckerberg 贴出了一张西瓜照片。他说这是自己的 Muse 助手发给他的，借此调侃该模型的内部代号。可爱，也有信息量，因为被调侃的不是一个更快的模型或更便宜的模型，而是一个会记忆的模型，而这份记忆的第一件公开产物，是一个人与他的智能体之间的私人玩笑。

记忆是机器能给你的最私密的东西，因为任何人都能回答一个问题，而正是记忆把工具变成了关系，而关系正是设计问题变得不舒服的地方：它保留什么、你如何纠正它、以及它记错时会发生什么。

所以来看看 Meta 实际交付了什么。Muse Wonder 及其更大的兄弟 Muse Wonder Full 是 Meta 首批称为前沿（frontier）的模型，由其超级智能实验室为个人与专业智能体工作打造：读租约、理清理赔、理解财务或健康信息、构建软件，而[两项能力承载了整个卖点](https://siliconangle.com/2026/10/12/meta-releases-muse-wonder-ai-models-built-to-run-personal-and-professional-agents/)：Active Memory（主动记忆）在对话之间携带关于你的上下文，并在任务需要时检索相关细节。Active Focus（主动专注）在任务变难时继续工作，尝试其他方法，从错误中恢复，并在做任何重要事情之前先确认。

Meta 研究科学家 Kavya Kopparapu 在发布视频中说得直白：「投入了巨大的努力，确保你的模型能在数天、数周、数月乃至更久的时间里记住对你重要的东西。」[这是一句可爱的话。](https://pondero.ai/news/2026-10-13-meta-muse-wonder/) 它也是一个关于工程的说法，值得用算术来核对。

## 价格表就是一份自白

Wonder 经 Meta Model API 提供，每百万输入 token 4 美元，每百万输出 token 20 美元。它接受约 100 万 token 的上下文窗口。做个乘法，完整读一次百万 token 的上下文要 4.00 美元。现在想象 Meta 所描述的那种记忆——一份关于你生活的、被带进每次请求的工作记忆——给它一个适中的规模：20 万 token 的偏好、项目与持续约束。

这份记忆在每次请求上要花 0.80 美元的输入费用。按每天 50 次请求——对于真正把生活交给智能体的人，这是一个合理的数字——仅记忆一项每天就要 40 美元，累积到每月 1200 美元。

~每月 1200 美元

把 20 万 token 的记忆带进每天 50 次请求，按 Muse Wonder API 价格（每百万输入 4 美元）计算要花多少钱，对比每月 20 美元的 Power 与每月 100 美元的 Maximum 固定订阅。

消费级 Muse 的 Power 每月 20 美元，Maximum 每月 100 美元。按 API 价格，Maximum 大约只够 125 次携带记忆的请求，之后 Meta 就在你身上亏钱，而这还只是输入，尚未算上每百万 token 20 美元输出的任何一个字。没有人会交付一款记忆成本是订阅费十二倍的产品，这意味着 Meta 并没有把你的历史整包塞进上下文，因为它做不到；Active Memory 必然是选择性检索，一个找到你生活中相关那一小片、只把那一小片带进房间的系统。

Meta 自己的措辞与算术一致：Active Memory「在需要时检索相关细节」，不是在被要求时，而是在需要时，这意味着某个系统要在模型看到问题之前，就从你数月的生活中决定什么是相关的。这个检索层就是整个产品，因为模型是读者，检索是图书管理员，而图书管理员会做判断。

## 随着堆头变大，回忆会腐烂

这里独立证据开始不配合。2025 年 7 月，Chroma 发布了一份叫「上下文腐化」（Context Rot）的技术报告，让 Anthropic、OpenAI、Google 与阿里巴巴的 18 个模型做在任何长度下都应当微不足道的任务：在一段长文本里找一个事实，复制一串重复的词而其中夹着一个异类词。Chroma 的总结很直白：在所有实验中，模型表现都随着输入长度增加而持续下降。[最尖锐的结果使用了 LongMemEval，即对一段长聊天历史用两种方式提问。](https://www.matthewswong.com/en/blog/ai-agent-harness-engineering-research/) 在约 300 token 的聚焦上下文中，Claude Opus 4 得分 0.92，而在包含同样答案的完整 113,000 token 历史中，它跌到 0.38：信息相同，差别只在堆头。

Anthropic 自己 2025 年 9 月发布的工程指南毫不回避地指出了机制：有限的注意力预算，每个 token 都花掉其中一丝，而位置编码在序列越长时越模糊。公司称上下文腐化是一条性能梯度而非悬崖，存在于每个模型中，而更大的窗口不能解决它，因为更大的窗口只是更大的堆。

Meta 知道这一点，其 MemoryBench 评估在 64,000 至 100,000 token 的多轮对话中的回忆，其中穿插干扰轮次与中途变化的事实。这是一个严肃的测试设计，也是 Meta 对自家说法的自家测试，在广告中百万 token 窗口的十分之一规模上运行，且尚无独立复现，也就是说：承诺不等于证明。

## 基准说了什么，没说什么

在 Meta 的记分卡上，Wonder Full 在 Harvey 的法律智能体基准上通过了 13.1% 的任务，该测试只有满足每项标准并通过幻觉检查的交付物才算数，而 Wonder 得 10.0%，最接近的对手 GPT-6 Astra 得 8.6%。在 DeepSWE 1.1 这个长程编程测试上，Wonder Full 以 79.0 对 78.8 略胜 Wonder，那是穿着实验服的噪声。在 AutomationBench-AA 端到端业务流程上，Wonder Full 以 45.4 对 39.1 领先 Wonder。在 Artificial Analysis 智能指数上，Wonder 得 52，Wonder Full 得 56，都落后于 Claude Opus 5.5 的 58。

读一读模型卡的小字，因为 Meta 把它写进去了：竞争对手的运行是尽力而为，「提示与工具可能没有为它们做过最优调校」。这是一个诚实的限定说明，在一份自信的公告里安静地起作用。它意味着这份排行榜是 Meta 给自家作业打分，而对手的卷子由一位疲惫的助教批改。

然后还有可用性上的星号，而它起的作用更大声。赢得基准的模型 Wonder Full 不以任何价格上架 API；它存在于 Muse Code 订阅之内，而 Wonder 本身要「即将」才进入消费级 Muse 智能体，先向订阅者推送。被庆祝的东西，在它为之而造的产品里尚不存在。你读到的是一场回忆的预览。

## 支持它的最强论证

这一切都不是致命的，而反方论证值得完整的权重。选择性检索不是妥协；它是正确的架构，而揭示它的价格算术同时也为它辩护。一个在模型阅读之前就决定什么相关的系统，正是有限注意力预算所要求的。Meta 专门在多样、长时间运行的任务上训练这些模型，以在测试与修订的循环中维持努力，通过自家的 FocusBench 评估专注、通过 SWE-Marathon 评估执行，并在 Prometheus 数据中心以吉瓦级规模建成了整个东西。公司还在三天后交付了开放权重兄弟模型 Muse Spark Open：8160 亿参数，百万 token 窗口，可下载，在 Meta 的演示中运行于两台 Mac Studio 上。无论你怎么看闭源旗舰，这个实验室在公开地展示自己的工作。

而且这种设计直觉是对的，因为一个会请求澄清、在重要行动前先确认的智能体，正是为个人智能体的真实失败模式而造的，那不是愚蠢，而是自信的越界；Active Focus 读起来像是对每一场「机器平滑地做错事」的演示灾难的回应，而如果记忆有宣传的一半好，与它共处会感觉不像操作软件，而更像被了解——那才是值得渴望的承诺。

## 我未能核实的内容

诚实要求记账。我没有测试 Muse Wonder，因为消费级推送在发稿时尚未到达它，而所有基准数字都是 Meta 的，未经独立复现。记忆预算的计算使用示例输入：20 万 token 的记忆是我的估计，不是 Meta 的披露，每天 50 次请求描述的是一位重度用户。API 价格不是 Meta 的内部推理成本，缓存折扣会软化这些数字，但不会改变数量级。Chroma 的上下文腐化测量使用的是 2025 年中的模型；我没有找到已发表的研究表明这一效应在当前模型中已经消失，而 Anthropic 的指南仍把它当作实际约束。MemoryBench 的干扰轮次设计确实是对抗性的，这一点两面都成立：它是对的测试，也是他们的测试。

## 实际该做什么

不要为了记忆而升级到 Maximum，至少现在还不要：能证明它值得的模型还不在消费级产品里，也没有独立测试衡量过它的回忆。等它到来时，把第一个月当作试镜：让它回忆几周前的某件具体事情——你只说过一次的约束、埋在一段旧对话里的偏好、你后来更正过的事实——然后看它检索的是更正还是原文，因为无法忘掉被取代事实的检索不是记忆；那是记仇。

尽早问那些不客气的问题：到底存了什么、存在哪里、存多久，你如何看到它、如何删除它，以及当它自信地记住一件从未发生的事时你如何纠正它。Meta 称 Wonder 是迄今最对齐的模型，经过训练以保护私密信息并抵御恶意指令，这一点之所以重要，正因为这个智能体会持有你的消息、你的日历、你的文件。对齐声明应当得到与基准声明同样的对待：有趣、未经复现、待定。

那张西瓜照片很迷人，但注意它展示了什么：智能体记住了一件私人的事，主动把它呈现出来，取悦了它的用户，而这三步中的每一步都是某个人就你的生活做出的设计决定。取悦是容易的部分；困难的部分是那个月，它记住了你需要它忘掉的事，而你发现图书管理员是否接受请求。
