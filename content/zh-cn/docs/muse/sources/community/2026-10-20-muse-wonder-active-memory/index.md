## 内容摘要

文章以 Meta 2026 年 10 月 12 日发布 Muse Wonder 及其大号版本 Muse Wonder Full 开篇：扎克伯格在发布前数小时贴出一张西瓜照片，称是自己的 Muse 助手发来的，调侃模型内部代号。Wonder 与 Wonder Full 是 Meta 超级智能实验室为个人与专业智能体工作打造的首批自称前沿的模型，两项核心能力是 Active Memory（跨对话携带关于用户的上下文）与 Active Focus（任务变难时持续工作、尝试其他方法、从错误中恢复、在重要动作前确认）。作者的原创测算是价格表：Wonder 经 Meta Model API 定价为每百万输入 token 4 美元、每百万输出 token 20 美元，上下文窗口约 100 万 token；取 20 万 token 的记忆规模，每次请求仅记忆一项输入成本即 0.80 美元，每天 50 次请求则为每天 40 美元、每月约 1200 美元，而消费级 Muse 的 Power 为每月 20 美元、Maximum 为每月 100 美元，因此 Meta 不可能把全部历史塞进上下文，Active Memory 必然是选择性检索。Meta 官方记分卡：Harvey 法律智能体基准上 Wonder Full 通过率 13.1%、Wonder 10.0%、最接近的对手 GPT-6 Astra 8.6%；Artificial Analysis 智能指数 Wonder 52、Wonder Full 56、Claude Opus 5.5 为 58。可用性星号是：基准胜出的 Wonder Full 不在 API 上架，仅存在于 Muse Code 订阅内；Wonder 本身进入消费级 Muse 智能体的时间是“即将”，先向订阅者推送。

这是唯一一篇讨论 Wonder 模型与 Active Memory 的文章；每月 1200 美元的记忆成本测算、13.1%/10.0%/8.6% 的 Harvey 基准对照、Wonder Full 不在 API 上架的可用性星号，是已收资料里没有的模型事实。
