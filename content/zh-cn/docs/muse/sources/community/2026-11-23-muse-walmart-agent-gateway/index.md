**内容摘要**：据 The Verge 记者 Jess Weatherbed 2026 年 11 月 23 日的报道，沃尔玛 Agent Gateway 已上线并支持 Muse，可在对话内用沃尔玛账户保存的卡按 Walmart.com 的价格结账购买黑五特价商品，并适用沃尔玛的退货政策；作者依据沃尔玛 10 月 21 日的文章核对了 Agent Profiles、消费上限与审批等控制机制。购物流程分三步：告诉 Muse 需要什么、首次加购时在沃尔玛账户内设置 Agent Profile 与消费上限、最后在对话内完成结账；审批默认为必需，用户可要求每次购买都审批，或允许智能体在设定的消费上限内购买，文中以 50、100、200 美元为例，沃尔玛还可能在限额内要求额外审批。Agent Profile 在智能体首次通过网关购物时自动创建，由沃尔玛登录授权，可随时删除，智能体的购买单独显示；智能体收不到用户的银行卡信息，也不能增改支付方式，智能体看到的价格与人类在 Walmart.com 上看到的相同。作者同时记录了未核实之处：上线日期在 11 月 23 日当天两度变动，沃尔玛先称推迟至 11 月 24 日、后又称仍于 11 月 23 日推出；当日未找到 Meta 的官方文章与用户实际完成购买的报告，沃尔玛官网的网关页面仍称该项目为仅限邀请的早期测试版；亚马逊与 eBay 则已阻止 AI 智能体浏览其平台。

**保留理由**：这是对沃尔玛 Agent Gateway 上线首日的逐项核查记录，区分了已确认与未核实的信息，并逐条列出 Agent Profiles、消费上限与审批规则的依据来源，是已收官方材料之外的独立核查视角。
