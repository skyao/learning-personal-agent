## 什么是 Muse？

Muse 是 Meta 推出的个人 AI Agent，住在云端的一台独立电脑里，能用浏览器、自己装工具、自己写代码，把你交代的任务做完。

它主要解决：

1. 每天重复的内容生产（做视频素材、写标题标签）
2. 多账号定时发布（X、Threads、IG）
3. 博客动态维护和 SEO/GEO 检查

目前主要应用于自媒体自动化运营场景。

## 为什么选择 Muse？

| 方案 | 价格 / 成本 | 特点 | 稳定性 |
| --- | --- | --- | --- |
| Muse（本次实测） | 免费额度内 0 元（一周用了 82%） | 一句话交代任务，它自己拆解执行 | 视频号直发曾频繁失败，后改 CunFetch 中转解决 |
| 手动运营 | 0 元，每天几小时时间成本 | 完全可控 | 看个人精力，长期坚持很难 |
| 传统定时脚本 | 服务器费用 | 规则写死，不会变通 | 脚本挂了只能自己修 |

## 准备工作

开始之前需要：

- 一个 Muse 账号（注册就行）
- 要自动化的平台账号（X、Threads、IG 等）
- 能部署 Cloudflare Worker 的环境（可选，给 CunFetch 中转用）

预计时间：半天搭通
难度：⭐⭐

## Muse 自动化工作流教程

### 第一步：注册 Muse，给它一个具体任务

别说"帮我运营账号"，要说"每天 8:30、11:30、18:30 各做一条 10 秒科技短视频，打包上传到 CunFetch"。任务越具体，它执行得越稳。我的感受是：一开始给的任务太笼统，返工了好几次。

### 第二步：搭一个中间存储（CunFetch）

Muse 住在云端电脑里，文件到不了你本地。我自己写了个开源的 CunFetch，部署在 Cloudflare 上（用它的免费存储），给 Muse 一个 API Token，它就能把做好的视频、封面、标题 JSON 传上来。

### 第三步：登录各平台账号

X 和 Threads 让 Muse 用它自己的浏览器登录后发布；IG 走官方 API。Threads 每次发布要点一次确认卡，这个绕不过去。

### 第四步：本地定时拉取并发布

Windows 定时任务在发布前把 CunFetch 里的新素材拉下来，我用自己写的 CunPush 做一站式分发。目前视频号我是手动点发布——之前让它自动发，十次里总有几次失败，不如手动稳。

## 我的测试体验

测试环境：

- 使用时长：7 天
- 任务内容：视频素材 3 档/天，X/Threads/IG 定时发帖，博客动态维护

✅ 好的方面：

- 到点就干活，一周没落下过一次
- 博客动态、SEO 检查这种杂活也顺手做了
- 免费额度完全够用，一分钱没花

❌ 不足的地方：

- 机房动态 IP，小红书直接登录不上
- 视频号登录态只能维持一两天，要重扫
- 账号能不能做起来，看的是运营思路，不是自动化

## 常见问题 FAQ

### Muse 多少钱？

免费版实测一周用了 82% 额度，平台还送了 310 亿词元，一分没动。按我的用量，免费完全够用（本次实测）。

### 新手怎么开始？

注册 Muse，发一句话任务，看它执行。先从最小任务开始，比如"每天早上 8 点半提醒我"，跑顺了再加码。

### 在中国大陆能用吗？

Muse 本体本次在境外 IP 环境下实测可用，大陆直连情况本次没测。另外注意：Muse 的云电脑是机房动态 IP，小红书直接封禁这个 IP 段，登录不上。

### 任务失败了能救吗？

能。我之前让它直发视频号，频繁失败；改成"CunFetch 中转 + 本地手动发"后就稳了。自动化链路里加一层缓冲，容错率高很多。

### 有什么风险？会封号吗？

有三点：一是机房 IP 发帖，平台风控可能比家用 IP 严，X 一旦出现验证或限流提示立刻停手；二是视频号登录态只能维持一两天；三是别把 admin 账号密码给它，只给 API 权限。

### 一定要用 CunFetch 吗？

不用。任何"Muse 能上传、你能下载"的中间存储都行，网盘、对象存储都可以。CunFetch 是我自己写的开源方案，GitHub 搜 CunFetch 就能找到。

### 火柴人视频 skill 是什么？

kaomei 开源的 stickman-video-director，我"喂"给了 Muse，让它按导演提案加分镜提示词的流程出火柴人视频。目前还在测方向。

## 总结

通过实际测试：

1. 一周 7 天，3 档视频素材加 7 次定时发帖全部自动完成，免费额度只用 82%（本次实测）。
2. 自动化解决的是"动手"问题，解决不了"动脑"问题——账号起不起得来，看运营思路。
3. 机房 IP 是硬伤：小红书上不去，视频号要频繁重登，方案设计时要留缓冲层。

如果你的需求是把重复的内容工作自动化，Muse 是一个值得尝试的方案；如果你指望它直接把账号做起来，建议先补运营思路，或者找个运营高手合作（比如我，我负责自动化）。
