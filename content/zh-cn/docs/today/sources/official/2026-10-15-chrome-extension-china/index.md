## 概述

将 Chrome 连接到 Today 中国服务，在已登录的网站中读取页面、点击和填写表单。需要中国大陆手机号账号；不适用于 today.ai 国际服务。

Today AI 中国版是 Today 的 Chrome 插件。安装并登录后，Today 可以读取你已打开的标签页，在你已登录的网站中打开页面、点击、输入和填写表单，并把结果交回 Today 客户端。
多网页对比
同时打开几个网页时，可以让 Today 一起读取，整理成一张对比表。例如：“比较我打开的三套房源，列出月租、面积、离地铁多远和押付方式。”不需要逐页复制内容。
网页操作与表单填写
Today 可以在已连接的 Chrome 中打开页面、点击、输入和选择选项。你可以说明任务做到哪一步为止，例如：“把这张报名表填好，先不要提交。”支持的操作取决于具体网站和任务。
历史记录与书签查找
任务需要时，Today 可以搜索你的浏览历史和书签，找到之前看过或保存过的页面。
开始使用
1. 安装「Today AI 中国版」。
2. 点开插件，点击登录，登录你的 Today 中国服务账号。
3. 等插件显示已连接，回到 Today 客户端或 https://todayai.cn，用同一个账号，让 Today 用已连接的 Chrome 完成任务。
使用要求
需要 Today 中国服务账号，当前登录支持中国大陆手机号。可用功能与使用额度以你的中国服务账号为准。任务执行期间，请保持 Chrome 运行且插件处于连接状态。你可能还需要登录任务涉及的网站。
本插件用于 https://todayai.cn 中国服务。使用 https://today.ai 国际服务的用户，请安装「Today AI」。两个插件连接各自服务的登录和 API 端点，使用独立的账号会话；本插件不能切换为国际服务。中国服务由汇翮（上海）智能科技有限公司运营，适用中国区服务协议和隐私政策。
隐私与控制
浏览器任务可能将网页内容、截图、网址，以及相关的浏览历史或书签查询结果发送给 Today 中国服务进行处理。插件还会保存连接浏览器所需的登录和连接信息。为排查登录和连接问题，插件会向 Sentry 发送经过脱敏的登录诊断，例如版本、流程阶段、耗时和错误分类。这些诊断事件不包含账号详情、网页内容或网址、令牌、授权码及 PKCE 密钥。你可以在插件中退出登录，或在 Chrome 中停用、移除插件，以断开此浏览器。断开连接不会自动删除已经发送的数据。有关数据使用和你的选择，请参阅本商店条目链接的隐私政策。
