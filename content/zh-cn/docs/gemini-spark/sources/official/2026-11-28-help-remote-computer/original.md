Gemini can use a remote computer to run code and handle complex tasks. If you turn on network access for the remote computer, Gemini can also install software, download data, and connect to online services to do even more. For example, it can help you:

- **Process documents & data:** Extract figures from PDFs, stream and analyze large datasets, and run heavy-duty CSV or tabular operations.
- **Track & chart live public data:** Connect directly to live data feeds (like weather, market rates, or earthquake monitors) to analyze real-time trends and generate interactive charts.
- **Create & edit multimedia:** Download open-source video and audio tools on the fly to trim recordings, generate subtitles, and produce clips with animated waveforms.

**Important:**

- For now, this feature and its settings are only available in the Gemini mobile app and the Gemini web app at [gemini.google.com](https://gemini.google.com).
- We’re making network access for the remote computer available gradually, so it might not be available to you just yet.

## Assign coding & complex tasks to Gemini

You can assign Gemini a coding or complex task that requires processing files or gathering data. For example: “Download an open-access AI research paper, extract the architecture diagrams, and explain them in a summary doc.”

When a task requires extra processing power or coding tools, Gemini automatically uses the remote computer to work on that task. [Learn how to assign tasks to Gemini](https://support.google.com/gemini/answer/17094507).

## Review code executed on the remote computer

When Gemini uses the remote computer, you can review snapshots of the code it runs.

1. On your computer, open the task thread using the remote computer.
2. At the top, click **Computer** ![](images/img-01-944c54.png) ![and then](images/img-02-bfcdbc.png) **View executed code** ![](images/img-03-a30ec9.png).
3. To scroll through snapshots, at the bottom, click View previous ![](images/img-04-ace26c.png), View next ![](images/img-05-4a00fc.png), or **View latest** ![](images/img-06-250a06.png).
4. To go back to the task thread, at the top, click Close remote browser ![](images/img-07-59ce42.png).

## Manage network access for the remote computer

By default, the remote computer Gemini uses for your tasks is not connected to the internet. You can turn on “Network access for remote computer” in your Task settings so Gemini can go online to help with your tasks.

Before you turn on network access

Before you turn on network access for the remote computer, review these important details and risks:

- **Your tasks share one computer.** Gemini uses the same remote computer across all your tasks.
- **Review how long data is kept and your choices.** To help get things done for you, your computer stores some data, such as core tools and software files that keep your workspace running, your personal configurations, tool login tokens, command history, and files. Some of this data expires automatically after a set period of time, and some of it is kept until you delete it. You can ask Gemini what data, including files, it has stored. You can delete any of this data at any time in [your Task settings](https://gemini.google.com/gemini-spark). [Learn how to delete remote code execution data](#delete_code_data).
- **Be cautious of unsafe code.** When the remote computer connects to online services or untrusted sources, it can be exposed to malicious or unsafe code that downloads and runs automatically. This unsafe code could read saved task files and share them online.
- **Be mindful of stored files and code.** You can manage or clear your code execution history and files in [your Task settings](https://gemini.google.com/gemini-spark) at any time.

Turn network access for the remote computer on or off

**Important:** Never share files with sensitive or personal info, secrets, API keys, or private credentials while network access is on.

When you turn on network access for the remote computer, Gemini can connect to online websites and services. It can also download software, install packages, and call external APIs.

1. On your computer, go to [gemini.google.com](https://gemini.google.com).
2. At the bottom, click Settings ![](images/img-08-bbb6bc.png) ![and then](images/img-02-bfcdbc.png) **Task settings** ![](images/img-09-57eb08.png).
3. Turn **Network access for remote computer** on or off.

What happens if you turn off network access

If you turn off “Network access for remote computer,” it:

- Disconnects the remote computer from the internet right away
- Deletes your files and tools saved on the remote computer

## Delete remote code execution data

When Gemini uses a remote computer to run code or perform complex tasks, it saves data on the remote computer for future sessions for your convenience. You can delete all the data saved on the remote computer at any time in Task settings. This will delete all saved remote code execution files and data from previous sessions.

1. On your computer, go to [gemini.google.com](https://gemini.google.com).
2. At the bottom, click Settings ![](images/img-08-bbb6bc.png) ![and then](images/img-02-bfcdbc.png) **Task settings** ![](images/img-09-57eb08.png).
3. Under “Delete remote code execution,” click **Delete** ![](images/img-10-23ae4d.png).
