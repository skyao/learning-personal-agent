**“** 互联网的交互方式正在发生一次新的变化。**”**

如果明天你醒来，发现有一个 AI 已经替你做完了这些事情：

它知道你今天有三个会议，已经阅读了相关邮件和文档；它发现你上周收藏的一个产品降价了，按照你之前设定的预算和偏好，整理好了购买建议；它知道你下周要去上海，已经比较好了机票和酒店，甚至发现航班时间与一个重要会议冲突，提前给出了调整方案。

你没有给它下达十几个指令。你只是在几天前告诉它：「帮我把这周的事情安排好」。这就是我理解的 Personal Agent。

过去两年，我们一直在讨论 AI 能不能写代码、做 PPT、分析数据。但一个更值得关注的变化正在发生：AI 正在从一个等待你提问的工具，变成一个能够理解你的目标、持续管理任务，并代表你与数字世界交互的代理人。

这不是 Siri 的升级版，也不是 ChatGPT 多了几个插件。它可能意味着，互联网的交互方式正在发生一次新的变化。

01

—

不是 Agent，而是 Personal

很多人对 Personal Agent 的理解存在一个误区：把它等同于一个拥有更多工具调用能力的 AI Agent。但 Agent 和 Personal Agent 不是一回事。一个通用 Agent 可以帮你完成一项研究任务、写一个程序，或者在浏览器里操作十几个网页。

但一个真正的 Personal Agent，需要回答一个更难的问题：它凭什么代表你做事？这里面至少有五种能力。

第一，长期理解一个人。它不仅知道你刚刚说了什么，还需要理解你的历史、偏好、工作习惯、关系和长期目标。比如，你让它推荐一家餐厅。普通 AI 会根据评分和距离推荐。Personal Agent 则应该知道你不喜欢排队，最近在控制预算，周末通常和家人一起吃饭，而且你之前说过不喜欢某种菜系。这不是简单的聊天记录，而是一套不断更新的个人上下文。

第二，从指令理解升级到目标理解。你告诉它「帮我准备一次 AI 行业分享」。它不应该只生成一份 PPT，而是要理解分享对象、时间、内容目标，判断还需要哪些研究，拆解任务并推进。人只需要定义目标，不必亲自设计每一步操作。

第三，能够跨应用执行。真正的 Personal Agent 不应该被困在一个 App 里面。它需要连接邮件、日历、浏览器、办公软件、社交平台、购物平台，以及各种专业工具。否则，它只是一个拥有更多功能的 AI App，而不是个人代理。

第四，拥有持续工作的能力。传统 AI 的工作周期通常是一次对话。Personal Agent 的工作周期应该是一个长期目标。你交给它一项任务，它可以在后台持续推进，遇到新情况时调整计划，在需要你决策的时候再回来。

第五，拥有明确的权限和责任边界。它可以帮你起草邮件，但不一定有权直接发送。它可以比较商品，但不一定有权自动付款。它可以整理文件，但不能擅自删除重要资料。真正的个人代理，必须知道自己什么时候可以行动，什么时候必须征求你的同意。

所以，我更愿意这样理解：Personal Agent = 以个人上下文为基础，以个人目标为驱动，能够跨应用持续执行任务，并接受个人授权与监督的 AI 系统。

它的核心不是更聪明，而是更了解你，也更有能力替你做事。

02

—

两条不同进化路线

一个有意思的现象是，硅谷公司更倾向于从通用模型、云端计算和数字工作环境出发。中国公司则更倾向于从手机、超级应用和现实生活服务出发。这不是简单的技术路线之争，而是两种互联网生态的自然延伸。

硅谷：让 AI 成为一个独立的数字代理人

2026 年 9 月，Meta 发布了 Muse，这是一个值得认真研究的产品。

它拥有独立的云端虚拟计算环境和浏览器，可以连接用户的邮件、日历等应用，持续推进个人目标。

你可以让它处理邮件、安排旅行、填写表格，甚至在后台持续工作。它还会记住用户曾经提到的事情，在合适的时间主动提出建议。

更重要的是，它开始把安全机制设计进产品架构：独立的云端执行环境—— 单独的安全代理审核对外操作—— 敏感操作需要用户确认—— 用户可以查看完整操作记录——用户可以管理和撤销应用权限。

这些设计说明，硅谷头部公司已经开始认真思考一个问题：如果 AI 要代表一个人行动，它需要什么样的数字工作环境？

这种路线的核心是：把 AI 从一个 App 里的功能，变成一个拥有独立工作环境的数字员工。它可以在互联网中移动，连接不同服务，完成跨平台任务。

中国：让 AI 成为手机和生活服务的统一入口

中国互联网生态有一个非常明显的特点：超级应用和生活服务高度集中。支付、购物、外卖、地图、旅行、社交，几乎都已经存在于成熟的平台之中。这给中国 Personal Agent 提供了一个很好的切入点。

2026 年 1 月，阿里升级千问 App，将淘宝、支付宝、飞猪、高德等服务连接起来。用户可以直接通过自然语言完成点餐、支付、旅行规划和预订。

到了 5 月，千问进一步接入淘宝和天猫的完整商品目录，尝试把传统搜索框变成一个能够理解需求、比较商品和执行购买任务的对话入口。

9 月，阿里又推出 Qwen Intelligence，与荣耀合作探索 Agent 手机。其中包括负责任务规划的 Mobile Planner Agent，以及负责跨 App 操作的 Mobile-Use Agent。

这条路线的核心是：让 AI 成为现实生活服务的统一调度入口。你不需要知道应该打开哪个 App，也不需要了解背后有多少个服务商。

你只需要表达自己的需求。

但这里有一个非常值得关注的现实问题。2026 年 10 月，媒体报道，超过 150 个中国 App 限制豆包手机助手通过 GUI 自动化操作其应用，其中涉及微信、支付宝、美团等平台。这件事很有代表性。

Agent 可以操作 App，不代表 App 愿意被 Agent 操作。

中国的 Agent 想要成为超级入口，必须面对一个现实问题：原有互联网平台未必愿意把自己的用户入口和交易关系交给另一个 Agent。

总结来看，路线虽然不同，但最后都要解决同一个问题：谁有权代表用户进入数字世界？

03

—

不是模型，而是个人上下文

如果今天有两个 Agent。A 的模型能力非常强，但每次使用都需要重新告诉它自己的情况。B 的模型能力稍弱，却知道你过去三年的项目、工作习惯、兴趣、偏好和长期目标。

你会选择谁？

我倾向于 B。因为对于 Personal Agent 来说，个人上下文可能比单次推理能力更重要。这里有一个值得关注的概念：Human Context Layer。BCG 在 2026 年的一篇关于 Personal Agent 的研究中，将其描述为一个结构化、经过授权的个人上下文层。

它涉及六类信息：

沟通信息：邮件、消息和关系历史。

时间信息：日历、安排和周期性习惯。

财务信息：账户、消费习惯和授权额度。

健康信息：运动、健康记录等。

职业信息：工作工具、角色和组织关系。

行为信息：浏览、购买、位置和个人目标。

这些信息组合起来，才能让 Agent 真正理解一个人。

例如，航班延误了，普通 AI 可以告诉你有哪些替代航班。

Personal Agent 则应该知道你为什么要去这座城市、你能接受多少额外费用、下一场会议有多重要，以及你是否愿意改变原来的行程。

它提供的不再是一个答案，而是一个结合个人处境的决策。这才是 Personal 的含义。

但这里也出现了一个更大的问题：这些个人上下文究竟应该属于谁？

如果你使用 Meta，记忆留在 Meta。

如果你使用 Google，记忆留在 Google。

如果你使用阿里，记忆留在阿里的生态中。

你可能用了三年时间训练一个 Agent，让它越来越了解自己。

但有一天，你想换一个 Agent，能不能把这些记忆完整迁移过去？如果不能，那么个人记忆就会变成新的平台锁定工具。

我认为，未来 Personal Agent 竞争有一个非常重要的指标：

个人上下文是否能够被用户真正拥有、管理和迁移。

模型可以更换，Agent 可以更换，但一个人不应该因为更换 AI 服务商，就失去自己长期积累的数字记忆。

04

—

下一代个人数字生命操作系统？

过去二十年，互联网的入口经历了几次变化：

门户网站时代，我们通过网站进入互联网；搜索引擎时代，我们通过关键词寻找信息；移动互联网时代，我们通过 App 进入服务。

生成式 AI 时代，我们开始通过对话获取知识和生产内容。

Personal Agent 时代，我们可能直接通过目标委托，让 AI 代表自己调用互联网服务。

这里有一个根本变化：

过去，互联网要求用户理解它的产品结构。你需要知道应该打开哪个 App，点击哪个按钮，填写什么信息。

未来，Agent 可能会逐渐替用户理解这些产品结构，用户只需要表达目标。

这意味着，互联网平台争夺的东西可能会改变。

过去，平台争夺的是用户时间、用户注意力和 App 使用频率。未来，平台还需要争夺 Agent 的调用、推荐和交易。

用户不再需要亲自打开每一个 App，但这并不意味着 App 会消失。服务、商品、支付、供应链、履约仍然需要真实的平台提供。改变的是用户与这些服务之间的关系。App 可能从用户的主要交互界面，逐渐变成 Agent 背后的服务能力。

那么，Personal Agent 是不是个人数字生命的操作系统？

这个比喻有一定道理，但还不够准确。操作系统管理设备、进程、文件和权限，Personal Agent 管理的是个人目标、上下文、任务和委托关系。

它可能运行在手机、电脑、云端，也可能同时存在于多个设备上。它更像是一个个人数字生活的编排层：向下连接设备、操作系统、应用和服务；向上理解个人的目标、偏好、关系和长期计划。

操作系统让计算机能够工作，Personal Agent 希望让数字世界能够围绕一个人工作。

05

—

Personal Agent 应该属于谁？

假设未来每个人都有一个 Agent。它知道你的工作、消费、日程、关系、偏好和长期目标。它甚至比你自己更清楚，你过去几年做过什么决定。那么，这个 Agent 究竟应该属于谁？

是 OpenAI、Google、Meta这样的科技公司？还是应该成为一个由个人真正拥有、可以自由迁移的数字资产？

这两种路径可能带来完全不同的互联网。

第一种路径，科技公司掌握个人上下文，Agent 越了解你，你就越难离开这个平台。

第二种路径，个人拥有自己的上下文，可以授权不同 Agent 使用它，服务商之间围绕能力和体验竞争。

前者可能形成新的超级平台。后者则可能带来一种新的个人数字主权。

当然，个人拥有数据并不意味着必须自己维护所有技术，也不意味着 Agent 可以脱离服务商独立运行。但至少，个人应该拥有知情权、授权权、撤销权和迁移权。

最后想说的是：Personal Agent 不是给 AI 装上一双手，而是让 AI 获得了代表一个人行动的资格。这才是它与上一代个人助理最大的区别。

未来的竞争，不只是哪个模型更聪明，也不只是哪个 Agent 能操作更多 App。而是谁能够真正理解一个人，持续为这个人创造价值，并且让这个人放心地把一部分数字生活交给它。

如果说移动互联网时代，每个人都有一部智能手机。那么在 Agent 时代，每个人可能都需要一个真正属于自己的数字代理人。

下一代互联网最重要的入口，可能就藏在这里。
