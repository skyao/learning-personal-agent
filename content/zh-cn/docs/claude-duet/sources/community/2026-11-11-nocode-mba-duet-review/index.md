Claude Duet 评测：我设置它时发生了什么

Claude Duet 导入了我的 Claude 设置，却仍然让我解释我是谁。以下是我第一次使用时，它的共享记忆频道、Tasks 页面和 Opus 5.5 模型选择表现如何。

我本以为 Claude Duet 一导入我的 Claude 账号就会认识我。它把我的工具、项目、聊天、记忆和技能都带了过来，然后仍然让我用自己的话描述我的工作。这是设置 Anthropic 这款个人 AI 智能体时的第一个意外，也为这个应用的其余部分定下了基调：一个助手，一份共享记忆，按生活的不同部分分成不同频道，还有一个专门的任务（Tasks）页面处理持续推进的工作。

我用 Duet 整理了一个健身教练频道、为 No Code MBA 批准了三项研究任务，并在应用内审阅完成的文档。我的看法是：相比一堆聊天线程，这个界面让持续进行的工作更容易跟进，我也喜欢它跑在 Opus 5.5 上。代价是模型固定。你不能切换到其他提供商，而且我还想看看 Duet 长期下来能有多主动。

## Claude Duet 设置过程中让我意外的地方

Duet 的引导从延续性开始。它会提出导入你 Claude 账号关联的工具、项目、聊天、记忆和技能。它还会给 Claude 一台自己的云端计算机，并可以选择连接你的计算机，让它能使用你已经登录的网站。我一开始跳过了连接应用，把设置限制在探索界面所需的范围内。

然后 Duet 告诉我，它掌握的信息太少，无法公平地了解我，并请我说明我的工作。我告诉它我运营 No Code MBA 的 YouTube 频道，想把它做大。接下来，它就围绕我的领域和视频创意提出了建议。这个额外的问题很小，但值得知道：导入账号上下文并没有消除用平实语言向 Duet 说明什么对你重要的需要。

Anthropic 把 Duet 描述为一个基于云的智能体，可以在你离开应用后继续工作，并称它在发送消息、付款、签署文件或删除内容等操作前会请求批准。当前的预览详情见 [Claude Duet 官方公告](https://claude.com/resources/articles/claude-duet) 和 [Claude Duet 设置与访问指南](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet)。

## 一个智能体，共享记忆，独立频道

Duet 给你一个主聊天，以及若干频道。频道把话题分开，又不必为每个话题创建单独的智能体。我建了一个叫「Workout coach」的频道，免得它混进我的工作聊天。Duet 仅凭频道名称就提出了任务，之后我要求工作日早上 8 点做一次 check-in。这段体验让整个结构很容易理解：不同话题用不同工作区，但它们背后是同一个助手、同一份共享记忆。

如果你想要条理又不想管理一长串智能体，这是一个有用的中间方案。在我的比较里，Grok Bot 的各个独立机器人各自拥有自己的上下文，而 Meta Muse 更接近 Duet 这种单一助手加侧边聊天的做法。我在这里描述的是产品的结构，并不是声称做了一次正面对比的性能测试。

想更仔细了解那些其他工作流，可以读我的 [Meta Muse 评测](https://www.nocode.mba/articles/meta-muse-ai-review) 和 [Meta Muse 与 Grok Bot 对比](https://www.nocode.mba/articles/meta-muse-vs-grok-bot)。我还在 [Claude Cowork 评测](https://www.nocode.mba/articles/claude-co-work-review--ai-agent-file-management) 中解释了 Anthropic 其他智能体工具之间如何配合。

## Tasks 页面让后台工作保持可见

Duet 为我的频道建议了三项任务：找出 10 个热门的无代码和 AI 视频创意、分析我最受欢迎的视频有什么共同点，以及评估竞争频道。我在聊天中逐一批准了它们。三项任务都作为活动项出现在 Tasks 页面上，我可以在那里打开任务、查看它的计划和进度，而不必猜测智能体在做什么。

完成的工作以文档形式送到 Duet 里。我审阅了视频创意和对现有视频的分析，然后勾选一项任务，把它移入 Resolved。有用的地方不只是它生成了报告。由于工作在同一个助手中保持连贯，我可以回到主聊天，询问它做过的那份报告。

聊天：你批准 Duet 建议的一项任务

任务页：处于活动状态，显示它的计划与进度

文档：完成的工作，就在 Duet 内

在主聊天中询问那份报告

询问那份报告

我还看到了 Slack、邮件、Google 云端硬盘、Stripe 和 1Password 等服务的连接器选项。这次我没有连接那些账号，所以我不把这段视频当作 Duet 在各个服务内能做什么的测试。在连接你自己的账号之前，应到 Anthropic 的帮助页面查看当前的设置要求和资格。

如果你不熟悉智能体工作流背后的术语，我的[AI 工作流入门指南](https://www.nocode.mba/articles/vibe-coding-beginners)给出了基本概念。关于 Claude 中可复用的上下文，见我的 [Claude Skills 教程](https://www.nocode.mba/articles/claude-skills-tutorial)。

## 模型选择固定是主要的取舍

Duet 跑在 Anthropic 的 Opus 5.5 上，应用不提供模型选择器。如果你想把工作交给其他提供商，或为某项任务选择别的模型，Duet 做不到。我喜欢 Opus 5.5，所以目前这个取舍我可以接受，它不是我跳过这个应用的理由。如果你在判断自己的 Claude 订阅是否值得，可以把下面链接的价格指南与 Anthropic 当前的套餐详情对照着看。

想更仔细了解你的套餐成本，见我的 [Claude 价格指南](https://www.nocode.mba/articles/claude-pricing-2026)。Anthropic 表示 Claude Duet 目前是面向美国 Pro、Max 和 Ultra 套餐订阅者的研究预览，通过候补名单获得访问权限，用量限额与 Claude 其他部分相同。资格和访问方式可能变化，请到[官方帮助页](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet)确认。

## Claude Duet 值得一试吗？

我的第一印象是 Duet 做得很扎实。我喜欢「一个助手、共享记忆、频道，加一个独立的 Tasks 页面」这个组合。它让我批准的工作容易跟进，完成的报告也可以在同一处审阅和讨论。如果你已经在受支持的 Claude 套餐上、又能拿到邀请，我认为值得下载，尤其是如果你喜欢 Opus 5.5。

对我来说，悬而未决的问题是主动性：Duet 会随着了解我的日常而不断提出有用的工作，还是大部分价值仍来自我明确批准的任务？这第一次会话展示的是设置和任务审阅流程，不是长期可靠性测试。我会继续用它，但我会用时间来判断：它的建议是否真的有用，它的后台工作是否总能在我的一天里挣得一席之地。

## 常见问题

### 在 Claude Duet 里可以选择模型吗？

不能。在演示的预览版中，Duet 跑在 Claude Opus 5.5 上，不提供模型选择器。

### Claude Duet 会在不同频道之间共享记忆吗？

会。在演示的设置中，Duet 是一个拥有共享记忆的助手，而频道用来区分话题和项目。

### 谁可以使用 Claude Duet？

Anthropic 目前把 Duet 描述为面向 Pro、Max 和 Ultra 订阅者的美国研究预览，通过候补名单获得访问权限。当前资格请查看 Anthropic 的帮助页。
