## 收集者摘要

帮助中心的入门文档，覆盖使用条件、工作方式、加入候补名单、连接应用、局限、价格与用量、隐私与安全。使用条件为 Pro、Max 或 Ultra 套餐、美国的 Claude 账号和候补名单邀请，Team 与 Enterprise 计划以后再支持。它沿用 Claude 账号的记忆、技能和连接器，在云端自己的计算机上工作，有 Tasks 标签页跟踪任务，并可搜索用户在 Claude 中的历史对话（受同一设置控制）。局限包括：不能选模型（固定 Claude Opus 5.5，自行决定投入多少推理）、不能观看或接管其浏览器、按固定间隔检查账号、不打电话不发短信、部分操作即使批准也不允许、Microsoft 365 暂不可用。用量与 Claude 聊天按同等费率计入五小时和每周限额，晨报和检查等后台工作也计入；获准加入预览时可获得一次完整的限额重置，有效期至 2026-11-30。

## 保留理由

列出了发布文中没有的具体限制（不能选模型、不能看浏览器、不能打电话发短信、Microsoft 365 不可用）和用量计算规则，是 Claude Duet 当前能力边界的官方依据。
