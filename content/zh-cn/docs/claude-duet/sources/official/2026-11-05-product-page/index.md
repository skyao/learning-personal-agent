## 常见问题

### 什么是 Claude Duet？

Claude Duet 是一个能干、主动的 agent，你通过消息把工作交给它。告诉它你需要什么，它就在云端属于它自己的一台计算机上，使用你连接的应用来工作。它做完或需要你决定时会给你发消息。它虽然一直在线，但在主动联系你时会做出良好判断，知道什么可以等。

### Claude Duet 如何工作？

在应用里给 Claude Duet 发消息，就像给一位你信任的同事发消息，用文字或语音都行，不需要提示词，也不需要设置。你的历史都在一个线程里。它记得你之前说过的话，并把完成的成果（如文档、表格或演示文稿）交回来供你审阅。

### Claude Duet 与 Claude 有什么不同？

Claude Duet 使用你的 Claude 账号，包括记忆、技能和连接器。Claude 应用等你打开对话，然后你和 Claude 一起处理某件事。Claude Duet 会来找你。它每天早上告诉你什么需要你关注，承接你通过消息交给它的任务，并在任务完成或需要你批准时主动联系你。

### Claude Duet 能做什么？

Claude Duet 可以发送晨报，标出收件箱和日历中需要你处理的事项，起草回复供你批准。它也承担一部分经营业务的工作，例如找出未付发票并起草提醒、准备好工资单供你审阅、把合同准备好待发送。它也能整理简报、演示文稿或仪表盘。

### 谁能使用 Claude Duet，费用是多少？

Claude Duet 是研究预览版，以候补名单方式提供给美国、印度、印度尼西亚、巴西和日本的 Claude Pro、Max 和 Ultra 订阅用户。Team 和 Enterprise 套餐暂不包含。

### Claude Duet 的用量如何计算？

研究预览期间，Claude Duet 与 Claude 的其余部分共用你套餐的用量限额，但用量方式与典型对话不同。它的后台检查计入这些限额。较大的任务，例如构建财务模型或演示文稿，需要更多的模型轮次和后台工作。

### 我在哪里可以使用 Claude Duet？

Claude Duet 是面向 iOS 和 Android 的独立应用。在电脑上，可以在 claude.ai 的网页上打开。

### 还有什么尚未就绪？

Claude Duet 是研究预览版。它可能误读某个线程，或对什么算紧急判断失准，也可能漏掉在两次向你了解情况之间到来的事情。
