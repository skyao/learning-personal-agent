## 常见问题

### Claude Duet 是什么？

Claude Duet 是一个有用、主动的智能体，你通过消息把工作交给它。告诉它你需要什么，它就会在你连接的应用程序中，用它自己在云端的计算机上工作。当它完成或需要你做决定时，会给你发消息。虽然它始终在线，但它在联系你时会做出良好判断，知道什么可以等待。

### Claude Duet 如何工作？

在应用里像给一位你信任的队友发消息那样给 Claude Duet 发消息，可以用文字或语音，不需要提示词或设置。你的历史都在同一个对话线程中。它记得你之前说过的话，并交回完成的成果，例如文档、表格或演示文稿，供你审阅。

### Claude Duet 与 Claude 有什么不同？

Claude Duet 使用你的 Claude 账号，包括记忆、技能和连接器。Claude 应用等你打开对话，你与 Claude 一起处理某件事。Claude Duet 会主动来找你。它每天早上告诉你什么需要你关注，接受你通过消息交给它的任务，并在任务完成或需要你批准时联系你。

### Claude Duet 能做什么？

Claude Duet 可以发送晨报，指出你的收件箱和日历中需要你处理的事项，并起草回复供你批准。它还承担一些经营业务的工作，例如找出未付发票并起草提醒、准备薪资供你审阅，以及准备好合同以便发送。它也能整理简报、演示文稿或仪表盘。

### 谁可以使用 Claude Duet，费用是多少？

Claude Duet 是一项研究预览，面向美国的 Claude Pro、Max 和 Ultra 订阅者，采用候补名单制。目前不包含 Team 和 Enterprise 套餐。

### Claude Duet 的用量如何计算？

在研究预览期间，Claude Duet 与你套餐中的其余 Claude 功能共用用量限额，且使用方式与典型对话不同。它的后台检查会计入这些限额。更大的任务，例如构建财务模型或演示文稿，需要更多模型轮次和后台工作。

### 我可以在哪里使用 Claude Duet？

Claude Duet 是一款适用于 iOS 和 Android 的独立应用。在电脑上，你可以在网上通过 claude.ai 打开它。

### 哪些功能还没准备好？

Claude Duet 是一项研究预览。它可能会误读一段对话或误判什么才算紧急，也可能漏掉在两次与你确认之间到来的某些事情。
