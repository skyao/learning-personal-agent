# 主题标签词表

每篇资料打 1 到 4 个标签，选资料的主要内容所涉及的主题，顺带提到一句的不打。只能从下表中选；词表覆盖不了时，在本轮报告中提出新标签建议，由用户决定是否加入。

以后分析一侧的目录按这些标签划分，所以标签要打准，不要为了覆盖面多打。

| 标签 | 用于 |
| --- | --- |
| 发布 | 产品发布、新地区上线 |
| 功能更新 | 新功能、版本变化 |
| 开放与价格 | 地域、套餐、邀请制、费用 |
| 运行环境 | VM、沙箱、云端与本地执行 |
| 记忆与上下文 | 个人数据接入、记忆机制 |
| 持续执行 | 后台任务、定时、目标跟进 |
| 连接器 | 第三方应用接入 |
| 设备 | 眼镜、电脑、手机等终端 |
| 交互渠道 | 用户与智能体交流的入口：短信、iMessage、WhatsApp、Telegram 等消息应用，专属邮箱与电话，以及接入这些平台的审批与费用 |
| 模型 | 底层模型、模型卡、评估 |
| 安全 | 权限、审批、漏洞、安全事件 |
| 隐私 | 数据使用、分享、第三方同意 |
| 实测评测 | 任务实测、横向评测 |
| 商业与规模 | 用户数据、财报、商业模式 |
