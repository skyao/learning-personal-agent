# 翻译 agent 说明

本文件给负责翻译的 agent（或其他翻译工具）使用，可以单独交给它，不需要读收集流程的其他文件。

## 任务

把一篇外文资料的原文译为中文，写入它的资料页。

- 输入：资料目录下的 `original.md`（原文全文存档）。
- 输出：同目录的 `index.md`，在文件末尾追加「译文」一节，并修改 frontmatter 的 `translation`。

## 找出待翻译的资料

```bash
grep -rl "^translation: 待翻译" content/zh-cn/docs --include=index.md
```

只处理同目录下有 `original.md` 的页面；没有的（`fidelity: 仅链接`）跳过，报告给用户。

## 步骤

1. 读 `original.md`。开头两行是来源与取文信息，不翻译；空行之后是正文。
2. 读 `index.md`，了解 frontmatter 与收集说明（其中可能写了原文的删节、结构还原等处理）。
3. 在 `index.md` 末尾追加：
   ```
   ## 译文

   （译文）
   ```
   原文的 `##` 标题在译文中降为 `###`，`###` 降为 `####`，依此类推。
4. 把 frontmatter 的 `translation: 待翻译` 改为 `translation: 已翻译`。
5. 不改动 `index.md` 已有的其他内容（frontmatter 其他字段、收集说明、收集者摘要、保留理由），不改动 `original.md`。
6. 在仓库根目录运行 `npm run build`，退出码必须为 0。

## 翻译规则

- 译文要准确、完整，语句通顺；不删减、不摘要、不调整段落顺序，不意译、不润色、不补充原文没有的内容。
- 产品名、公司名、人名、模型名保留英文，不翻译，例如 Muse、Dots、OpenAI、Mona Sarantakos。
- 功能名与术语首次出现时写「中文译名（English）」，之后用中文；没有通行译名的保留英文。
- 数字、日期、金额、百分比、版本号照录，不换算币种和时区；原文给出时区时一并保留。
- 引语译为中文，加中文引号「」。
- 代码、命令、配置、日志、提示词原样保留，不翻译；需要时在其后加译注说明含义，例如「（译注：意为「……」）」。
- 原文语义含糊或可能有多种理解时，按字面译出，在该处加译注：「（译注：原文为 "..."）」。译注只用于语言层面的说明，不写评价。
- 标题层级、列表、表格、引用和代码块保持原样（标题按上面的规则降一级）。
- 链接保留原始 URL。图片保留 `original.md` 中的相对路径（如 `images/xxx.png`），替代文本 `![...]` 与图注译为中文。视频、音频的占位行（如 `[视频：...](URL)`）把说明译为中文，链接不变。

## 完成后报告

列出处理的页面、跳过的页面及原因，以及原文中拿不准、加了译注的地方。不回传译文全文。
