## 收录范围

用户 2026-11-06 决定按 Personal Agent 跟踪 WorkBuddy。它本身定位为「全场景 AI 办公工作台」，收集时只收与 Personal Agent 五个方面（个人上下文、实际执行、持续运行、长期委托、用户控制）相关的资料。

- 收：产品简介、更新日志、助理（远程任务）与各 IM 接入指南、定时任务、记忆、项目、技能、连接器、模型配置、积分与定价、Buddy One 会员、权限与沙箱、数据管理、Agent 邮箱；腾讯官方对 WorkBuddy 的定位文章；专门写 WorkBuddy 的一手实测。
- 不收（文档站中的其他页面）：安装指南、界面说明（侧边栏、任务栏、右侧栏、设置、结果查看、文件浏览器）、任务创建与对话的操作说明、实践案例（Practice-*）、「零成本技能 Top 10」、知识库与资料库（IMA、乐享、腾讯文档协作）、应用发布（Web 应用、小程序、云服务）、开发者功能（Git 集成与并行开发）、灵感与专家中心、FAQ、错误码、账户注销、发票、下载历史、套餐管理与用量查询。这些页面以操作细节为主，属于 tracking.md 所说的边缘资料；确有新信息时再列入报告。
- 企业版与托管：Buddy 应用（企业与行业工作台）、Enterprise 专享版（`cloud.tencent.com/document/product/1831/139478`）、Managed Agents 白名单内测（`.../1831/138968`）属于企业智能体平台，不收。
- 开放平台（`open.workbuddy.cn` 第三方应用开发说明）、腾讯云数据库 Memory Hub 的接入文档（`cloud.tencent.com/document/product/1813/137263`）是开发者与可选集成资料，不收。
- 法律文档（服务协议、隐私政策）不收；文档页末尾引用协议的「声明」一节照常保留。
- QClaw（腾讯基于 OpenClaw 的本地助手，2026-09-24 宣布停运、12-24 停服）是另一个产品，它的停运公告和报道不收；只在需要说明 WorkBuddy 用户来源时引用。
