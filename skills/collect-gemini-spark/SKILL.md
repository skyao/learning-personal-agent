## 收录范围

- 收：Spark / Task 本身的发布、更新、帮助页、产品页，专门写 Spark / Task 的报道和实测，以及用户对 Spark / Task 的一手问题记录。
- Gemini 应用的综合发布文只节选 Spark 部分（例如 I/O 发布文不收 Neural Expressive、Omni、Daily Brief）。Daily Brief 是另一个智能体功能，暂不收，以后若与 Task 合并再判断。
- 帮助中心：收专讲任务（tasks / task mode）的页面；技能、自定义 MCP 应用、相册工作流这类同时用于聊天和任务、但最早随 Spark 推出的页面也收。Personal Intelligence、过去聊天记忆、Connected Apps 总览等 Gemini 通用页不收（页面里没有任务小节）。
- 模型：按 tracking.md 的原则，只收说明模型用于 Spark / Task 的部分（例如 Gemini 3.7 Flash 发布文的「Improving Gemini Spark」一节，帮助页里任务模式按档位可用的模型表）。
- Chrome 的 auto browse 帮助页、Chrome 智能体安全设计文（2025-12-08）、Android 的 Gemini Task Automation（2026-02 起，Samsung 设备上的应用内自动化）不是 Spark 资料，不收。
- 只顺带提到 Spark 的 Google 博客文章（Windows 应用上线、技能进入聊天、新一批 Connected Apps 等）不收。
- Muse Spark（Meta 的模型）、NVIDIA RTX Spark 等同名事物与本产品无关，检索时排除。

## 官方渠道

| 渠道 | 地址 | 内容 | 抓取方法 |
| --- | --- | --- | --- |
| The Keyword 博客 | `blog.google/innovation-and-ai/products/gemini-app/...`；RSS `.../gemini-app/rss/`；sitemap `blog.google/en-us/sitemap.xml` | 发布与月度更新 | 直接下载，`extract.py auto`；正文在「Summaries were generated by Google AI」（或「This content is generated by Google AI」）之后、「Get the latest news from Google」之前，页首的分享按钮、音频播放器和 AI 摘要都要去掉。截至 2026-11-05，Spark 专题更新只有 6 月、7 月两篇 |
| Gemini Apps 帮助中心 | `support.google.com/gemini/answer/<id>?hl=en` | 任务、计划、Mac、技能、MCP、模型、相册 | 直接下载，选择器 `.cc`；页面不带日期，取收集日期。界面小图标是协议相对地址 `//lh3.googleusercontent.com/...`，改写站内链接时不能把它当成相对链接 |
| Spark 更新日志 | `support.google.com/gemini/answer/17171264` | 5–7 月逐日更新 | 现在跳转到 Gemini 总发布说明（`gemini.google/us/release-notes/`），用 Wayback 20260930003151 快照 |
| 产品页 | `gemini.google/overview/agent/spark/` | 定位、示例、常见问题 | 现在跳转到 `gemini.google/about/`，用 Wayback 20261011114836 快照；示例提示词在静态 HTML 中重复两次，常见问题的题目在折叠按钮里，要从 HTML 补回 |
| Gemini 总发布说明 | `gemini.google/us/release-notes/` | 全部 Gemini 功能 | 只在出现新的 Task 条目时节选 |

- 帮助中心有中文版（`?hl=zh-Hans`），按同一内容的不同语言版本记入 `altUrls`。
- 以后检查：The Keyword 博客 RSS 和 sitemap 中带 `spark` / `task` 的新文章，帮助中心任务页的「What you need」和限制是否变化（并发 15、计划 50），总发布说明里的 Task 条目。
